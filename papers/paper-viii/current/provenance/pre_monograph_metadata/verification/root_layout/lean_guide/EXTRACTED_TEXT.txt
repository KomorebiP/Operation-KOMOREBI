1 Reading a finite formal development
1.1 The objects precede the theorem names
A packet representation starts with a finite projector family and an operator. A structured rep-
resentation adds explicit factor matrices or tensor coordinates. A compiler starts with a finite
candidate tree and an independently defined set of legal cuts. An error theorem starts with actual
errors in a normed space and budgets that bound them. In each case, the theorem follows the ob-
ject being modeled. Reading only the endpoint name misses the domain, norm, convention, and
supplied data on which its conclusion depends.
Use the traditional paper’s original item numbers to find the corresponding subsection in Sec-
tion 11. Then locate its declaration in Section 12 and its module in Section 13. For a first reading,
work through the chapters in order. The small-core chapter is longer because the final block proves
optimality from several independent ingredients, rather than accepting an optimality certificate
as input.
1.2 A short Lean vocabulary
Source form
Meaning in this guide
Matrix m n K
A function with row type m, column type n, and coefficients
in K. Finite index instances provide finite sums; rectangular
shapes are visible in the type.
[Fintype I]
A finite enumeration of the index type. Empty index types are
allowed unless a nonempty hypothesis is separately stated.
[DecidableEq I]
Equality can be decided where the construction needs it. It is
not a numerical tolerance test.
Fin k
Natural indices smaller than 𝑘. The type Fin 0 is empty.
[Ring R]
Addition and multiplication are available; multiplication
need not commute.
IsUnit D
The matrix or algebra element has a two-sided multiplicative
inverse. A displayed inverse expression alone does not estab-
lish invertibility.
X →L[K] X
A continuous linear map over K, with its operator norm.
Option R
Either some v, a finite candidate value, or none, an unreachable
/ infeasible state.
let A := ...
A local definition in the statement.
It abbreviates the con-
structed object; it adds no hypothesis.
noncomputable def
A mathematically defined object using classical choice or
other noncomputable ingredients. It does not advertise an ex-
ecutable numerical routine.
A theorem statement may inherit variable declarations from its section. An omit ... in command
removes unused instances for that declaration. autoImplicit false means an undeclared symbol
is rejected rather than silently turned into an implicit parameter. Names such as SmallCore.spectr
alNorm explicitly choose the intended norm; a bare matrix norm also depends on the open norm
scope surrounding its declaration.

Induction is visible in the recursive structured algorithms and dynamic programs. A calc chain
shows the successive equalities or inequalities used in a norm estimate. Arithmetic tactics have
limited roles: ring normalizes polynomial identities, omega handles integer and natural-number
constraints, and linarith/nlinarith combine supplied real inequalities. They do not supply
unrecorded analytic or hardware assumptions.
1.4 Which evidence is current
The inherited sixth-block report records the compiler, source hashes, local dependency hashes,
saved log hashes, axiom sets, and two rejected invalid-proof controls. The present guide replays
