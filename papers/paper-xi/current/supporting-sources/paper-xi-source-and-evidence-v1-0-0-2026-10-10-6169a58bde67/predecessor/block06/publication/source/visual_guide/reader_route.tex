\textbf{One candidate throughout.} A source-defined induction candidate and a directly constructed type candidate are not identified merely by notation. Occurrence, full-character normalization and the noncompact extension must concern the same representation. The \href{https://komorebi.invalid/b06/visual_occurrence}{Part II occurrence analysis} retains the excluded original route and the corrected route's remaining obligation.

\textbf{A transported mark is not a prescribed native mark.} The positive scalar-pushout attachment carries the supplied finite marking through a center-fixing homomorphism. It does not identify that output with an independently fixed host subgroup. Conversely, the stronger native problem must not be inserted as a new premise into the different transported-marking result.

\textbf{The equal-capacity example is conditional.} At rank eight the full profile has exactly six quotient dimensions. The finite Arf test applies when the actual native refinement is independently prescribed. The abstract six-dimensional forms in the research atlas are examples, not a computation of that candidate's native square bits.

\textbf{A successful finite repair has inputs.} The transvection starts with an allowed symplectic map and an isotropic discrepancy vector. The odd-action correction starts with genuine supplied finite actions. Neither constructs the arithmetic normalizer or chooses every honest phase. See \href{https://komorebi.invalid/b06/visual_repairs}{plates V25--V29}.
