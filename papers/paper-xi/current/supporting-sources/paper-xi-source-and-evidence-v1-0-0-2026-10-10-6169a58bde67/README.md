## Package structure

`publication/source` contains the editable original-reader trio. `publication/pdfs` contains the five frozen readers. `evidence/block07` contains source maps, exact conversion patches, reference and claim audits. `verification/block07` contains executed tests, logs, render comparisons and rebuild receipts. `ledger` contains versioned snapshots. The complete compact Block06 predecessor is preserved under `predecessor/block06`, including its older checkpoints. Do not alter that history.

The source checkpoint is sufficient to rebuild the three originals, reproduce the checks, and assemble the five-reader set. It is not the entire historical scientific archive. The full recovered-source distribution additionally contains the unchanged Block01 scientific ZIP under `historical/`. Neither distribution supplies the missing complete Block02 editable ZIP.

The historical archive includes third-party reference material with its own rights. Inclusion in a recovered working package is not a new blanket license to redistribute third-party works publicly. No license change is made here. No standalone font files are supplied.

See BUILD.md, RELEASE_REVIEW.md, FAILURES_AND_LIMITATIONS.md, PROGRESS_LEDGER.md and CONTINUE_HERE.md. Archive-specific extraction/replay verification is exported separately to avoid a circular archive self-hash.
