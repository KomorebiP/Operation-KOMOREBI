I. MATHEMATICAL/MEANING RISK — RESOLVE OR EXPLICITLY RECORD

1. Moving-phase notation is used outside its declared domain.
   File: publication/source/traditional/Paper_XI_Traditional_Final.tex:1776–1788.
   Label: cor:break_phase.
   The hypothesis says the stabilizer preserves every break packet and is fixed point free on its moving part, but the displayed product uses Phi_p(g,V) and Phi_p(g,V_s). Definition def:odd_phase (around 1303) defines Phi_p only for an operator with no fixed vectors; def:moving_phase (around 1400) separately defines Phi_p^mov.
   Resolution choices: state this as a product of moving phases, retaining the semisimplicity/direct-complement assumptions needed to form them; or require that the operator have no fixed vectors on every whole summand. The choice is a substantive hypothesis/notation decision, so it must not be silently treated as a uniquely forced typo. The existing proof via prop:odd_multiplicativity supports the fixed-point-free version. The supplied Lean catalog includes BreakOddPhase.product_of_moving_forms and related moving-space results.

2. The type-side additive character is not defined, and its domain matters.
   File: main manuscript:1144–1163.
   Section: sec:typeside.
   The quotient is called a vector space over the residue field, then psi_0(h_theta(x,y))=theta([x,y]) is used to define h_theta. psi_0 appears nowhere else in the main source. If psi_0 is on a nonprime residue field, a single character value does not uniquely determine a residue-field element.
   Natural explicit convention: fix a nontrivial psi_0:F_p -> mu_p, regard the type quotient as an F_p-space, and define h_theta using that injective character. This aligns its coefficient field with the Galois-side F_p symplectic envelope. If a larger-residue-field form is intended, specify the additional bilinear normalization rather than asserting uniqueness from one character value.

3. Arbitrary cocycles need not literally have a finite central extension with their original values.
   File: main manuscript:976.
   Label: thm:twisted_matrix, semisimplicity sentence in its proof.
   Current sentence invokes Maschke averaging 'after passing to a finite central extension realizing the cocycle' although c:A x A -> C^times is arbitrary. A cocycle with non-root-of-unity values requires a cohomologous normalization before such a literal finite extension can be invoked.
   The theorem is correct. A short direct proof avoids the unnecessary assertion: for a submodule choose a linear projection P onto it and average u_a P u_a^{-1} over a in A. Projective scalars cancel in conjugation, so the average commutes with all u_a and is an equivariant projection. This establishes semisimplicity. Changing the proof should be documented as a mathematical clarification, not a conversion repair.

4. 'Complete finite invariants' can be read as an incorrect classification claim.
   File: main manuscript:1809, opening paragraph of sec:boundary.
   Current wording attributes 'complete finite invariants' to the local polynomial and conductor calculations. For all nontrivial irreducible tame atoms of a fixed rank n>1, these include local polynomial 1 and Artin conductor n, so this pair of invariants does not classify the atom.
   Minimal wording: replace 'complete finite invariants' with 'explicit finite invariants'. Full packet coordinates separately retain the inertia orbit and closing scalar.

5. The finite tame package proof omits two small edge cases.
   File: main manuscript:1811–1830.
   Label: prop:tame_package.
   (a) The package permits a tame induced atom of any rank, but cites prop:tame_conductor, whose hypothesis is n>1. Add the rank-one case: Artin conductor 0 for trivial inertia and 1 otherwise.
   (b) Item 6 speaks of a finite Gauss phase for each declared residue character, whereas def:gauss_phase defines a unit phase only for nontrivial multiplicative characters. The Lean guide's E09 discussion explicitly retains the trivial-character exception. Either qualify this item by 'nontrivial' or state separately that G(1,psi)=-1 and the q^{-1/2}-normalized sum has magnitude q^{-1/2}, so it is not the unit phase defined above.

III. OPTIONAL LOCAL CLARIFICATIONS

8. The tensor interaction cycle need not be the minimal inertia-character orbit.
   File: main manuscript:589–595, cor:gcd_lcm_count.
   'Each packet has Frobenius orbit depth L' refers to the L labelled coset lines of the induced interaction carrier. The interaction character may have a shorter Frobenius orbit and the induced packet may split further. Prefer 'each induced interaction packet has an L-step coset cycle and dimension L', with a sentence that the minimal character orbit can be shorter. This matches the proof's actual dimension argument and avoids conflating the induced carrier with an irreducible tame atom.

9. Transition indices stop before the final native rank.
   Files: appendices/odd_character.tex:57–76 and appendices/dyadic_character.tex:152–164.
   Native b_j is defined for 1<=j<=d. The subsequent gamma_j, b_(j+1), and q_(d-j) transition formulas require j<d. The intended range is evident from the induction, but explicitly prepend 'For 1<=j<d' at the transition definition/bullets to avoid q_0 and b_(d+1) at the boundary.

10. The projective holonomy paragraph presupposes scalar holonomies.
    File: main manuscript:1680–1686, prop:projective_holonomy.
    It starts with edge maps defined up to scalar and then refers to 'the two scalar holonomies'. The preceding corollary assumes all based holonomies are scalar. A short reference to that scalar-holonomy setting would make the presupposition explicit. Merely projective edge data do not force loop holonomies to be scalar.
