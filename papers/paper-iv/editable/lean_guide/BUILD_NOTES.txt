Build history
1. Initial data generation failed because the completion-status document has
   a short earlier table whose rows also begin with result numbers. The parser
   now accepts only the four-column full-result table, and asserts 68 rows.
2. The first TeX pass found an unescaped caret in literal theorem-map prose.
   The display escape routine now handles caret and tilde explicitly.
3. That aborted pass left a truncated auxiliary file. The compile-only builder
   now clears stale aux/toc/out files before its four passes.
4. Initial direct PDF output failed in xdvipdfmx font subsetting because a
   P052 font-family lookup selected a Type 1 bold font. Explicit P052 .otf
   filenames removed that ambiguity. No absolute font path is required.
All corrected builds preserve the original Lean sources and map wording.
