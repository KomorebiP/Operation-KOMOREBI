BUILD AND REPRODUCE
From this package root:
  python3 scripts/verify_integrity.py
  python3 scripts/build_pdfs.py --check-only

The second command rebuilds all PDFs in a temporary directory, compares
extracted text and page counts, and leaves the shipped PDFs untouched. It
needs Python 3, PyMuPDF, pdfLaTeX, XeLaTeX, latexmk, BibTeX, and the fonts/TeX
packages listed in each companion. For a normal edit, use the build.py in
that companion directory. No Lean build is performed by PDF assembly.

To rerun the finite computational checks, use the portable runner documented
in verification/computational/README.md with --release-root pointing to
source/canonical_v1.2.1 and --visual-root to source/visual_guide_original. It
requires the documented Python dependencies. Formal replay instructions and
dependency pins are in the Lean guide and canonical formalization folder.
Rebuilding can change PDF bytes across TeX versions; original delivered
checksums apply to the shipped edition, not to subsequent edits.
