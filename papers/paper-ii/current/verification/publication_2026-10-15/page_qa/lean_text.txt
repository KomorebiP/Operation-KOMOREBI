2 Reading the inherited formal walkthrough
The traditional paper develops the mathematical theory and its written proofs. The visual guide pro-
vides finite models for its identities, precision statements, and boundaries. This guide explains how to
read and use the preserved Lean component: the types accepted by each theorem, the objects actually
constructed, the obligations supplied by a caller, and the evidence attached to the source. These three
companions have complementary roles.
The component described in this walkthrough is the historical version 1.1.1, preserved within canoni-
cal manuscript release 1.2.1. Current additions and their boundaries are recorded in Section 1. In the
delivered package it is located at source/canonical_v1.2.1/formalization/lean/. The final traditional
edition incorporates a broader written development. Its ordinary proofs of lattice gluing, necessary
precision delay, convergence in an inverse limit, general DVR arithmetic, holomorphic and exponen-
tial defects, and multilevel identities are not converted into Lean proofs by appearing beside formally
mapped results.
The fixed formal contract contains 25 rows: 21 numbered canonical statements, one Smith phase iden-
tity, and three mathematical algorithm specifications. The appendix crosswalk identifies their loca-
tions in the integrated traditional edition. Throughout this guide, “row” means a row of the canonical
formal map, never a count of every theorem in the final traditional paper.

Parenthesized arguments are normally supplied explicitly. Braced arguments can be inferred. Argu-

The common constructor tactic splits a structure or conjunction into its fields. rcases opens a supplied
witness into its data and proofs. rw rewrites using proved equalities. simp applies simplification rules
and produces a proof term. ext reduces equality of structured maps to pointwise equality. exact
supplies a term of the required type. rfl uses definitional equality. None of these words is a substitute
for a missing mathematical hypothesis.

3.1 Definitions, certificates, and algorithms
A structure such as TwoSidedInverse x y records equations about already supplied 𝑥and 𝑦. A theorem
that accepts this structure does not discover 𝑦. By contrast, the rationality branch for finite graphs
defines a denominator and numerator from the graph and proves their properties without accepting
rationality as an input.
noncomputable does not mean unproved. It marks a definition that is not offered as executable code
through Lean’s ordinary computational evaluation. This component uses noncomputable choices from
finite sets, instances for finite types, determinants, adjugates, and constructions of least exponents.
Their mathematical properties can be proved even though a standalone executable implementation is
not supplied.
The three algorithm rows certify mathematical contracts relating inputs to outputs. They do not certify
the companion Python package, its storage layout, its numerical residuals, or its performance. Even
where a finite enumeration is executable in principle, the contract contains no general complexity esti-
mate or extraction theorem.

5.1 What a refinement witness supplies
A parent map 𝜋∶𝐽→𝐼assigns fine labels to coarse labels. The finite set children parent a is the
fibre 𝜋−1(𝑎). The refinement witness records surjectivity and exact equality of coarse maps with sums
of their fine children.
Source: KomorebiVerification/PaperII/NestedRefinement.lean.
structure Refines
(coarse : LinearProjectorFamily R M ι)
(fine : LinearProjectorFamily R M κ)
(parent : κ →ι) : Prop where
surjective : Function.Surjective parent
coarse_eq_sum_children :
∀a, coarse.proj a = ∑b ∈children parent a, fine.proj b
The structure does not construct a parent map between arbitrary families. To apply its theorems, a
caller supplies a map and proves these two fields. The resulting absorption identities are genuine
consequences. If 𝜋(𝑗) = 𝑖, then
𝑃𝑖𝑄𝑗= 𝑄𝑗= 𝑄𝑗𝑃𝑖;
if 𝜋(𝑗) ≠𝑖, both products vanish. Expand 𝑃𝑖as the sum of its children, distribute composition, and use
orthogonality of the fine family. Transitivity follows by applying this reasoning through two successive
parent maps.

9.2 What the formal lattice means
The lattice parameter is an AddSubgroup M. Preservation by a map means that each member is sent back
into this additive subgroup. A general valuation ring, finite generation, full rank, completeness, and a
chosen basis are not built into its type.
A clearing certificate at exponent 𝑠states that 𝜋𝑠𝐸preserves the lattice. The source names this Is

upward closed. Given existence of some clearing exponent, Nat.find defines a least one and proves its
minimality property. This is a noncomputable construction of a least witness, not a search algorithm
over matrix entries.
If 𝑟= 𝑢𝜋𝑠, then

C Source excerpts and reproduction inventory
Every printed Lean listing comes from an exact UTF-8 excerpt in excerpts/*.lean.txt. The adjacent
*.render.txt file escapes TeX control characters and substitutes a math font glyph where the code font
lacks one. It preserves token order. Exact source text, not the display fallback, is the object to copy into
an editor. Excerpts retain their surrounding source context only when that context is printed. They
are not standalone Lean files. generated/excerpts.json records each source path, inclusive source
line range, the SHA-256 digests of each full source file, exact excerpt, and display file. generated/theo
rem_map.json contains all 25 rows with fully qualified targets, classifications, scopes, boundaries, and
lexical source locations. generated/mapped_source_index.json provides an alphabetical target index.
generated/static_identity_audit.json records all manifest comparisons and the optional baseline
comparison performed for this edition.
build_guide_data.py uses only the Python standard library. It generates the map, import table, pins,
excerpts, and current static audit without invoking Lean. build_guide.sh calls that generator and runs
XeLaTeX four times. The bundled P052, Nimbus Sans, DejaVu Sans Mono, and Latin Modern Math
fonts provide the typography for this edition. The required LaTeX packages are listed in the preamble.
The independent PDF check script uses PyMuPDF and Pillow for page rendering and contact sheets.
The historical source snapshot remains preserved. Current additions live in the separate current project
and are indexed in the current correspondence. Editing this guide cannot by itself repair or strengthen
a Lean theorem. A mathematical change to the formal component requires a separate source change, a
new compile, an updated map when appropriate, and new execution evidence.
