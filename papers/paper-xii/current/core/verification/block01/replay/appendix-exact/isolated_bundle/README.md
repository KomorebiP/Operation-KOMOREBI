# Paper XII — complete source bundle with visual appendix

Open **START_HERE.md** for the directory map, authority of the proof records,
and build commands. Read **pdfs/Paper_XII_With_Visual_Appendix.pdf** for the
54-page combined edition.

This package includes both editable LaTeX trees, all current production Lean
sources and replay evidence, Python figure generators and exact-example checks,
TikZ/vector figures, bibliography, PDFs, and historical source records.
The compiler, Mathlib cache, TeX distribution, installed Python dependencies,
and font files are not included.

Check this extraction with:

```text
python Run-PaperXII.py verify
```

The new bundle integrity check is separate from the inherited Lean certificates.
