# Source preservation ledger

Raw original and authoritative revised mathematical sources are preserved verbatim in `source_preserved/original/` and `source_preserved/revised/`. Saved formal release evidence is preserved verbatim in `source_preserved/evidence/`. The final manuscript is a separately named edition; no raw source was overwritten. The complete imported historical package remains preserved with the companion collection.

The exact eighteen supplied vector figures are copied without alteration to `figures/`. Their figure labels, layouts, and PDF bytes match the authoritative release. Source data and raw generator packages remain in the preserved imported archive. No generative-image system was used.

The final manuscript contains all 52 original revised proof environments, with 50 proof bodies byte-for-byte identical. The two changed proof bodies contain the documented local structural-map clarification (Proposition 3.3) and the added `r>n` Fitting boundary case (Theorem 6.4). All 106 LaTeX labels remain in the same sequence. No proof was shortened or replaced by a summary.
