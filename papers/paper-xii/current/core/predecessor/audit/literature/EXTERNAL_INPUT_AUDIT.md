# Paper XII: bounded external-input audit

Checked 2026-10-06 against the immutable v0.17.1 bundle's formal-release TeX (`Paper_XII_Revised_Formalization_Complete_v0.17.0.tex`) and bibliography. This report checks the external contracts actually used in the support-to-realization spine. It is not an audit of every cited paper, every arithmetic theorem, or novelty. No raw manuscript or author file was edited by this audit.

The exact identification used by the manuscript is supported: continuous finite-dimensional semisimple representations over the original Hausdorff characteristic-zero coefficient field are identified by common Frobenius polynomials on a dense union of conjugacy classes. The source statement for identification over the original field is Gee, Fact 2.5. The density-to-topology passage and the extension by continuity are separate deductions. They do not require a special valuation or a locally compact coefficient field.

Two declaration repairs were sent to the authors: the initial global setup should explicitly make `S` finite, and the realization input should fix a common Frobenius/Hecke normalization. The ordinary completion datum must retain the common-polynomial comparison for the universal specialization as well as the attached representation; the claim auditor independently identified this dependency. The conditional conclusions remain conditional on arithmetic inputs supplied at the actual eigensystem.

## Exact identification contract and translation

Let `F` be a number field and `S` a finite set of places. Let `D` be a density-zero set of finite places of `F` (using natural or Dirichlet density). Remove the finite ramification and other declared bad-place sets. In every finite Galois quotient, every conjugacy class retains a test prime outside `D`. Open cosets form a basis of the profinite topology, so the union of the corresponding entire Frobenius conjugacy classes is dense. A set containing merely one arbitrarily chosen lift from each conjugacy class need not itself be the dense set being used.

For continuous `ρ₁,ρ₂:G_{F,S}→GL_n(E')`, characteristic-polynomial coefficients are finite polynomial expressions in matrix entries. Continuous ring operations therefore make them continuous functions to `E'`. They are conjugacy invariant. If `E'` is Hausdorff, their equalizer is closed, so agreement on that dense union extends to every group element. Original-field identification gives an `E'`-linear isomorphism of the semisimple representations. This paragraph is the explicit project deduction from the checked source statements, not a claim that either states the arbitrary-Hausdorff composite verbatim.

The notation dictionary is `F` ↔ the sources' base number field `K`/`F`; `E'` ↔ Gee's coefficient field `L`; `P_v` ↔ BLGGT's monic `Q_v` after the specified coefficient embedding; `ρ^{ss}` ↔ the Jordan–Hölder semisimplification over that same coefficient field. The quotient representations are inflated along the continuous surjection `G_F→G_{F,S}` before applying the stated Galois source result. For the perfect-support comparison, manuscript `C` ↔ Stacks `K`, and `κ(𝔭)` has exactly the same residue-field meaning. No variance, grading shift, twist or coefficient extension is silently inserted.

The strongest safe contract when density has not been verified is to **supply a dense union of Frobenius conjugacy classes** directly. When the general algebraic Brauer–Nesbitt leaf has not been independently audited in a particular formal environment, supply the exact original-field identification theorem, together with a semisimple representative preserving every characteristic polynomial. These are the contracts the conditional realization arguments actually need.

## Search boundary, unavailable material and editorial recommendations

Initial discovery searched the authorized bundle for cache/literature files and read the dependent manuscript statements before external searches. Web discovery used both search systems, with queries covering arbitrary-field Brauer–Nesbitt, finite-quotient Chebotarev, adequate-image definitions, perfect residue-field support and Artin localization products. Verification used only official publisher/arXiv, author-hosted primary papers and official Stacks statements; search snippets, encyclopedias and forum answers were discovery aids only. Backward references checked were Gee → Curtis–Reiner and Miagkov–Thorne → Thorne/GHT. No forward-citation survey or novelty investigation was attempted.

JSTOR exposed metadata but no usable text for the 1941 Brauer–Nesbitt article. The AMS Schlessinger PDF request returned 403; the underlying primary proof was not filled from discovery snippets. Neukirch and the older commutative/homological algebra books were not acquired in full. These are access and citation-pagination limitations, not counterexamples to the standard results. Authentication of the alternative source statements does not certify the unread books' exact variants.

Recommended narrow citations/declarations: use Gee (2022), Fact 2.5, p.75 for original-field identification; add the author-hosted Chebotarev source or inspect Neukirch VII §13, Theorem 13.4; use stable Stacks tags for the Artin and perfect-support leaves if precise accessible locators are desired; state finite `S`, common geometric Frobenius convention, and realization-theorem normalization. Preserve every arithmetic gate as a separately supplied, instance-specific contract. No source located in this bounded check validates unrestricted automorphy, universal companions, universal full patched support, or a uniform coefficient-two replacement for the arithmetic hypotheses.
