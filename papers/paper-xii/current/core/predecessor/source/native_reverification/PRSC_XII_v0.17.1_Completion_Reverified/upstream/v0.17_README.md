## Reproduce the full cumulative check

Use the pinned Linux portable kit, Lean 4.34.0-rc2 and Mathlib commit
`aeb72f1e9981b6d35b426b16dca7759be3e7ba06`:

```bash
bash Run-Portable.sh /path/to/Komorebi_Portable_Lean_4.34.0-rc2
```

The command starts from an empty project object directory and checks every registered
source. It does not install or rebuild Mathlib. Native Windows execution was not tested;
the supplied kit and launcher are Linux/WSL-oriented. The kit is separate from this ZIP.
A bounded invocation is `python3 checks/verify.py KIT --start --batch 4`, followed by
`--resume --batch 4` until the report says PASS. RUNNING is not PASS.

The optional `checks/replay_completed_tensor.py` performs a second clean build of the
16-module completion dependency closure from an extracted archive. Its result is
separate from, and must not be substituted for, the full cumulative certificate.
