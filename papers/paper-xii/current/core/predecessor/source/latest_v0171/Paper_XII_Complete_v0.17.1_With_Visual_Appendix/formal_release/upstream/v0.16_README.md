## Mathematical contract

For a commutative ring R and a finite presentation

    R^b --A--> R^a --> M --> 0,

`minorIdeal A k` is the ideal generated by actual size-k determinants. The empty
minor is one. The presentation ideal is `I_(max(a-j,0))(A)` for j a natural number.
The upper-index normalization is proved explicitly, not inferred by incorrect natural subtraction.

The development proves:

1. Coefficient maps preserve minor ideals. Multiplication by a matrix gives the
   appropriate containment; actual inverse matrices give equality.
2. Redundant relation columns and adding any finite identity block preserve the
   presentation ideal.
3. Any two finite presentations of the same module give the same ideals. Their
   free covers are lifted to a common generating family; the augmented relation
   matrices are proved to have the same actual kernel. Presentation independence
   is a theorem, not an input field.
4. `fittingIdeal R M j` is defined using a chosen finite presentation and then
   proved to equal the ideal of every finite presentation. Actual module
   isomorphisms preserve it.
5. Tensor right exactness constructs the base-changed presentation, whose matrix
   is obtained by applying the coefficient map. Thus

       Fitt_j^S(S tensor_R M) = map(R -> S, Fitt_j^R(M)).

   No flatness, injectivity, or Noetherianity of the coefficient map is assumed.
6. Over a field, the intrinsic ideal is zero below the actual vector-space
   dimension and the unit ideal at or above it. Consequently

       Fitt_j(M) <= p  iff  j < dim_kappa(p)(kappa(p) tensor_R M).

   This proves support and every higher stratum, including indices beyond the
   number of generators. The higher-stratum statement requires r >= 1.
7. For an existing S-module and a surjective map R -> S, the canonical scalar
   tensor map `S tensor_R M -> M` is proved to be an equivalence. Under a ring
   isomorphism, this composes with the retained spectrum/support theorem to give
   the full Claim 7.1. The manuscript-facing wrapper derives finite presentations
   from the original finite-module and Noetherian hypotheses.

The formalization uses the left tensor carrier `S tensor_R M` (and
`kappa(p) tensor_R M`) for base change. This is the conventional canonically
symmetric version of the manuscript's displayed `M tensor_R S` notation.

The intrinsic API is defined for finitely presented modules. This release does
not extend its definition to arbitrary finitely generated modules over arbitrary
non-Noetherian rings. That extension is unnecessary for these manuscript claims.

## Verification

Run from the extracted folder:

    bash Run-Portable.sh /path/to/Komorebi_Portable_Lean_4.34.0-rc2

or:

    python3 checks/verify.py /path/to/Komorebi_Portable_Lean_4.34.0-rc2

The verifier checks the pinned Lean 4.34.0-rc2 executable and Mathlib commit
`aeb72f1e9981b6d35b426b16dca7759be3e7ba06`, deletes the continuation build directory,
and compiles every manifest module with one Lean thread and warnings as errors.
It enforces a timeout with process-group cleanup and writes a fail-closed status record.

The replay scope is **10 new modules plus 3 unchanged predecessor support modules**.
It is **not** a rebuild of every old Paper XII module or all of Mathlib. The
upstream snapshot retains all 71 original production sources byte-for-byte.
`UPSTREAM_PRESERVATION.json` records the parent archive hash and exact source hashes.

`verification.json` records the actual fresh build, source and output hashes,
per-declaration transitive axiom audit, and three deliberately invalid controls.
Only `propext`, `Classical.choice`, and `Quot.sound` are allowed. The one private
helper is covered transitively by its exported consumers and is not counted as
an additional public theorem.

The production source scan excludes `sorry`, `admit`, custom `axiom`,
`native_decide`, and `unsafe`. Deliberately invalid control files live only in
`checks/`, outside production. Boundary checks include zero/free modules, upper
index normalization, and one-by-one relation matrices. No finite numerical
experiment is being used as a substitute for the universal proofs.

## Boundaries preserved

No proof of universal residual occupancy, unrestricted companion existence,
unrestricted automorphy, or global Langlands is added. All arithmetic inputs
and all eight earlier manuscript amendments remain explicit. No PDF was
retypeset, and the retained manuscript sources are not labeled a fresh editorial release.

This is a new checked formalization block for this project, not a mathematical
novelty claim. The underlying Fitting theory is classical; see the Stacks Project,
Section 15.8, tag 07Z6, especially Lemmas 15.8.2, 15.8.4 and 15.8.7:
https://stacks.math.columbia.edu/tag/07Z6
