INTERPRETATION
The Fraction models fix column-stochastic transitions, departure-state
Feynman-Kac weights, weighted conditional expectation, a mesh quadrature factor
for Green kernels, and a nonzero Jordan direction in rational functional calculus.
They test explicit finite examples. Numerical quadratures and exponential
approximations use the original tolerances, not certified interval bounds.
A finite successful test does not establish a continuum limit, an improper
integral identity for all parameters, arbitrary holomorphic naturality, or an
unrestricted existence theorem. Those conclusions require the prose and formal
arguments with their actual hypotheses.
