\subsection{Column conservation}
\code{MarkovSemigroup} proves nonnegativity of the actual matrix exponential by shifting a Metzler generator by a scalar identity, expanding a nonnegative matrix exponential, and then undoing the scalar shift. Conservation follows from zero column sums of the generator. The final probability statement combines these two independent facts.

\subsection{Weighted projection on observables}
For a partition map $f:I\to A$, \code{Coarsening.coarsen} sums probability mass over fibers. In contrast, \code{ConditionalExpectation.expect} returns a function on the original fine space. It averages an observable within each fiber with respect to finite weights $p_i$. Strict positivity guarantees that the occupied fiber denominator at each fine point is nonzero.
\excerpt{ConditionalExpectation}{conditional}
The source also proves that the range is exactly the block-constant functions and that the expectation equals a literal kernel matrix applied to the observable. Self-adjointness is with respect to the weighted inner product, not ordinarily the unweighted Euclidean inner product:
\excerpt{ConditionalExpectation}{self_adjoint}
The displayed self-adjoint identity is algebraic and its signature has no positivity premise. Calling the pairing a positive-definite inner product, or deriving range separation from it, uses the strict positivity hypotheses elsewhere in the module. Reuse the endpoint matching the intended claim rather than adding an interpretation that its type does not supply.
