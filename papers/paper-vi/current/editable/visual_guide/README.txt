The guide contains 42 worked and reference pages after its cover and route page.
All 587 mathematical spans in the two body-source files remain byte-identical
against the immediately preceding corrected edition. Every one of the 40 vector
plate files was regenerated from the supplied Python sources and matched its
shipped TeX bytes. The local figure renderer increases fraction-row spacing
for legible matrix labels under Unicode mathematics. Models, labels and plate
geometry are unchanged.

Build the PDF offline with Python 3 and XeLaTeX:
  python3 build.py
  python3 build.py --output-directory /absolute/path/to/output
  python3 build.py --check-only

The builder copies the authored source tree into an isolated temporary
directory. It uses installed URW P052 and Nimbus Sans, and Latin Modern mono
and math fonts; the Lean guide additionally uses DejaVu Sans Mono. Font files
are resolved locally with kpsewhich and standard system locations and copied
only into the private build stage. No font binaries are bundled or downloaded.
The builder compiles in four passes and rejects overfull boxes, missing
characters and unresolved references.
The build uses supplied geometry and does not require symbolic regeneration.
No network calls are made. SOURCE_DATE_EPOCH fixes the edition timestamp.

Review and navigation:
  python3 review_pdf.py
  python3 -B checks/verify_preservation.py
  python3 make_crosswalk.py --traditional-map /path/to/canonical_label_to_final.json

review_pdf.py requires PyMuPDF and Pillow. It renders every page and checks
text bounds, vector-only figures, internal destinations and TeX warnings.
PDF_QA.json records mechanical checks. VISUAL_REVIEW.txt records manual visual
inspection separately. The crosswalk reads actual PDF labels and bookmarks,
then resolves each declared result or section target after pagination freezes.
Reading targets do not imply identical formal scope.
