# Annals submission checklist

## Required article items

1. English manuscript: complete
2. PDF manuscript: complete
3. Self contained abstract below about 200 words: complete at 183 words
4. Complete bibliography: complete
5. Every bibliography entry cited: complete
6. BibTeX database: included
7. Publication quality figures: complete
8. Vector figure sources: included
9. Figure captions and numbering: complete
10. No forced page breaks: confirmed
11. No forced prose line breaks: confirmed
12. Language model contribution disclosure: included

## Source package

1. LaTeX source included
2. BibTeX source included
3. Fourteen vector PDF figures included
4. Figure generation script included
5. Verification code included
6. Verification summary included
7. Mathematical audit records included
8. Original Paper X release preserved under `legacy`
9. SHA 256 manifest included

## Remaining author responsibilities

1. Complete an independent line by line proof review.
2. Obtain specialist review of the deformation and compatible system statements.
3. Complete a literature and historical priority review.
4. Decide whether to add a correspondence address and email.
5. Confirm the journal language model policy at the time of submission.
6. Submit the PDF attachment or an arXiv identifier through the Annals office.
