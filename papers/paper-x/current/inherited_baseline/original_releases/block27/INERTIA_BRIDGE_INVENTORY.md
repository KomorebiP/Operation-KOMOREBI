# Block 26: actual valuation inertia and Frobenius recognition

The new `lean/PaperX/CyclotomicInertiaBridge.lean` proves an arithmetic local
restriction result for the actual absolute Galois group of Q and the actual
residue-action definition of valuation inertia. It does not define inertia as
a preimage of a finite quotient subgroup.

## Proved interface

Let L/Q be a cyclotomic number field generated by n-th roots of unity, with
n > 0. Write Qbar for Mathlib's `AlgebraicClosure ℚ`, and let A be any valuation
subring of Qbar. Mathlib defines `A.decompositionSubgroup ℚ` as the stabilizer
of A in `Gal(Qbar/ℚ)`, and `A.inertiaSubgroup ℚ` as the kernel of its action on
`IsLocalRing.ResidueField A`.

For a rational prime p, assume that this actual residue field has
characteristic p and that p is coprime to n. Then the new module proves:

1. n is a unit of A; this is derived from coprimality.
2. Every actual inertia element restricts to the identity on L.
3. Every representation of Gal(L/Q), pulled back along the actual restriction
   homomorphism, is trivial on that actual inertia subgroup.
4. If a supplied decomposition-group element acts by x -> x^p on the residue
   field, its restriction is exactly Block 25's `primePowerAutomorphism n L p`.
5. The entire pulled-back linear action, and hence its trace, agrees with the
   finite cyclotomic action at such a supplied arithmetic Frobenius element.

The root order n is not asserted to be the minimal conductor. The convention
is arithmetic p-power Frobenius, not inverse Frobenius.

## Proof of the key injectivity statement

For a local domain R, if n is a unit and x^n = y^n = 1, roots having identical
residues are equal. Put

    s = sum_{i=0}^{n-1} x^i y^(n-1-i).

Then s(x-y) = 0. Its residue is n times residue(y)^(n-1), which is nonzero.
Thus s is nonzero, and the domain condition gives x=y. Roots of unity lie in
any valuation subring: if x does not already belong to the ring, x inverse
does, and its (n-1)-st power is x. Inertia fixes residues, so this injectivity
proves it fixes every n-th root. The cyclotomic generator then proves equality
of the restricted field automorphisms.

This uses neither a supplied equality of Galois characters nor a replacement
of local arithmetic invariants by labels.

## Boundary and controls

The unit condition cannot simply be removed. The module proves in the actual
characteristic-zero DVR `PadicInt 2` that 1 and -1 are distinct square roots of
1 with the same residue. It also proves that 2 is not a unit. The last concrete
ZMod 2 equality is proved by kernel-checked `decide`; no `native_decide` is used.

`checks/PositiveCyclotomicInertia.lean` checks the general root-injectivity and
inertia interfaces, and both parts of this concrete boundary.
`checks/FalseResidueRootsWithoutUnit.lean` reduces the proposed root-injectivity
statement without the unit condition to an unsolved `False`, using the proved
Z2 counterexample.

  `Ideal.Quotient.stabilizerHom_surjective_of_profinite`.
- `NumberTheory/RamificationInertia/Galois.lean`: finite inertia cardinality
  equals the ramification index.

The finite-kernel ideal-stabilizer lifting theorem does not directly apply to
an infinite absolute-Galois restriction kernel. The profinite residue
surjectivity theorem is a viable separate route, but applying it requires
constructing the integral-closure ring action with its discrete continuity and
invariant-ring instances. Relating an ideal stabilizer to a chosen valuation
stabilizer is another comparison obligation.

This module supplies A and its actual residue characteristic. It does not
construct such A, or construct a decomposition element realizing p-power
Frobenius on the entire absolute residue field. It proves the restriction and
representation comparisons for these genuine local objects when supplied.
The chosen global lifts in `CyclotomicAbsoluteSamples.lean` are not thereby
proved to be absolute decomposition-group elements.
