# Frobenius coverage inventory — Block 25 planning

**Verdict: incomplete, with the smallest missing implication.** The available files do not prove that every conjugacy class in every finite Galois quotient is represented by a permitted arithmetic Frobenius class. They do contain an actionable restricted route for cyclotomic extensions, using the checked Dirichlet theorem on primes in residue classes.

## Exact target

Source Claim 9.1 is `Finite Frobenius separation` in the Block 24 amended manuscript. It quantifies over pairwise nonisomorphic strictly compatible systems with absolutely irreducible members and common number-field-valued traces. It concludes the existence of exactly r distinct permitted unramified places with nonsingular trace matrix. Ordinary representation trace comparisons exclude places over the coefficient characteristic.

The source proof uses both arithmetic Frobenius density and the implication from nonisomorphic systems to nonisomorphic members at a fixed coefficient prime. Neither can be inserted as a generic assumption and then advertised as the full arithmetic claim proved.

The checked topological input is `PaperX.ProfiniteSeparation.QuotientCoverage s`:

```
∀ (H : OpenNormalSubgroup G) (g : G),
  ∃ x k, g⁻¹ * (k * s x * k⁻¹) ∈ H
```

For G the actual absolute Galois group, the absent arithmetic implication is: for every finite Galois extension cut out by H, every conjugacy class in its Galois group, and every fixed finite forbidden set of primes, there is a prime outside the forbidden set, unramified in the extension, whose Frobenius class is that class. A Frobenius lift and finite-level compatibility must be attached to actual arithmetic ideals and their residue actions. The proof only needs this existence consequence, not a density value, but this is still a substantial arithmetic theorem.

## Restricted constructive route already supported by Mathlib

1. `Nat.infinite_setOfPred_prime_and_eq_mod` and `Nat.forall_exists_prime_gt_and_eq_mod` in `NumberTheory/LSeries/PrimesInAP.lean` prove actual prime existence in every unit residue class modulo n, for n ≠ 0. Choosing a prime larger than every member of any finite forbidden set removes that set. The unit residue condition itself proves p is coprime to n.
2. `IsCyclotomicExtension.Rat.galEquivZMod n K` is an actual multiplicative equivalence `Gal(K/ℚ) ≃* (ZMod n)ˣ` for a cyclotomic number field K. Its inverse gives a canonical automorphism for a prime residue. Thus actual prime residue coverage gives surjectivity onto this actual finite Galois group.
3. `galEquivZMod_apply_of_pow_eq` / `galEquivZMod_smul_of_pow_eq` identify its power action on roots of unity.
4. `galEquivZMod_stabilizer` identifies the image of the decomposition group above a prime p coprime to n with the cyclic subgroup generated by [p]. This supports membership of the chosen automorphism in that actual decomposition group, but equality of generated subgroups alone does not identify the specific arithmetic Frobenius generator.
5. A precise residue-action bridge can plausibly be proved by either lifting the p-power residue automorphism with `stabilizerHom_surjective` and identifying its root-of-unity exponent, or proving equality of the quotient maps on the integral generator. `IsCyclotomicExtension.Rat.adjoin_singleton_eq_top` in `Cyclotomic/Basic.lean` proves ℤ[ζ] is the full ring of integers for general n. These are proposed new proofs, not inventory results.
6. Once that bridge is checked, representations factoring through the specified cyclotomic extension have an actual arithmetic sampling theorem without a coverage assumption. This does not cover arbitrary finite Galois quotients or arbitrary compatible systems.
