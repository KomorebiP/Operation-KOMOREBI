# Exact norm filters with the torsion multiplicity retained

`IdealNormFilterAttachment.lean` is frozen and compiled successfully with
`-DwarningAsError=true`. It adds five theorems and two equivalence definitions.

## Actual arithmetic equivalence

For a fixed actual nonzero integral ideal `J`, the file constructs

\[
\operatorname{idealSet}(K,J)\;\simeq\;
\{L\ne0:J\mid L,\ L\text{ principal}\}\times\mu(K).
\]

Here `idealSet` is Mathlib's actual fundamental cone intersected with the actual
ideal lattice, and `μ(K)` is its roots-of-unity group. The first projection is
exactly the principal ideal generated by the represented integral element. A
separate proved identity identifies its ideal absolute norm with the actual
mixed-embedding norm of the generator.

For an arbitrary predicate `P : ℝ → Prop`, the equivalence restricts to points
satisfying `P(norm a)`. The restriction affects only the principal-ideal
coordinate and retains the entire torsion coordinate. It therefore proves the
exact roots-of-unity factor for every such norm filter.

## Bounded class-filter identity

If `[J]=C⁻¹`, multiplication by `J` identifies ideals of class `C` with principal
ideals divisible by `J`. Its norm identity changes `P(NL)` into `P(NI·NJ)`.
Positivity of `NJ` then cancels it from the bound `NI·NJ ≤ X·NJ`, for every real
`X`. The final theorem is

\[
\#\{a\in\operatorname{idealSet}(K,J): |Na|\le XNJ,\ P(|Na|)\}
=|\mu(K)|\,
\#\{0\ne I\subseteq\mathcal O_K: NI\le X,\ [I]=C,\ P(NI\cdot NJ)\}.
\]

The Lean statement uses `Nat.card` and places the torsion factor on the right;
commutativity gives the displayed formula. The unrestricted predicate theorem
also holds without assuming finiteness, as a cardinality identity induced by an
actual equivalence. The bounded application concerns actual bounded ideal sets.

## Scope

This is an exact arithmetic attachment, not a congruence equidistribution theorem.
Norm-residue filters can be substituted into `P`; their geometric counting must
still be established separately.

The full torsion factor is preserved for predicates of **absolute** norm. A
single sign chamber for the algebraic norm need not be preserved by every root
of unity: multiplication by `-1` switches the sign in odd degree. A later signed
residue argument must recombine the sign chambers before using this full-torsion
identity, or account separately for the sign stabilizer.
