The new norm-filter attachment uses an explicit norm-preserving equivalence,
not a cardinality argument that loses the fiber information.

For each fixed integral nonzero ideal J:

  idealSet(K,J) ≃ {L : nonzero integral ideals | J divides L and L principal} × μ(K).

The first projection is exactly the principal ideal generated by the represented
integral element. Its ideal norm equals the mixed-space absolute norm. Therefore
an arbitrary predicate P on real absolute norms restricts only the first
coordinate, leaving μ(K), the roots of unity, intact.

Multiplication by J is then restricted to ideals of class C, where [J]=C^-1.
Under that bijection, P(NL) becomes P(NI*NJ). Positivity of NJ changes
NI*NJ ≤ X*NJ into NI ≤ X at every real X. This gives the exact torsion-factor
identity for actual norm-filtered class counts.

This is an exact attachment, not an equidistribution theorem. Applying it to
congruences still requires the congruence-cell counting argument, and translating
absolute norms to a polynomial residue requires the signed-norm partition.
