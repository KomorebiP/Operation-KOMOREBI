# Paper I contract extension, Block 03

The frozen 35-row normative map is preserved verbatim under `predecessor/baseline/source/main`. Its historical exclusions describe that original component, not the expanded theorem closure. This delta records what has subsequently been added without rewriting the predecessor.

## Row 13: single-operator seed rank

The original row verifies a seed number from supplied primary/extraction/quotient certificates. Block 03 now proves the primary-block-count version for every finite-dimensional operator over an arbitrary field from the actual polynomial action. It constructs a positive primary presentation, supplies CRT generators, proves residue-field lower bounds and derives both canonical seed ranks. The public theorem does not require a caller-supplied decomposition or seed equality.

The expanded publication additionally defines each multiplicity as the intrinsic quotient dimension `dim_{k[t]/(p)}(X_p/p(T)X_p)`. That identification remains to be formalized. Consequently the complete publication record for the general theorem is still partial, although the previously missing arbitrary-field primary-block construction is now proved.

The separate invariant-factor-count corollary is fully mapped at its stated conditional scope. Its displayed nonconstant divisibility-chain presentation is the input. The resulting count is proved using a common residue-field quotient and coordinate generators.

## Row 14: cyclic criterion

Block 02 proved cyclicity equivalent to equality of the minimal and characteristic polynomials. Block 03 adds that every actual positive primary presentation is cyclic exactly when no two blocks have the same irreducible principal-ideal label. These are theorems, not assumptions stored in a certificate record.

The full six-way expanded-publication criterion still contains the intrinsic-primary and scalar-extension/geometric clauses. They are not marked complete merely because an equivalent primary-block characterization is available informally.
