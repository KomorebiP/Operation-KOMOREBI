# Available Paper IX manuscripts

The `baseline/` directory exposes every PDF and TeX file from the preserved original completion archive, unchanged. The main manuscript is `baseline/paper/Projector_Resolved_Seed_Calculus_IX_Status_Corrected.pdf`; its accompanying completion and Lean-block supplements are under `baseline/docs/`.

These are historical manuscript versions. They have not been rewritten to incorporate all subsequent sharp towers, exact periods, isometries and polynomial lifting results. Read the root `REMAINING_CHECKLIST.md` for current status and the continuation reports linked from the root README for later results.

The reconstructed Annals text is `../strengthening/recovery/PSC_Paper_IX_Local_Polyphase_Annals_Edition.retrieved.tex`. Two other older edge manuscripts are available only as the recovered partial source windows in `../historical/recovered_source_windows/`; this package does not supply their complete original manuscripts.

`EXTRACTION_MANIFEST.json` records the exact source entries and hashes. The original baseline ZIP is retained for full source, script and audit provenance. The external Nishibuchi paper is referenced in the source record rather than redistributed.
