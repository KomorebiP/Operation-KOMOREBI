# Changelog

## 1.16.0 - 2026-08-31

### Added

- Holonomy-Twisted Universal Lane Transport Theorem for finite connected chart
  groupoids with coherent address and splitting cocycles.
- Exact identification of descended morphisms with compatible sections of a
  matrix local system.
- Base-fiber invariant normal form identifying global sections with matrices
  fixed by the loop group at one chart.
- Monodromy-orbit theorem giving the finest ordinary globally labeled
  projector-sum coarsening.
- Simultaneous source-target pair-orbit selectors and exact residuals.
- Permutation-module orbital lane calculus, including an exact intertwiner
  basis and nonnegative integer path-count structure constants.
- Rational cyclotomic orbit projectors expressed through Ramanujan sums.
- A self-contained seven-page theorem note.
- Deterministic 1,344,823-assertion Block 16 verifier and 85-check publication
  audit.

### Changed

- The integrated foundations manuscript is now version 1.16.0 and 239 pages.
- Repository build, CI, packaging, citation, theorem-map, review, and release
  files now target Block 16.
- The previous trivial-address-holonomy boundary is sharpened: trivial
  holonomy is necessary for globally fixed individual labels, but not for the
  exact transport calculus.

### Clarified

- Object-address orbits and source-target pair orbits encode different data.
- Orbit descent does not identify cyclic character projectors with
  coefficient-residue projectors.
- The factorial step-product remains a multiplicative companion rather than an
  additive idempotent splitting.
- Exact finite verification is not independent peer review or a historical
  novelty determination.
