SCOPED COMPUTATION REVIEW

Code inspection preceded execution. Original README instructions, the main
VERIFY_PAPER.py gates, verification/verify.py, all three standard-library test
families, the companion run_all.py and numerical models, the Annals checker,
and the visual appendix dependency declarations were inspected. No commands
were inferred from untrusted output. Original code was not edited.

The strongest finite exact cross-check is tree enumeration: the recursive
complete-pruning generator is compared against an independently implemented
path-incidence predicate on every node subset of every ordered rooted tree
topology with one through eight nodes. The run covers 626 topologies, 129,958
subsets and 3,467 admissible prunings, with 3,130 seeded rational objectives.
It also exhausts 471 small integer objectives. These are finite bounds, not a
claim about all trees. Singleton and tie behavior are checked separately.

Signed polyphase/FIR checks include negative indices and very large integers.
Direct convolution is compared with channel convolution. Reverse channel
roundtrips start with independently generated channels. Sample-delay group laws
and the distinction between original-sample delay and channel-index delay are
tested explicitly. Exact Haar checks use Q(sqrt(2)), avoiding a floating square
root in the exact suite. Matrix actions are checked on basis vectors, and Smith
projective checks include a pole example.

The 16 verifier tests include a clean positive case, incomplete and unknown
scope targets, corrupted baseline, changed/missing/extra source, resealed proof
placeholders, incomplete imports/targets/audit lists, wrong dependency pins,
comment/string scanner boundaries, optimized Python behavior, and subprocess
failure/timeout logs. Several tests contain more than one assertion, and the
reported 16 is a test-method count, not an invalid-case count.

The numerical runner uses a fixed NumPy seed and explicit finite signal/grid
sizes. The historical dictionary key 'exact_certificates' contains floating
residuals. We preserve that historical spelling but do not relabel those values
as exact arithmetic. Comparing all 52 float metrics also verifies object keys,
array lengths and every nonfloating discrete leaf. The fresh dictionary equals
the recorded dictionary exactly in this environment, beyond the tolerance gate.

The Annals checker includes 10,001 sampled half-shift positions, quadrature
approximations, seeded matrix tests, direct finite identities and source-format
checks. Its pass count is dominated by sampled half-shift positions. Some
illustrative trace-jump checks merely confirm the declared coefficient values.
This suite does not by itself establish trace regularity, general recovery,
operator-domain hypotheses or any universal theorem. Those need proof review.

All five original checksum manifests were checked directly. The ZIP archives
were also opened and compared member-by-member to each extracted tree, so a
missing unlisted source file could not silently pass a partial manifest.

No scientific computation failed. The only post-run metadata omission found
was the figure generator's additional NumPy seed 31 in the human-written seed
summary. The exact figure-source file had already been pinned and hashed before
and after execution, and the generated outputs were captured. That omission is
explicitly corrected in ADDITIONAL_RUN_METADATA.json without changing the raw
runner manifest or pretending that another execution occurred.

Residual limits: no fresh Lean compilation, no exhaustive semantic review of
every Lean target, no English-to-Lean equivalence proof, no pytest execution,
no SymPy visual-check replay, no specialist/historical priority certification,
and no inference from finite success to a universal mathematical conclusion.
