PAPER V MONOGRAPH / GUIDE BUILD

python3 build.py copies the full authored tree into a temporary directory. Externally installed
fonts, chapters, generated catalogs and styles are retained. Four XeLaTeX passes
resolve navigation. The final pass rejects missing glyphs and unresolved references.
No formal or numerical verification is inferred from successful typesetting.

Use --output-directory PATH to write products elsewhere, or --check-only to leave
all delivered files unchanged. SOURCE_DATE_EPOCH defaults to 20 October 2026 UTC and
FORCE_SOURCE_DATE=1 requests reproducible timestamps. Full TeX package availability
is required. No network operation is performed by this builder.

Catalog generation is a separate operation. It checks the immutable source contract
and records exact source, transcript, dependency and traditional-map hashes. It does
not substitute a newer Mathlib revision or run Lean.
