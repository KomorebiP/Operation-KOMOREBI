# Annals Submission Checklist

## Required manuscript items

- [x] Manuscript is in English
- [x] PDF is searchable and not encrypted
- [x] Self contained abstract is approximately 200 words or fewer
- [x] Complete bibliography is included
- [x] Every bibliography entry is cited in the article
- [x] Article titles and page ranges are included where applicable
- [x] LaTeX source is included
- [x] BibTeX source is included
- [x] Figures are numbered, captioned, floatable, and supplied as vector PDF files
- [x] Figure generation source is included
- [x] No forced page breaks are present
- [x] No forced prose line breaks are present
- [x] Language model contribution is disclosed in the manuscript
- [x] Manuscript builds with the Annals `aomart` class

## Mathematical and editorial checks

- [x] Every theorem, proposition, lemma, and corollary has a proof
- [x] Classical Gibbs behavior is marked as imported
- [x] Numerical illustrations are not used as proofs
- [x] Universal edge recovery is not claimed
- [x] Fixed noise consistency is not claimed without decreasing effective noise
- [x] Gibbs control is conditioned on packet accuracy
- [x] Higher dimensional geometry is presented through conditional tube estimates
- [x] Internal cross references resolve
- [x] Bibliographic citations resolve
- [x] Clean build matches the release PDF on every page

## Remaining author actions before submission

- [ ] Independently verify every proof and citation
- [ ] Complete a specialist literature and priority review
- [ ] Decide whether the Cayley coordinate section belongs in the submitted article or a companion note
- [ ] Add a correspondence address and email if desired
- [ ] Decide whether Annals of Mathematics is the most appropriate first venue after external mathematical review
- [ ] Prepare the submission email and attach the final PDF or provide an arXiv identifier
