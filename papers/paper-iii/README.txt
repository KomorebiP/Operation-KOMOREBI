REBUILD
Run from any directory, with a TeX Live installation providing pdflatex,
bibtex, xelatex and the required standard packages/fonts:
  python3 scripts/build_pdfs.py --check-only --report /tmp/paper-iii-build.json
This compiles from shipped inputs in temporary directories and compares page
counts and extracted text using PyMuPDF. It does not invoke Lean or rerun
mathematics. Omit --check-only to replace PDFs; refresh metadata/hashes after
any such edit. Each editable companion also has a compile-only build.py.
P052, DejaVu Sans, DejaVu Sans Mono and Latin Modern Math fonts are required
by the Lean guide.
