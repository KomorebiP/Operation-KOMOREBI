## Limits of the successful block
This accepts three named Section 16 proof scopes, one definition, and their actual
coordinate construction. It does not formalize all later jets, trees, analytic
correction, filtered lifting, or convergence statements. The older finite 41-row
contract and expanded manuscript denominators remain distinct.

The same pinned Lean kernel performs replay. Upstream caches are authenticated to
the selected kit and nine revision pins, not independently rebuilt or certified by
another proof assistant. The Windows/WSL launch instructions are supplied but not
tested on the user's Windows machine. Ordinary proof review beyond the selected
Section 16 bridge, external novelty assessment, and a global license selection were
not performed. The existing project license status was not changed.
