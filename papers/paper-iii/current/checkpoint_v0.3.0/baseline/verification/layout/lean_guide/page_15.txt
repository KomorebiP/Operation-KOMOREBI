3.6 The naturality square is a typed equality
Source: KomorebiPaperIII/CoordinateNaturality.lean.
theorem exactCoordinateMap_naturality
{X : Type u} {Y : Type v}
{XA : Type w} {XB : Type x} {YR : Type y} {YS : Type z}
(sourceA : X ≃XA) (sourceB : X ≃XB)
(targetR : Y ≃YR) (targetS : Y ≃YS) (map : X →Y) :
exactCoordinateTransport targetR targetS ∘
exactCoordinateMap sourceA targetR map =
exactCoordinateMap sourceB targetS map ∘
exactCoordinateTransport sourceA sourceB := by
funext value
simp [exactCoordinateTransport, exactCoordinateMap, Function.comp_def]
On the left, represent the map in the first coordinate systems and then change target coordinates.
On the right, change source coordinates first and then use the second representative. Both sides
map XA to YS. Expanding them gives the same function.
This exact set-level statement already applies to a nonlinear function. It does not imply differen-
tiability, a chain rule for jets, or convergence of a formal series. Those stronger properties require
additional structures and additional theorems. The formal contribution here is exact representa-
tion and naturality for arbitrary functions under exact equivalences.
