theorem heterogeneousPacketPathExpansion
[Fintype V] [DecidableEq V] [Semiring R]
(steps : List (Matrix V V R)) (source target : V) :
heterogeneousProduct steps target source =
heterogeneousPathSum steps source target := by
induction steps generalizing source target with
| nil =>
by_cases h : source = target
· subst target
simp [heterogeneousProduct, heterogeneousPathSum]
· have hreverse : target ≠source := fun h' => h h'.symm
simp [heterogeneousProduct, heterogeneousPathSum, hreverse]
| cons step rest ih =>
simp [heterogeneousProduct, heterogeneousPathSum, Matrix.mul_apply, ih]
The induction is on the list of factors. The base case is the matrix identity. The successor case
is exactly the entry formula for matrix multiplication, with the induction hypothesis substituted
into the remaining product. The theorem quantifies over every finite list, but all factors are Matr
ix V V R.
The strengthened ordinary article can discuss a fully dependent chain with a new packet index
type at every stage. That theorem is outside this fixed 41-row Lean contract. Rows 13 and 14 make
the distinction explicit: differing types at lengths two and three, varying factors on one common
type at arbitrary finite length.
3.3 Declared support is a certificate
A SupportedStep stores an operator, a relation on source and target packets, and a proof that an
entry is zero whenever the relation does not hold. The relation need not be the exact nonzero
support; it can be a conservative allowed-support relation. SupportedPath says each successive
step respects the corresponding relation.

theorem heterogeneousPathSum_eq_zero_of_no_supportedPath
[Fintype V] [DecidableEq V] [Semiring R]
(steps : List (SupportedStep (V := V) (R := R))) (source target : V)
(h : ¬ SupportedPath steps source target) :
heterogeneousPathSum (steps.map SupportedStep.operator) source target = 0 := by
induction steps generalizing source target with
| nil =>
have hreverse : target ≠source := fun h' => h h'.symm
simp [heterogeneousPathSum, hreverse]
| cons step rest ih =>
simp only [List.map_cons, heterogeneousPathSum]
apply Finset.sum_eq_zero
intro middle _
by_cases hedge : step.relation source middle
· have hrest : ¬ SupportedPath rest middle target := by
intro hpath
exact h ⟨middle, hedge, hpath⟩
rw [ih middle target hrest]
simp
· rw [step.supported source middle hedge]
simp
