1.3 Notation that carries mathematical content
Lean writes a linear map as M →l[R] N and a linear equivalence as M ≃l[R] N. The latter includes an
inverse and its inverse laws. An arbitrary equivalence is X ≃Y. A function X →Y carries no linear
structure. Replacing one of these types with another changes the claim.
Bracketed arguments such as [Semiring R] are typeclass hypotheses. They supply operations
and laws, not merely notation. Braced arguments such as \{R : Type u\} are implicit parameters
inferred from use. Type u allows the object to live in a universe; different universe names allow
different input, fiber, and coefficient types. autoImplicit false requires undeclared identifiers to
be rejected rather than silently generalized.
Fintype V supplies finite enumeration. DecidableEq V supplies a decision procedure for equality.
Some definitions use classical so that a finite sum can be filtered by a proposition without de-
manding a user-supplied decision procedure. This logical choice does not turn an abstract graph
theorem into an efficient graph algorithm.

1.4 What a short proof is doing
rfl closes a definitional equality: the two sides reduce to the same expression. ext x or Linear
Equiv.ext reduces equality of maps to equality at an arbitrary input. simp uses definitions and
registered simplification rules, including inverse laws and zero laws. rw rewrites by an explicit
equality. induction exposes a finite recursive object, such as a list or tree, and proves the conclusion
from the smaller objects.
