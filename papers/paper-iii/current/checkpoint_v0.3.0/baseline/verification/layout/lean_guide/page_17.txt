4.3 Reversible connections use dependent fibers
The second interface assigns a module 𝐹(𝑎) to each vertex. Pair transport is a linear equivalence
between the actual endpoint modules, and reverse transport is required to be its inverse.
Source: KomorebiPaperIII/ReversibleConnections.lean.
structure ReversibleConnection
(R : Type u) (X : Type v) (F : X →Type w)
[CommRing R] [∀a, AddCommGroup (F a)] [∀a, Module R (F a)] where
transport : ∀a b, F a ≃ₗ[R] F b
transport_self : ∀a, transport a a = LinearEquiv.refl R (F a)
transport_reverse : ∀a b, transport b a = (transport a b).symm
The hypotheses include a commutative ring, additive commutative groups on all fibers, and mod-
ule structures. These permit subtraction of parallel linear maps. The cocycle law is still not a
structural field. Thus reversible connections may have nontrivial triangle holonomy.
