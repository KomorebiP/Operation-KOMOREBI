D Source and reproduction inventory
The preserved formal component has nine Lean files, totaling 1,948 source lines, and sixteen files
including the map, manifest, gate, pins, and documentation. The guide stores 44 exact excerpts.
For each, generated/excerpts.json records the source file, inclusive line range, full-source hash,
exact-excerpt hash, and PDF-display-file hash.
generated/theorem_map.json contains all 41 rows and complete source locations. generated/mapp
ed_source_index.json provides an alphabetical index. generated/inherited_axiom_records.json
records the 143 saved transcript reports. generated/static_audit.json separates current checks
from inherited counts and records the checksums used. The original report and transcript remain
in the preserved finite release.
build.py is a compile-only XeLaTeX builder. build_guide_data.py regenerates static data from
an explicitly supplied preserved release. verify_pdf.py renders the PDF, prepares contact sheets,
and records page-level layout checks. BUILD_NOTES.txt records authoring failures and their repairs,
rather than silently treating failed attempts as successful verification.
The guide uses P052 for body text, DejaVu Sans for headings, DejaVu Sans Mono for code, and
Latin Modern Math for mathematical symbols. Code displays use fvextra, preserving token order.
Display fallbacks are documented separately from the exact UTF-8 source excerpts.
