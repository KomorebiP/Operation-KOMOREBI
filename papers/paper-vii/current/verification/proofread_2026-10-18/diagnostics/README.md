# Intermediate diagnostics

These records document intermediate build/font and layout candidates. Their original statuses, hashes and observations are retained. A successful TeX process did not constitute final visual acceptance: the first delayed-driver candidate had a missing bold A, and subsequent layout candidates were further corrected. Only `../FINAL_PDF_REVIEW.json`, `../PDF_PREFLIGHT.json`, `../PACKAGED_BUILD_REPLAY.json` and the final `../RELEASE_VALIDATION.json` identify the accepted release. Reports that say a float or binder fix was pending describe the historical stage at which they were written. Failed PDF binaries and disposable build stages are not part of the current reading set.

The explicit OpenType mini-test source and PDF are supplied to reproduce the eight-face alphabet check. It requires the same installed font faces described in the font provenance record. No standalone font binaries are included.
