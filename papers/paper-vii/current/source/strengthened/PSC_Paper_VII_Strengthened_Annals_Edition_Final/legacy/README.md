# Projector-Resolved Seed Calculus VII

**Quantum Seed Calculus: Symmetry Packets, Circuits, Effective Dynamics, and Quantum Spacetime**

Author: **Komorebi P.**

This package contains the standalone paper, finite-dimensional Python library, tests, figures, and machine-readable numerical certificates for Paper VII of the series.

The implementation covers quantum seed reachability, cyclic symmetry projectors, tensor refinement, circuit packet paths, leakage bounds, exact Feshbach reduction, moving projector frames, finite quantum channels, exact three-qubit bit-flip error correction, spectral-dimension diagnostics, and a controlled Euclidean volume-transfer toy model.

The continuum quantum-spacetime statements are conjectures. The code does not claim a numerical solution of quantum gravity. The release contains 22 automated tests and 19 code-generated figure pairs.
