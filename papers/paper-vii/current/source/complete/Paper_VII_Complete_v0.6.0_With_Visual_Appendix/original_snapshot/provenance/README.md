# Provenance

The original Paper VII TeX and the earlier Paper VI source inputs are unchanged. Dependency pins remain fixed. Files explicitly named `first_block` or `second_block` are historical snapshots and do not describe the current cumulative count. The current release's ledger, README, verifier, artifact audit and third-block run supersede earlier status totals.

`INPUTS.json` identifies this release's immediate source archive and runtime. `INPUTS_second_block.json` preserves the previous provenance record. `UPSTREAM_PRESERVATION_second_block.json` and `ARTIFACT_CHECK_second_block.json` are historical.
