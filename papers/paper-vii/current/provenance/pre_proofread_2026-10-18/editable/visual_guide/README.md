## Build

Run `python 3 build.py`. XeLaTeX compiles the complete staged source tree in four passes. The builder accepts `--output-directory DIR` to write products elsewhere and `--check-only` to compile without changing delivered files. It does not regenerate prose, models, figures, formal sources, or scientific results. The fonts are bundled; no fonts are loaded through an absolute machine path.
