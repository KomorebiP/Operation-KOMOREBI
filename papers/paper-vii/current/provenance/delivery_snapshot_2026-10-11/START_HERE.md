# Operation Komorebi — paper delivery snapshot, 11 October 2026

This is a retrieval and packaging snapshot, not a new mathematical release or proof audit.
The collection includes the latest core paper editions located in the retrieved Library
entries and the supplementary publication/source sets listed in the manifests. It is not
claimed to exhaust every historical draft or every file ever created for the project.

## Reading and source versions
Use the separately supplied current reading collection for the selected PDFs. Older PDFs
inside source/evidence archives are retained as provenance, not promoted to current editions.
Paper I's outer archive filename says 2026-10-05, but CURRENT_READING_EDITION.txt explicitly
identifies the enclosed current monograph as 2026-10-08. Its 2026-10-10 Block 05 checkpoint
is included separately, not represented as a new prose edition. Papers XI and XII combine
their reader sets and source/evidence sets. Paper XII also includes the delivery receipts.
Paper XI includes the Conjecture 66 progress paper and visual atlas. Packaging does not
change conjectures, conditional results, open obligations, or recorded verification scope.

## What was checked for this delivery
Source archives were read recursively, with ZIP CRC checks, and original/delivery SHA-256
hashes recorded. Bundled standalone font files were removed where found. All other payloads
are retained; an enclosing archive's bytes may change when a nested archive is sanitized.
Embedded typography within PDF documents was not modified. Rebuilding manuscripts may
require configuring fonts installed on your own system. Original source manifests and
receipts are historical records; the delivery manifests explain any changed hashes.

No Lean compilation, Python theorem test suite, or visual proofreading was rerun as part
of this file-delivery task. A packaging timeout was recovered from the saved per-archive
receipts; all selected source packages were subsequently processed.

## Navigation
The reading ZIP includes an offline index.html and a per-PDF provenance manifest.
Source bundles contain original archive basenames plus delivery receipts. The separate
index contains all source hashes, included file versions, bundle membership, and checksums.
