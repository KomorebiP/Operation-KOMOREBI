\[
Q=0.02\chi^2_{80},
\]
with the literal decimal threshold beginning
\[
q=470.874490072839519665842558646653705377688346050339\ldots.
\]
The full input string, not this abbreviated display, is in the control
manifest.  Its tail is near \(10^{-5000}\).  Requested multiplicative

refinements, using \(K=256\), \(L=14\), and 50 interval decimal digits.
The proven ratio upper endpoint satisfies
\[
\boxed{\frac{p_+}{p_-}-1\le9.202\times10^{-20}.}

The full retained upper endpoint is approximately
\(9.2014149826333253\times10^{-20}\); the displayed inequality rounds outward.
The logarithmic width is approximately
\(3.996123752659559\times10^{-20}\) decades.

An independent interval calculation of the finite Erlang expression

\subsection{Fresh exact-binary64 matrix-to-tail control}
A dense \(64\times64\) factor was constructed as a normalized Hadamard matrix
with singular values \(1,3/4,1/2,1/4\), each repeated 16 times.  Its entries
are exact binary64 dyadic rationals, so the target Gram spectrum is known:
\[
1,\quad9/16,\quad1/4,\quad1/16
\]
with the same multiplicities.  Every one of the 64 known eigenvalues was
contained in the directed post-certified spectral intervals.

For the exact literal threshold \(q=131.33201485100517\), the matrix-defined
tail is near \(10^{-16}\).  Requested multiplicative uncertainty
\(10^{-12}\) was accepted, with final ratio upper endpoint satisfying
\[
\boxed{\frac{p_+}{p_-}-1\le2.783\times10^{-15}.}
\]
The unrounded upper endpoint is approximately
\(2.7829391894740692\times10^{-15}\).  The candidate used 50 decimal digits,
the spectrum postcheck used 65 interval decimal digits, and the combined run
took 34.618 seconds.  Orthogonality and reconstruction norm upper bounds were
approximately \(1.6471\times10^{-49}\) and \(9.1752\times10^{-50}\), respectively,
with those displayed bounds rounded outward.

This example verifies the complete supplied-factor route at moderate dense
dimension.  It does not establish directed correctness of arbitrary
statistical preprocessing or a streamed, memory-bounded large-scale
spectral postcheck.

\subsection{Publication corrections and their boundary}
The final code adds a directed ratio acceptance predicate and preserves outer
endpoint strings through matrix-to-tail propagation.  It serializes exact
binary interval bounds by directed decimal conversion.  This repairs two
specific gaps in the original source: ambient point precision could collapse
a narrow log interval, and nearest-rounded display strings could move an
endpoint inward.  The new regressions exercise these cases and exact
acceptance boundaries.

The directed enclosure remains conditional on the correctness of the
interval library and the stated input/domain restrictions.  A finite test
suite is evidence for this implementation, not a formal proof of its full
numerical runtime.  The fresh control JSON retains all authoritative input
and output strings; abbreviated text and plotted summaries are descriptive.
