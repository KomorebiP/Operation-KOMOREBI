# Code of conduct

Technical disagreement is expected. Personal attacks, harassment,
intimidation, doxxing, discriminatory conduct, and knowingly deceptive
benchmark or authorship claims are not accepted.

Reviews should address definitions, hypotheses, code paths, evidence, and
reproducibility. Contributors must distinguish proved statements,
implementation invariants, controlled numerical certificates, conjectures,
and speculative extensions.

Repository maintainers may edit, lock, or remove material that violates
these standards and may restrict participation when necessary to protect
contributors or the project.
