# Changelog

## 2.3.0 · 2026-10-09

Added standalone finite real 1-D analysis, explicit FIR polyphase transfer blocks,
causal streaming with flush/reset, pickle-free source-signal archives, installation
self-check and signal-file CLI, and six expanded executable examples.

Corrected continuous color semantics, irregular and small image handling,
original-frame archive preservation, real Fourier projector validation, strict
modulus and depth contracts, complete packet pruning validation, extreme atlas
weight normalization, regression posterior-scale cancellation, invalid probability
normalization, and nondeterministic graph recommendation.

Candidate scores now use comparable nested targets and report candidate failures.
Surviving candidate regressions are refit on all supplied training records.
The benchmark's explicit training-step argument is no longer ignored.

The original 32-case core suite is retained and expanded to 184 core cases.
Eight separately supplied static local-fixture cases also pass. The current
benchmark, 2,025 FIR stress combinations, 160 irregular images, 160 signal lengths,
35 operator identification cases and negative controls have fresh evidence.

The core 2.1.0 source archive is the authoritative predecessor. Separate ARC2
and ARC3 agent branches are not merged or assigned this release's verification.
The inherited license is unchanged. No remote publication is performed.
