# Claim scope

This release provides executable Python code for an offline Bayesian multiresolution operator-program agent connected to the official ARC-AGI-3 local toolkit interface.

It establishes:

- deterministic packet extraction and nested resolutions;
- a finite Bayesian operator library;
- offline replay-based probing with consistency checks;
- action planning and local result logging;
- runtime network blocking;
- package-level correctness on a bundled deterministic smoke environment;
- API-contract tests against the documented ARC toolkit interface.

It does not establish:

- an official ARC-AGI-3 benchmark score;
- access to private or public ARC game files not supplied by the user;
- unrestricted operator-program invention;
- general intelligence;
- compatibility with future toolkit versions beyond the pinned interface without retesting;
- official competition eligibility, because competition mode is intentionally absent.
