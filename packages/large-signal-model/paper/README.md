# Historical PR-LASM capstone

`Projector_Resolved_Large_Algebraic_Signal_Model.pdf` is the preserved 38-page
capstone distributed with the core 2.1.0 repository and recording the 2.0.0
controlled results. The PDF, TeX and figure assets are retained unchanged.

The current 2.3.0 behavior, numerical audit and API contracts are described in
`../docs/RELEASE_GUIDE.md`, `../docs/migration-2.3.md` and `../RELEASE_AUDIT.md`.
The old paper is not relabeled as a fresh 2.3.0 empirical report. In particular,
continuous color semantics, original-frame preservation, Fourier-selector
validation and cross-resolution statistical scoring have been corrected.
Historical counts and references must be read with their recorded version.
