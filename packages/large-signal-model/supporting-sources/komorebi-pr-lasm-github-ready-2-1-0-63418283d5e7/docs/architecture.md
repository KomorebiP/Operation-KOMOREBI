# Architecture

## Exact observation archive

Each frame is analyzed in spatial, unitary Fourier, orthonormal Haar,
two-dimensional polyphase, and categorical color coordinates. Every
declared atlas carries an explicit synthesis map. Their weighted direct sum
is normalized as a finite tight frame.

## Statistical states

The exact archive is summarized into deterministic feature groups and then
projected into macro, meso, and micro states. These states are compressed
predictors, not exact inverses of the observation.

## Typed operator posterior

Each candidate program declares an atlas, resolution, mechanism family,
feature map, target map, complexity, and memory requirement. Conjugate
Bayesian multivariate regression provides predictive distributions and
evidence. Posterior mass remains distributed over competing programs.

## Adaptive refinement

A complete Haar packet tree permits mixed-depth exact prunings. Best-basis
dynamic programming chooses between retaining a node and retaining both
children. Because the selected paths form a complete antichain, synthesis
remains exact.

## Memory and graph

Finite delay, power-law memory, and exponential memory are distinct typed
state packets. Observed deterministic transitions are stored in a graph
with visit, reward, progress, win, and loss statistics. Nondeterministic
edges are marked and excluded from exact shortest-path reasoning.

## Active planning

Action utility combines exact probes when available, known graph outcomes,
posterior reward and progress, win and loss probabilities, novelty,
information value, role statistics, uncertainty, and loop penalties.
Statistical predictions never overwrite exact replay evidence.
