# Repository layout

| Path | Purpose |
|---|---|
| `src/komorebi_pr_lasm` | Stable public import facade |
| `src/komorebi_arc3_offline` | Implementation and 2.0.0 compatibility namespace |
| `tests` | Core tests and optional local-suite tests |
| `examples` | Minimal executable demonstrations |
| `paper` | Canonical manuscript, LaTeX, and figures |
| `benchmarks/reference` | Immutable reference output ledgers |
| `environment_files` | Ignored local ARC environment location |
| `test_environment_files` | Small adapter contract fixtures |
| `scripts` | Figure generation, validation, and archived wrappers |
| `.github` | CI, issue forms, dependency updates, and pull-request policy |

Generated wheels, runtime outputs, recordings, downloaded games, and local
environments are excluded from Git history.
