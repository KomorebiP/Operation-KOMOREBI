# Proof-state protocol

Use the pinned runtime and warnings-as-errors. Promote only actual successful
final-source checks. Preserve the inherited sources and their split provenance.
The active source tree has no admitted proofs, custom axioms, unsafe code, or
native-decide shortcuts. Audit every theorem's axioms and preserve source/output
hashes. Keep the mathematical theorem separate from finite diagnostic tests.

Centered covariance is defined from covarianceBilin. Explicit posterior versions
are pointwise; canonical counterparts retain each model's own evidence-a.e.
quantifier. Both prior covariances may be singular; both noise covariances must
remain positive definite. Projector algebra, self-adjointness, contractivity,
operator norm, and Frobenius geometry must not be conflated.

The next open layer is a posterior-distribution metric certificate. Literature
novelty, optimal refinement, nonlinear/non-Gaussian generality, singular
innovation, and full stochastic-integral semantics remain separate boundaries.
