# Proof and continuation protocol

The current CONTINUE_HERE.md and AUDIT.json define authority. Older root documents
are preserved history, not live instructions. Checked means final source compiled
under the pinned runtime, warnings as errors, with no active placeholders, custom
axioms or native proof shortcuts. Audit all declared theorem axioms and source,
compiled output and direct dependency hashes. Finite tests do not prove universal
results. Failed and interrupted checks are not successful receipts.

Work in small sequential dependency-ordered modules. Never infer arbitrary IEEE
semantics or uncertain-input guarantees from exact rational or dyadic calculations.
A rounded certificate can be sound without every requested precision schedule
succeeding. Keep exact-vs-canonical posterior, singular-prior, projector geometry,
metric-versus-coupling, and implementation trust boundaries explicit.

Preserve every inherited checked-release file. Archive superseded root controls,
record actual new evidence, and create a successor checkpoint without unproved
scope promotions. The full prior exact Richardson successful-termination result
remains retained but is not automatically a rounded-iteration theorem.
