# Proof and continuation protocol

Current CONTINUE_HERE.md and AUDIT.json define the live state. Historical root
controls are preserved evidence, not active instructions. A checked theorem must
compile under the pinned runtime with warnings as errors, no placeholders,
custom axioms or native proof shortcuts. Audit all declarations and final source,
compiled-output and direct-dependency hashes. Finite numerical checks are not
universal proofs. Failed, timed-out and interrupted checks never count as success.

Run small sequential dependency-ordered modules. Preserve every inherited
checked-release file. Distinguish exact gain iteration, outward certificate
arithmetic, and actual machine execution. Precision sufficiency is now proved
with explicit slack and the hybrid manufactures that slack. It is not a theorem
of rounded gain-iteration convergence or monotone scores at every precision.

Keep actual-versus-explicit/canonical posterior quantifiers, singular-prior scope,
projector geometry, coupling-versus-optimality and external implementation
boundaries explicit. Update the current boundary only with new durable evidence.
