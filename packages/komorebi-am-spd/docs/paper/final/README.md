# Adaptive Multiscale Singular Packet Decomposition

This directory is the self-contained source package for the finalized AM-SPD manuscript.

## Primary files

- `Adaptive_Multiscale_Singular_Packet_Decomposition_Final.pdf` is the compiled 78-page manuscript.
- `Adaptive_Multiscale_Singular_Packet_Decomposition_Final.tex` is the complete LaTeX source.
- `figures/` contains 85 vector PDF figures generated by the research code.
- `tables/` contains the corrected principal-result tables and the historical appendix tables.
- `data/` contains the authoritative JSON outputs used to audit the principal tables.
- `MANUSCRIPT_AUDIT.md` records the editorial, mathematical, and reproducibility changes.

## Build

### PowerShell

```powershell
./build.ps1
```

### Bash

```bash
./build.sh
```

The build requires `latexmk`, `pdflatex`, TikZ, `microtype`, `bookmark`, `placeins`, and the standard AMS packages.

## Regenerating the finalized source from the preserved research snapshot

The provenance script expects the GitHub repository containing `research/original`:

```powershell
python ./generate_final_manuscript.py `
  --repository-root C:\path\to\komorebi-am-spd `
  --output-dir C:\path\to\AM_SPD_Final_Manuscript_Source
```

The output directory is replaced. Use a new directory rather than the repository root or `research/original`.

## Scope

The final edition separates analytic statements from floating-point verification, labels exact and bounded metrics separately, corrects grayscale and RGB storage formulas, restores references, and moves full source listings out of the manuscript. The original 147-page archival edition remains preserved in the repository under `research/original`.
