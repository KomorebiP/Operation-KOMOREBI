# Original final research snapshot

The `original` directory is an extracted copy of the recovered final AM-SPD source archive. It is retained for auditability and manuscript reproduction.

The installable package under `src/am_spd` is the supported software interface. Changes to package ergonomics should normally be made there. Mathematical or benchmark changes should be made deliberately in both the research scripts and package implementation when they affect both layers.

The checksum ledger from the recovered source remains at `original/SHA256SUMS.txt`.
