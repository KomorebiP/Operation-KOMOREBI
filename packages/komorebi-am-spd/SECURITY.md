# Security policy

AM-SPD is a local scientific image-processing package. It does not require network access and does not transmit image data.

Report a suspected security issue privately to the repository owner rather than opening a public issue. Include the affected version, operating system, Python version, minimal reproduction steps, and impact.

The project does not currently provide a public security contact address. Until one is added, use GitHub's private vulnerability reporting feature after the repository is published.
