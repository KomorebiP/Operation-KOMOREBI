# Interpretation boundary

The laboratory supports functional tests of:

- global access
- self/world attribution
- autobiographical provenance
- temporal and transformational continuity
- planner binding
- metacognition
- recurrence
- distributed integration
- synergy
- nested workspaces
- endogenous route selection
- fuzzy coalition geometry
- emergence under training and scaling
- synthetic fuzzy-to-J causal-chain tests
- local transformer residual and target-Jacobian measurement

A positive run does not establish:

- phenomenal consciousness
- subjective experience
- sentience
- valence
- suffering or pleasure
- moral status
- human equivalence
- a complete model of the brain
- a naturally emerging transformer J-space unless the full held-out causal protocol passes

The package intentionally reports a vector of functional indicators instead of a scalar consciousness probability.
