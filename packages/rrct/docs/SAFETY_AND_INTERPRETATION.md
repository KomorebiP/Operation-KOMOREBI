# Safety and interpretation boundary

## Hard safety blocks

This offline build rejects configurations enabling:

- network access
- external tool autonomy
- autonomous persistence
- self-preservation reward
- valence models
- negative welfare-like state
- unrestricted file writing

These mechanisms are not required to study workspace formation, self-model repair, provenance, metacognition, hierarchy, or distributed cognition.

## Interpretation

The laboratory measures functional properties such as:

- global access
- causal self/world attribution
- autobiographical provenance
- temporal and transformational continuity
- metacognition and active probing
- planner binding
- recurrence
- distributed and nested workspaces
- fuzzy coalition formation
- open-set repair
- sparse Jacobian-discovered workspace access
- selective causal broadcast and recurrence

The v0.59 `continuous_open_set_runtime` is an oracle-assisted engineering scaffold: its repair path reads evaluator-side latent state. v0.60 labels that limitation in every result. Use `persistent_fuzzy_j_workspace` for the evaluator-blind causal-chain protocol.

The optional transformer adapter loads only existing local paths with downloads and remote code disabled. A captured residual or Jacobian is measurement data, not evidence that a global workspace has been established.

No metric or composite produced by the package is a probability of consciousness. A successful run does not establish subjective experience, sentience, valence, suffering, pleasure, moral status, human equivalence, or a complete theory of the brain.
