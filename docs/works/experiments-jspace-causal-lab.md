## Before you start

**Suggested background:** Basic programming and familiarity with the stated data and evaluation method. Read the input limits and acceptance criteria before interpreting output.

**Recorded results and limits:** Research instrument for candidate causal states using saved models and retained failed assays. Not a J-space certificate.

**Remaining work:** Resolve the recorded relay failures and run matched intervention/mediation checks on fixed settings.

The background advice is an editorial starting point. The work itself states its prerequisites and hypotheses.
