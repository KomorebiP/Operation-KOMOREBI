## Proof-review distinctions

Governance quotients preserve labels, enabled actions, and successors under one fixed action contract. A quotient is not automatically an implementable decentralized policy. The information obstruction uses joint history and random-tape laws, not equal local marginals. Residual composition compares each semantic type in one aligned codomain. Deadline transport preserves the monitor state, not a promise of service. The lifetime formula concerns first exit under a specified finite substochastic kernel with spectral radius below one.

Arrow and Gibbard–Satterthwaite are cited classical results, not newly numbered or reproved propositions. The exact finite suite checks implemented instances and counterexamples; its assertion count is not a count of formal theorems.
