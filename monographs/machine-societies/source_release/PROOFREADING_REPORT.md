## Mathematical clarifications checked

**Affected outsiders.** A correct internal allocation can still violate an omitted external reservation. Membership, voting rights, infrastructure control and affected parties are distinct. The proposed external-effects contract does not grant universal vetoes or establish consent by definition.

**Strategic inspection.** The mixed equilibrium assumes a simultaneous one-period two-action game, perfect detection, risk-neutral payoffs, authorized collectible penalties and no prior commitment. Paying for verifiably performed inspection changes that model. A verifiable receipt and its checker remain assumptions. The extension is not a solution of collusion, hidden transfers or the incentives of every upstream verifier.

**Sharp privacy envelope.** The likelihood-ratio bound concerns the complete record seen by the sanction procedure, and only cases covered by the declared pair or neighboring-input relation. The result bounds both the expected sanction difference and the compliance false-positive probability. Two-outcome laws attain the bound, but not every protected pair does. Pure pairwise protection is not silently replaced by approximate differential privacy. The exact factor-one and zero-cap cases are included.

**Transcript composition.** The conditional bound must hold at every reachable prefix. Private marginals can reveal the protected fact jointly. Extra appeal disclosures, side information and adaptive stopping cannot be omitted from the record covered by a certificate.

**Effective appeal.** The exact interval condition assumes a finite workload of unit review-and-disposition jobs, specified evidence-ready windows, reserved capacity and qualified authorized reviewers. Matching does not establish evidence truth, a favorable judgment or the reversibility of an external act. An unlimited incoming workload is not covered by a finite reserve.

**Available authorized endings.** The ending attractor and running kernel use distinct implemented action catalogues and a command observable before the next decision. A safe idle state can lack an ending strategy. Suspension, settlement and dissolution have different target meanings. Sure completion is distinct from almost-sure completion. The theorem certifies an available policy, not an incentive to obey it or an unmodeled command-delivery bound.

**Guarded certificate applicability.** The guard must be sound for the whole action interval. Checksums do not establish semantic premises. Authorized handovers preserve the stated protected set, and a shared rank must include the primitive checking and handover steps it counts. A rank that resets on every mode change cannot certify progress. An ungrounded cycle of implications does not establish its own initial premises, although properly anchored temporal assume-guarantee reasoning can be sound.

**One accountable commons.** The final variant explicitly uses a different noisy record law from both the earlier three-outcome audit and the perfect inspection game. The budget is eight execution units, with monetary audit fees separate. Three internal services, an external claim, a full appeal, the audit and final revocation fit at eight. At seven, the complete settlement claim fails. The implementation checks a five-transition phase rank with the final check inside the administrative profile. No uncounted free transition is used.

## Exact implementation coverage

The added suite checks inspector best responses and the verified-fee boundary, finite rational privacy pairs against both vertex enumeration and an independently coded fractional allocation, exact envelope attainment, conditional disclosure and postprocessing, all specified interval review jobs against Hall subsets, matching and direct assignment, finite running/ending games against stationary-policy and cycle enumeration, invalid stopping certificates, guarded finite transitions and rank controls, circular-assurance truth tables, observation-fibre enumeration, and the final commons for capacities zero through twelve.

The knowledge-game builder now enumerates subsets within observation fibres. Exhaustive small-state comparisons establish agreement with the old enumeration in the checked range, and a fully observed 128-state example checks that the avoidable global-subset explosion has been removed. General partial-observation models can still be exponential. The linear-program reference solver is finite vertex enumeration rather than a scalable optimizer.

The alternative implementations are authored within the same project. They are useful cross-checks, not independent external replication. The full tested ranges are attached to each group rather than inferred from a high count.

## Corrections and recorded failures

The first source-inventory checker incorrectly required exactly one label inside each statement. Controlled lumpability also contains a labeled equation, so the checker raised ValueError before producing a source-audit result. The parser was corrected to select theorem/proposition labels rather than internal equation labels. It then paired all 62 proofs and confirmed exact preservation of the 56 predecessors. This was an audit-tool parsing error, not a mathematical counterexample or an invalid manuscript label.

Visual review found that Appendix A began below the conclusion with only its first table row on that page. A new-page boundary before the appendices resolved that layout while preserving the final 106-page count. Intermediate handover and checking states were explicitly tagged in the progress model to remove ambiguity about what the shared rank counts.

One publisher-link fetch for the differential-privacy book failed. The accessible author-hosted full PDF supplied the actual reviewed definition and composition arguments. The failure was not counted as successful source review. See validation/reference_review.md for sources and scope.

No mathematical assertion failed during the first-edition runs. The source and presentation corrections were applied before the final build, exact rerun and fresh extraction. The original v0.7 attachment PDF and ZIP remain unchanged.

## Reproducibility and remaining limits

Bash, Python and LaTeX were executed in the recorded environment. The PowerShell build was inspected but not executed on Windows. The final render used Poppler, with PyMuPDF for text and geometry checks. No PDF/A, tagged-accessibility or pixel-level renderer-equivalence certification is claimed. The reading PDF embeds its fonts; no standalone font files are shipped.

The execution receipt retains the inherited legacy schema version 1. The project-local verifier checks its actual pinned inputs, output hashes, counts and source audit. It is not an independently authenticated copy of an external plugin validator. No Git commit or independent execution attestation is available. Tool invocations used bounded timeouts; no separate process memory, affinity or CPU quota was imposed. The fresh build ran in the same environment, so it is a clean rebuild, not cross-platform replication.

All six new references received targeted primary-source review. The 52 inherited references were retained and source-consistency checked, not all independently reread in full. A complete priority audit, independent proof review, target-venue acceptance review and proof-assistant formalization remain separate tasks. The first edition is complete within this stated editorial and theoretical scope.
