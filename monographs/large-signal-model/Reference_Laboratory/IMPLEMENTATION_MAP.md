# Source-to-code correspondence

The authoritative detailed map is PROOF_REGISTER.json. Forty entries link a named function or class to a restricted implementation sector, recording source-file hash and line range. Every entry separately names its related block-level calculation suite. An absent implementation link means no dedicated general algorithm is claimed, not that the written theorem is omitted.

The map deliberately labels numerical geometry proposals, bounded interval searches, scalar confidence specializations and fixed-template recognizers. None is described as implementing a stronger unrestricted theorem.

Run `python checks/verify_proof_register.py` to verify source locations, statement identities, dependency references, acyclicity, code-symbol locations and code hashes. This audit does not evaluate the general mathematical proof.

Run `python checks/verify_source_lineage.py` to verify the preserved source, all 87 proposition numbers, 86 unchanged statement/proof passages and the exact declared amendment to Proposition 72.

Run `python checks/audit_regressions.py` for the new dimension-boundary, parser and replay-integrity regressions. These records are reported separately from the inherited eight mathematical suites.

Run `python checks/verify_release_freeze.py` to compare all 87 immediate-predecessor spans, reference mathematics modules, fixed data and seven regenerated certificate files with their frozen identities. This checks preservation, not mathematical truth.
