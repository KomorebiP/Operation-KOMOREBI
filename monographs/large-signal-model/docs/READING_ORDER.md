# Reading order

1. Start with the current [theoretical atlas](../Visual_Companion/build/Realization_Calculus_Large_Signal_Model_Theoretical_Atlas.pdf) for diagrams, formulas and a continuous rational example.
2. Read the full [monograph](../Monograph/build/Realization_Calculus_Large_Signal_Model.pdf) for complete statements, proofs, glossary and source references.
3. Use [formal coverage](../Lean/COVERAGE.md) and the atlas [proof map](../Visual_Companion/PROOF_MAP.json) to locate the accepted Lean statements and their hypotheses.
4. Use the reference laboratory for the preserved scientific calculation scripts and replay instructions.

The visual atlas, reading guide and older visual notes in `Reference_Laboratory/` are historical companions retained with their original source and provenance. In particular, the old reading guide's audit-candidate and no-proof-kernel statements describe its predecessor checkpoint. The current accepted Lean release covers all 87 registered proposition cores, as recorded in `Lean/CURRENT_STATUS.json` and `Lean/COVERAGE.json`. The new theoretical atlas is the current visual entry point.

Illustrated examples and curves of bounds do not establish their quantified statements by themselves. Use the stated hypotheses and proof mappings.
