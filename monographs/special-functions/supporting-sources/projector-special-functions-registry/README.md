# Projector Special-Function Registry

This package documents the scalar, polynomial, p-adic, operator-valued, and nonlinear function families generated by the transfer-block/projector calculus.

The central distinction is preserved throughout:

- a **classical boundary** is a known function appearing as a block section or specialization;
- an **explicit derived family** is generated and proved by the calculus but may overlap known special-function theory;
- a **candidate-new family** has a clear definition and structural laws but still requires a dedicated literature and priority audit;
- an **operator/schema family** is a construction principle rather than a single scalar special function.
