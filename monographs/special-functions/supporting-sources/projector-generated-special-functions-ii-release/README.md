# Projector-Generated Special Functions II

## Cyclotomic Stieltjes Packets, Packet Resultants, Positive Energy Resolvents, Gamma Scaling, and Character Decoherence

**Author:** Komorebi P.

This release develops the second special-function family generated by the projector-resolved calculus. It begins with exact Bernoulli–Hurwitz refinement and derives new local, scalar, positive, asymptotic, and character-resolved structures.

The main proved results are:

- cyclotomic Stieltjes packet formulas for the full Taylor germ of every Bernoulli–Lerch detail channel
- exact transforms from generalized Stieltjes constants to derivatives of Dirichlet \(L\)-functions at \(1\)
- a holomorphic detail-variance identity
- primitive cyclotomic packet resultants
- complete monotonicity of the squarefree packet-energy sequence
- strict positivity of every finite packet-energy Hankel matrix
- a zero-free packet-energy resolvent on \(\mathbb C\setminus[1,\infty)\)
- an exact finite-difference representation using \(\zeta(s)/\zeta(2s)\)
- the packet-energy asymptotic and Gamma scaling limit
- asymptotic orthogonality of distinct Dirichlet-character packets

The principal Möbius coherence estimate remains open. In the zeta specialization it is equivalent to the Riemann hypothesis after normalization by the proved diagonal energy law.

From this directory, run:

```bash
python build_all.py
```

The command regenerates all 20 vector-PDF and 20 PNG figures, rebuilds the generated LaTeX tables, runs the independent tests, and compiles the paper three times.
