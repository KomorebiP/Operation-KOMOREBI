# Projector-Generated Special Functions V

**Author:** Komorebi P.

The canonical paper is `Projector_Generated_Special_Functions_V.pdf`.

The `source/` directory contains the LaTeX manuscript, one Python generator, 26 vector-PDF and PNG figure pairs, numerical tables, results, independent tests, reproduction scripts, the claim map, the release audit, and checksum ledgers.

The paper proves the unconditional positive phase-space and representation-theoretic results stated in the manuscript. It does not prove the principal Möbius coherence conjecture and does not prove the Riemann hypothesis.
