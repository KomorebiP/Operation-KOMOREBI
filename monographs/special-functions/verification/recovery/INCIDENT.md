# Archive recovery incident

The delivered Complete_Release ZIP had 38,556,430 bytes. Its external receipt described a 137,520,411-byte file. The delivered SHA-256 was 813d781aa5a98f5f285f17cd74812f6ace8684aa92170b0cab0a2e81c198b185, not the receipt's a651e89fb6608c979a35a391d8231d098b2899a0cc5b1aa977d6cf06d297dc65. Python rejected it as BadZipFile. A fresh retrieval returned the same incomplete bytes.

The stream ended exactly after its 1,085th complete local member, without the central directory or end record. All 1,085 local members passed their stored CRCs. Hash-matched files from the earlier proofread package and standardized source volume restored a further 576 files. The 1,659 recovered payload files all match the previous payload manifest. The two recovered manifest files are not counted as payload.

All three current books, all editable mathematical sources, the complete expanded visual source set, the original eight paper archives, registry, consolidated core and collected reader were recovered. The 99 missing manifest-listed items are prior-run reports, logs, duplicate generated run artwork, and the previous package verifier. Their exact paths and expected hashes are retained in missing_previous_records.json. This recovery does not claim to recreate their missing bytes. The package verifier has been independently replaced, and fresh checks are recorded separately.

The old external success receipt did not describe the delivered bytes. The exact point at which the file was truncated is known, but whether this occurred during interrupted creation or transfer is not established. The replacement archive is written to a temporary filename, closed, reopened, CRC-tested, independently extracted, and only then assigned its final download filename.

Local Lean recovery: all seven stored offline parts were reconstructed. Their combined SHA-256 exactly matches the recorded portable-runtime hash. The pinned compiler, nine dependency revisions, core proof, cached Mathlib proof, bundled Paper VI algebra, false-proof rejection and placeholder rejection were freshly tested. This validates the runtime, not a formalization of the Special Functions monograph. None of the eight Special Functions paper archives contains a .lean source file. The initial broad full-Mathlib smoke command timed out; narrower cached imports and the bundled integration module passed.

After the archive recovery, the scope register identified a separate stored browser-safe finite core. It was retrieved from Library and compiled locally. Thirty-nine theorem declarations passed after replacing the broad import with targeted modules and fixing one unnecessary simpa. A separate generated axiom-audit attempt initially included a word from a comment as a declaration name; that generator error was corrected, and the clean audit passed. All failed attempts and the exact patch are preserved.
