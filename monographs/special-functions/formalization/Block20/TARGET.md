# SF-LEAN-B20 target

Base: local SF-LEAN-B19, its accepted receipt and exact source/proof hashes,
on repository f49e00d6088bbc8dca4f8a3a70b232db1eea085b.

Interpret the source arithmetic as typed expression data with a Lean evaluator
that is separate from the Block19 arithmetic term printer. For every input in
each source-variable environment, prove equality of interpreted products,
weights, normalization, partials, majorant seed/update, default radius,
resource defaults, tail and dictionary with the already refined operations.
Compose the expression-based array/result construction with the existing
typed and analytic enclosures. Bind emitted expression data to actual sources.

This is a bounded continuation toward reducing translation trust. It does not
verify all Python syntax, the AST parser/data extractor, the fixed statement
template, CPython or standard-library primitive implementations. Natural-index
subtraction is used only with the reachable-index safety proofs from Block19.

Publication deliverable: publish Blocks18-20 and their evidence to GitHub,
update the maintained status/reading/source-inspector records, and verify the
GitHub Pages build and live revision. Preserve prior sealed sources and records.
