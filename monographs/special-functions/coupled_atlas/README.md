# Resolution and Coupled Atlas

The current reading copy is **../books/Resolution_and_Coupled_Atlas.pdf**. This directory contains the editable atlas and all fourteen vector plates.

Run `python build.py` with XeLaTeX installed. Output is `build/Resolution_and_Coupled_Atlas.pdf`. The mathematical implementation and figure-generating programs are preserved in **../research/**. The fresh coupled-suite report is under **../research/release_checks/coupled/**.

The atlas separates exact rational certificates, floating-point illustrations and analytic proofs. It makes no Lean certification claim. Prose now uses signed quadratic-form terminology and distinguishes project review from external peer review.
