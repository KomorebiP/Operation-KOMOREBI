# Proof Path Theory 1.2.0 status

The finite proof-field / Komorebi Space bridge is implemented and formalized.
The integrated outcome is recorded by `data/release_verification.json` and the
fresh formal audit in `evidence/lean/verification.json`. Only a PASS in those
records constitutes the integrated release verification.

The release has 33 manuscript result groups. Eight Lean modules cover the
specified realization, gluing, obstruction, counting and compression interfaces,
with 42 named theorems and an inventory of 78 selected declarations.
The whole manuscript is not claimed to be Lean-formalized.

The finite software retains version 1.0 wire-schema compatibility but rejects
invalid certification strings and binary floating inputs. The native Lean
exporter is executed, not proved correct for arbitrary declaration environments.
Human review, broad priority comparison, social-model experiments and a chosen
redistribution license remain external or author-dependent matters.
