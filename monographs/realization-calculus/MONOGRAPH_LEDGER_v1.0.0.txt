DECISION AND SCOPE

The user's request is to adapt the latest Komorebi Physics monograph format to
the twelve core papers with a distinct color. The delivered interpretation is
one collected volume, chronological Parts I–XII, with editable component sources
and individual component PDFs in the publication package. No public release or
repository mutation is included. The twelve scientific distribution freezes
remain separate, unchanged records.

The reference is the current Komorebi_Physics.pdf and its matching publication
package, selected on 21 October 2026. Their exact identities and SHA-256 hashes
are in editorial/TEMPLATE_PROVENANCE.json. The selected core editions are bound
to version 17 of the closeout register, whose named revision is v1.16.0. The
register text is a native-text reconstruction with its final newline restored;
it is not represented as a byte-exact download of an original text file.

DESIGN

The inherited hierarchy is a quiet cover, white part openings, readable serif
mathematics, sans-serif navigation, linked contents, running headings and global
folios. The new palette is deep plum #3C263F, mulberry #7B4165 and muted gold
#A68A56. P052 and Nimbus Sans are explicit installed typefaces. The Physics TeX
Gyre Type 1 files were unavailable, so this adaptation records the chosen fonts
and their hashes rather than silently substituting them. The package supplies
notices and dependency records; standalone font programs are excluded.

REPAIRS AND NONFINAL FAILURES

The audit trail retains rather than erases failed attempts. Source-group records
describe missing local fonts, caption-macro conflicts, omitted VII figure assets
restored byte-for-byte, and local layout adjustments. Final builds reported no
overfull boxes, missing characters or unresolved references. Nonfatal microtype,
underfull and three inherited VII math-font shape warnings remain documented.

The initial group adapter assumed one JSON report shape; the V–VIII direct list
required explicit normalization. Static review found duplicate part-opening
folios and named-destination coordinate conventions; both were corrected.
The first full PDF save spent several minutes in duplicate-object merging and
was interrupted while its output was still empty. Saving with unused-object
cleanup and cross-reference compaction completed successfully.

The first all-page audit used two incorrect representation assumptions: it did
not parse compact GoToE arrays such as [5/Fit], and treated special empty-path
bounds as ordinary visible geometry. Its original report and code are preserved
in book/audit_history/. Corrections are limited to those PDF representations;
source text, destination ranges, attachment identities and visible geometry
remain independently checked. It also identified 83 page-origin link targets
shifted six points outside the page by mirrored gutters. Clamping the navigation
points to page bounds repaired these without changing the visible content.

The final packaging review also found an I–IV rebuild dependency on a removed
local font folder. The delivered rebuild dependency setup and bounded relocation
check are documented in editorial/REBUILD_PORTABILITY_REVIEW.json.

The initial package-verifier invocation supplied an unsupported positional root
argument and stopped before checking files. The invocation and README now use
--strict; the unchanged verifier derives the package root from its own location.
The first diagnostic is retained under editorial/.
