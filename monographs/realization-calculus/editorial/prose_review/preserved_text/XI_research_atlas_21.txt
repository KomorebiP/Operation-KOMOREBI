PLATE XI.19

Abstract actions and native normalizers

Abstract lifting and arithmetic realization are different existence statements.





                                         not automatic
        Abstract action on F23              Homomorphism C4 →C3r
           A(x, y) = (−y, x)                     4x = 0 (mod 3r)
         order 4, symplectic                         only x = 0





        A nontrivial finite action may fail in a specified native normalizer.


           This excludes that action mechanism, not every allowed arithmetic host.





The linear map A(x, y) = (−y, x) on F23 is symplectic and has order four. Thus there is a genuine
nontrivial abstract C4 action. In contrast, every homomorphism C4 →C3r is trivial: an image x satisfies
4x = 0, and multiplication by four is invertible modulo 3r.

The arithmetic obstruction uses its stated native-normalizer quotient and inner-action requirements.
When that permitted quotient is a p-group, a prime-to-p subgroup cannot implement the desired
nontrivial action through it. The cyclic groups in the drawing isolate the elementary coprimality
mechanism. They are not asserted to be the entire normalizer of every type.

Finite central-extension actions can still lift under their own coprimality hypotheses, and projective
intertwiners can sometimes be linearized. Neither result supplies the missing arithmetic conjugating
matrices. An obstruction to this normalizer mechanism therefore remains compatible with success
through a different allowed host or a different stated attachment contract.





Evidence: Exact coprimality analogue.

Companion source: Part I, Sections 4 and 11. Book page 1525.

PLATE XI.20

The finite subgroup remembers its squares

Dihedral and quaternion markings survive inside the same complex scalar extension.


                       [X, Z] = [iX, iZ] = −I





      finite subgroup      q(e)         q(f)        q(e+f)        order 2       order 4

        D8           0        0          1           5           2

        Q8           1        1          1           1           6





           Same scalar pushout, different marked finite subgroups.




Let X2 = Z2 = I and XZ = −ZX. The subgroup generated by X, Z is dihedral of order eight. The
subgroup generated by iX, iZ is quaternion of order eight. Both have the same quotient polarization and
commutator −I.
                             qD(x, y) = xy,     qQ(x, y) = xy + x + y.

Their lift squares differ. The order columns count elements of exact order two and four, excluding the
identity. They distinguish the finite groups even though adjoining all complex scalars gives the same
ambient scalar extension.

For a fixed two-element center, a center-fixing extension map over a prescribed symplectic map must
preserve the quadratic refinement. With complex scalar center, square ratios have square roots, but this
freedom does not erase a separately prescribed finite subgroup. Transporting a quaternion marking into
the common scalar extension is valid. Identifying it with the independently fixed dihedral marking is
not.





Evidence: Exact finite-group enumeration.

Companion source: Part III, Section 26.1–26.2. Book page 1579.

PLATE XI.21

A square table does not specify an entire section

Changing one section value can preserve every square and still change products.




                     Change only the chosen section value at e+f

            0           0             0             0             0


            e           0             0             1             1


    v

                      f           0             1             0             1


           e+f           0             1             1             0


                     0               e                           f               e+f
                                w




Start from the ordered section σ(x, y) = XxZy in the dihedral example. Change only σ(e + f ) by a central
sign. Write the sign function as a(v) = 1v=e+ f . The displayed entries are the resulting cocycle differences

                              ∆c(v, w) = a(v) + a(w) + a(v + w) ∈F2.

Every diagonal entry is zero, so every square is unchanged. But ∆c(e, f ) = 1. A map fixing the specified
generating lifts cannot also implement the changed assignment at e + f. The cross marks a nonzero
product discrepancy, not failure of the two extensions to be isomorphic in some other way.

This is why the native certificate needs all specified section products, not only a quadratic table. When
the entire section is transported through one homomorphism, those products are retained automatically.
When the target section is independently prescribed, its pointwise assignments must be checked. The
distinction concerns what is fixed, not a contradiction in extension theory.





Evidence: Exact cocycle counterexample.

Companion source: Part III, Section 26.3. Book page 1580.

PLATE XI.22

Two different marking contracts

A positive attachment and a native obstruction can both be correct.





          Transported marking                       Fixed native marking
        source subgroup is input                 both subgroups are inputs
      host image chosen through F                 F must preserve both





         Scalar-pushout attachment                    Additional native square test
      with capacity and recovery inputs               can obstruct equal capacity





In the transported-marking contract, the source marking is supplied. After a permitted symplectic
embedding and scalar-extension isomorphism have been chosen, the host marking is their image. A
homomorphism fixes the represented center and carries squares, products, and specified lifts together.

In the independently fixed native contract, the target finite subgroup and its refinement are already
given. The comparison must hit that subgroup with its existing marking. A scalar rescaling that changes
it may be disallowed.

          choose a compatible target marking   ̸=  match this prescribed target marking.

The restricted one-vertex, trivial-stabilizer attachment retains its actual-type, capacity, full-character, and
recovery hypotheses. It should not acquire an extra native-marking premise merely because a stronger
problem is also studied. Conversely, that positive theorem cannot certify the stronger problem without
computing the additional datum. The two branches in the figure remain separate throughout the atlas.





Evidence: Contract comparison.

Companion source: Part III, Sections 26.4 and 27.3. Book page 1580.

PLATE XI.23

Two six-dimensional refinements with different signs

The alternating form and dimension do not determine the Arf invariant.



                                        q = 0        q = 1

              Arf 0: 36 zeros                           Arf 1: 28 zeros





               G(q) = 8                             G(q) = -8





Each grid contains all 64 binary vectors in dimension six. Columns encode the lower three bits and rows
the upper three bits, with row zero at the top. Circles have quadratic value zero. Crosses have value one.
The two forms share the standard polarization:

                      q+ = x1y1 + x2y2 + x3y3,   q−= q+ + x1 + y1.

Their Gauss sums are +8 and −8. Consequently the zero counts, including the zero vector, are (64 +
8)/2 = 36 and (64 −8)/2 = 28. The diagrams use exact binary evaluation at every vector.

These are explicit abstract refinements, not a claim that either has been computed on the actual rank-
eight arithmetic candidate. The example shows the datum still required when the host marking is
independently fixed. At equal capacity, an Arf mismatch has no orthogonal complement in which to be
absorbed.





Evidence: Exhaustive 64-vector displays.

Companion source: Part III, Section 27.1. Book page 1581.

PLATE XI.24

The equal-capacity test is sharp

One spare quadratic plane removes the free Arf obstruction, not every attachment constraint.



              Source dimension is 6; the embedding may be freely chosen.



       host dim          host Arf           source Arf 0             source Arf 1

         4              0                no                   no

         4              1                no                   no

         6              0                 yes                  no

         6              1                no                    yes

         8              0                 yes                    yes

         8              1                 yes                    yes





Fix a nondegenerate source of dimension six. The table varies the host dimension and its supplied
Arf invariant. The embedding may be freely chosen. A four-dimensional host cannot contain the
source. At dimension six, the map is an isometry and the Arf signs must agree. At dimension eight, the
complementary plane can have either sign.

                        Arf(U) = Arf(W) + Arf(V)  for W ≃V ⊥U.

This is the finite classification argument, not a numerical search over arithmetic matrices. It combines
with the original full dyadic capacity formula to isolate the rank-eight equality case.

The word “free” matters. A prescribed depth placement, an already fixed quotient embedding, or a
stabilizer-equivariance condition may forbid the required change of subspace. The table assumes the
actual quadratic host has been supplied. It does not compute that host’s native marking, choose its lifts,
or authorize modifications to the transport diagram.





Evidence: Finite classification criterion.

Companion source: Part III, Section 27.2–27.3. Book page 1581.

PLATE XI.25

A single transvection repairs an isotropic defect

The repair is explicit, and the previously correct line stays fixed.


                         Te(x, y) = (x + y, y)

        0                                                      0
       q = 0                                                  q0 = 0


         e                                                       e
       q = 0                                                  q0 = 0


                f                                                                                                  f
       q = 0                                                  q0 = 1


        e+f                                                       e+f
       q = 1                                                  q0 = 0


                    0 and e stay fixed; f and e+f are exchanged.




Take q(x, y) = xy and q0(x, y) = xy + y. Their discrepancy is B(e, −), with e = (1, 0) and q(e) = 0. The
transvection is
                                Te(x, y) = (x + y, y),     q0(Tev) = q(v).

The arrows show its action on every vector. Zero and e remain fixed. The vectors f and e + f exchange
places. Each arrow therefore lands on the same quadratic value shown at its source.

The original identity map did not work: q( f ) = 0 while q0( f ) = 1. Matching Arf invariants guarantees a
correction here, not the validity of an unchanged map. More generally, a defect vanishing on a subspace
U gives a defect vector in U⊥, so the transvection fixes U pointwise.

The correction fixes quotient vectors, not automatically independently fixed lifts above them. Its use in
an arithmetic diagram requires permission to change the embedding and a separate check of the relevant
section and phase data.





Evidence: Exact four-vector correction.

PLATE XI.26

The defect vector supplies a decision procedure

The same formula displays both the successful correction and its genuine obstruction.


                       q0 = q + B(a, −)



        defect a           q(a)       mismatched vectors         T_a correction

         0             0                0                    works

          e             0                0                    works

                 f             0                0                    works

         e+f            1                2                              fails



            When q(a) = 1, Arf changes and the obstruction is genuine.





For the fixed hyperbolic plane q = xy, every refinement with the same polar form is q0 = q + B(a, −)
for one vector a. The table lists all four defect vectors. Its mismatch column counts the vectors at which
q0(Tav) ̸= q(v).
                     q0(Tav) = q(v) + B(a, v)q(a),     Arf(q0) + Arf(q) = q(a).

When q(a) = 0, the correction works everywhere. For a = e + f, the Arf sign changes and two vectors
still fail. This is not an unlucky choice of basis. In equal dimension, the two forms are not isometric.

In a larger host this test applies to the pullback along the supplied embedding. A different permitted
subspace may behave differently. Under genuine supplied actions preserving both refinements and an
initially equivariant embedding, the defect vector is fixed by the group. The same transvection is then
equivariant. Those initial actions are hypotheses, not outputs of this linear solve.





Evidence: Exact defect enumeration.

Companion source: Part III, Section 28. Book page 1583.

An odd-order action discrepancy can be summed
away

The correction acts on a supplied finite extension, not on an unconstructed arithmetic host.


                     u = ∑δh = e
                                   h




     group element        delta_g          g u            u + delta_g + g u

          1              0              e                   0

          g              e+f                      f                   0

            g²                          f             e+f                  0



                             g(x, y) = (y, x + y)  on F22




Let C3 act on A = F22 by g(x, y) = (y, x + y). Use the cocycle values δ1 = 0, δg = e + f, and δg2 = f. Their
sum is u = e. The final column displays the corrected discrepancy, which is zero at every group element.

                               δgh = δg + gδh,    u = ∑ δh,     δg = u + gu.
                                                                h

The last identity follows by summing the cocycle equation and using that the group order is odd in
characteristic two. Replacing the comparison by the vertical sign correction u makes it equivariant.

In the extension theorem, the source and target already have genuine actions and an initial center-fixing
extension isomorphism. The cocycle lives in the character space Hom(W, F2). The diagram is an exact
module example of that calculation, not a new construction of those actions. A vertical correction may
also be forbidden when particular lifts must remain unchanged.

PLATE XI.28

The even-order negative control

A nonzero cocycle survives when every permitted coboundary vanishes.



                C2 acts trivially; the cocycle has delta_s = e.



           candidate u                u + s u               remaining delta_s

             0                       0                       e

              e                       0                       e

                         f                       0                       e

             e+f                      0                       e



             Every permitted coboundary is zero. None removes this cocycle.




Let C2 = {1, s} act trivially on the nonzero module A = F22. The assignment δ1 = 0, δs = e satisfies the
cocycle equation, since e + e = 0. For every proposed correction u,

                         u + su = u + u = 0,    u + δs + su = e.

The four rows exhaust the module. None removes the discrepancy. Thus the odd-order hypothesis of
the preceding plate is mathematically active.

This does not say that every even-order action problem is obstructed. It supplies one exact counterex-
ample to an unrestricted averaging claim. Other actions and cocycles may admit corrections. In the
arithmetic problem, it remains necessary to compute the actual discrepancy and respect the permitted
transformations. Declaring every projective or equivariance mismatch removable would erase precisely
the information this example retains.





Evidence: Exact obstruction model.

Companion source: Part III, Section 29.2. Book page 1586.
