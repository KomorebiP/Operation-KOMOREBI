5.1 When a finite empty level is an actual certificate

For polynomial equations with integral coefficients, or rational equations whose denominators remain
units, a fixed finite residue template gives a finite test at each precision. If the template exactly describes
X modulo ϖn, then emptiness of its complete solution set certifies failure of that fixed template. If there
is no exact solution in the fixed compact model, Theorem 5.1 guarantees some empty level.

This is a semidecision procedure for nonexistence within that model.  It provides neither a uniform
bound on the first empty level nor a proof that a partial search was exhaustive. A failed random search,
a resource cutoff and an actual empty finite level have different logical meanings.

Example 5.2 (Individual equations are not simultaneous solvability). Over Z2, the equations x = 0
and x = 1 are each soluble to every precision. They have no common solution even modulo two. The
nonempty sets needed in Theorem 5.1 contain joint solutions to the first n equations, not a separate
solution for each equation.

Example 5.3 (A nonclosed admissibility condition can disappear). The elements xn = 2n are nonzero
in Z2 and satisfy xn ≡0 (mod 2n). Their limit is zero. A requirement such as x ̸= 0, or an unspeci-
fied nonzero determinant, is not automatically a closed condition. A fixed unit leading coefficient or a
prescribed nonzero residue class is a different condition and can survive the limit.


5.2 The actual matrix binder obligation

The retained matrix template uses a square-zero variable x and expressions of the form

                 Q(x) = −s(xb0x),     β(x) = γ′ + [x, b0] −xb0x,     x2 = 0.

The purpose is to force desired corestriction and leading-lane behavior inside actual matrix algebras.
Compactness can assemble solutions only after the source-to-equation encoding is faithful, the admissi-
bility conditions define a closed fixed template, and every finite collection of equations is jointly soluble.
The general H1–H4 assumptions have not been proved to imply those three facts. The binder theorem
therefore sharpens the realization problem without closing it.
