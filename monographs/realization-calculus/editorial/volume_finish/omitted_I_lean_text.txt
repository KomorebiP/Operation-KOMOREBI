C Guide source, data, and reproducibility
The editable guide directory contains this LATEX source, exact source excerpts, generated contract and
import tables, machine-readable JSON, and build_guide_data.py. The historical data generator is read-
only with respect to the preserved formal component. It imports the preserved verifier’s comment-
aware scanning function, compares source and log hashes, reconciles map inventories, and extracts
listings. It never invokes Lean.
From editable/lean_guide/ in the source archive:
python3 build_guide_data.py \
--source ../../source/traditional_v1.3.1
xelatex -interaction=nonstopmode -halt-on-error \
Paper_I_Lean_Guide_Final.tex
xelatex -interaction=nonstopmode -halt-on-error \
Paper_I_Lean_Guide_Final.tex
xelatex -interaction=nonstopmode -halt-on-error \
Paper_I_Lean_Guide_Final.tex
The correspondence section is generated separately from the reviewed inventory. From the source
archive root:
python3 scripts/build_release_companion_data.py \
--coverage formal/coverage/COVERAGE_108.json
Pass --metadata with the companion evidence JSON to reproduce the recorded verification summaries.
This step preserves every coverage classification and never executes Lean. It also regenerates the current
machine catalog from the same statements and proofs.
The PDF uses P052, Nimbus Sans, DejaVu Sans Mono, and Latin Modern Math fonts with XeLaTeX.
A TeX installation must provide the packages listed in the preamble. Rendering the resulting PDF is a
separate presentation check. It is not a Lean verification step.
