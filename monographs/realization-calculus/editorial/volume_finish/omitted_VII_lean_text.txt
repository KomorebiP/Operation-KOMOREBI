8.4 Rebuild only this guide
The guide directory contains the authored TeX, frozen navigation, rendered code, raw excerpts, styles
and font licenses. Font binaries are not included in this delivery. The styles use the matching bundled
fonts when those are supplied and otherwise use the named installed fonts. The script build.py copies
the complete source tree to an isolated temporary directory. It performs four XeLaTeX passes to re-
solve the document structure, then runs xdvipdfmx once to produce the PDF. It compiles the authored
document without regenerating prose, source data, figures or mathematical evidence, and it does not
invoke Lean.
python editable/lean_guide/build.py
python editable/lean_guide/build.py --output-directory /path/to/pdf_rebuild
python editable/lean_guide/build.py --check-only
Run these commands from the package root, or supply an absolute path to the script. Python 3,
XeLaTeX, xdvipdfmx and the TeX packages named in the preamble are required. Fonts resolve through
the relative fonts/ directory when the matching binaries are present. Otherwise the styles use installed
P052, Nimbus Sans, Latin Modern and DejaVu Sans Mono fonts. The optional --output-directory
keeps delivered products unchanged, and --check-only writes no delivered products.
Regenerating the source tables additionally requires FontTools and the preserved snapshot. The as-
sembler uses the bundled DejaVu Sans Mono and Latin Modern Math files when present, or matching
installed files otherwise. Run the following commands only when regenerating the tables as part of an
edited release. Refresh the recorded checks and document hashes afterward.
python editable/lean_guide/assemble.py
python editable/lean_guide/static_check.py
python editable/lean_guide/build.py
python editable/lean_guide/verify_pdf.py
Both source scripts accept --source PATH for a relocated snapshot. Assembly stops if counts, inven-
tory, saved axiom sets or source identities disagree. A new source edition requires a deliberate revision

8.5 Replay the formal development with the pinned kit
With the separately supplied pinned portable kit, set the working directory to source/complete/Paper_
VII_Complete_v0.6.0_With_Visual_Appendix/original_snapshot, relative to the package root. Choose
a new output directory to preserve the inherited evidence.
python scripts/verify.py --kit /path/to/kit \
--out verification/my_run --timeout 240
python scripts/audit_constructions.py --kit /path/to/kit \
--run verification/my_run
python scripts/test_verifier.py
The verifier checks runtime version and Mathlib revision, then compiles local modules in depen-
dency order with one worker and strict warnings. It compares emitted axiom audits with the exact
inventory and checks both deliberate invalid controls. The construction audit uses the fresh run’s ac-
tual build interfaces. It rejects stale source or interface identities.
For short execution windows, the retained checkpoint mechanism can pause after a few checks:
python scripts/verify.py --kit /path/to/kit \
--out verification/my_run --timeout 240 \
--max-checks 3 --resume
Repeat until the verifier reports complete success. Exit code 2 means paused or incomplete. Resume
checks the verifier, runner, inventory, source dependencies and both public and private interfaces be-
fore trusting a cached module. An interrupted build remains incomplete even when earlier modules
passed.
The check_low_memory.py launcher uses ordinary Lean with one worker. Its name does not promise
an enforced memory cap. The snapshot is not a delivered Lake project with a current lakefile. Its
provenance manifest supplies the portable kit’s locked dependencies. A bare lake build would not
reproduce the retained procedure.
