## Rebuild the book

Install a TeX distribution with pdfLaTeX and the packages named in `book/monograph.sty`, including `newpxtext`, `newpxmath`, `tikz`, `tcolorbox`, and `bookmark`. From this directory, run:

```text
python build.py
```

The builder performs three passes and copies the resulting PDF to the package root. It writes compilation logs under `verification/typesetting/`. Font binaries and TeX distributions are not bundled.

## Replay the numerical checks

The recorded replay used Python 3.13.5 with NumPy 2.3.5, SciPy 1.17.0, mpmath 1.3.0, and pandas 2.2.3. In a suitable isolated environment:

```text
python -m pip install -r requirements-engine.txt
python replay.py --include-controls
```

The runner creates a new timestamped log directory rather than overwriting the recorded results. It hashes the engine source before and after execution. The recorded run passed all 60 test methods with no failures, errors, or skips. Both independent numerical controls also passed.

The exact algebra check for the range-core correction can be replayed with SymPy installed:

```text
python verification/check_range_core.py
```

These are finite tests, not a universal proof of the implementation. The directed enclosure remains conditional on the interval library's arithmetic and transcendental implementation.

## Mathematical correction and preservation

All 61 numbered source environments are retained: 55 theorem, lemma, proposition, or corollary statements, five remarks, and one algorithm. The number of proof environments is 39 in the corrected volume. The inventory is a preservation check, not an independent proof audit.

The range-core, QR-update, and residual-completion statements distinguish nonzero spectra from complete core spectra. The frontier-to-I/O proof now distinguishes compressed and ambient operators. The noncentral shift and saddlepoint domains are made explicit. See `VERIFICATION_REPORT.md` for the full correction record.

The exact range-core statement is corrected. When an orthonormal captured basis merely contains the range of the factor, unused directions may add zero eigenvalues to the core. The nonzero spectra agree with multiplicity. Agreement with the *entire* core spectrum additionally requires the captured basis to span exactly the factor range. The revised proof, an exact counterexample, and a worked calculation are included in Chapter 4 and `verification/range_core_correction.json`.

The interval reporting patch computes widths before converting endpoints to binary64. It does not change the authoritative probability intervals or the directed acceptance rule. The corrected table and figure are generated by:

```text
python verification/proofread_checks/recompute_widths.py
python verification/proofread_checks/exact_algebra.py
python verification/proofread_checks/audit_publication.py
```

These auxiliary checks require SymPy, Matplotlib, and PyMuPDF in addition to the engine dependencies. The supplied baseline inventory makes the static audit independent of the original ZIP. Exact inputs and change records are retained under `verification/proofread_checks/`.

## Formal verification boundary

The retained Lean evidence covers 26 theorem declarations and eight definitions, with a 34-declaration axiom audit. It covers finite algebra and consequences of supplied bounds, not the complete probability analysis or numerical implementation. No new Lean compilation was performed for this monograph. The appendix and `VERIFICATION_REPORT.md` keep that distinction explicit.
