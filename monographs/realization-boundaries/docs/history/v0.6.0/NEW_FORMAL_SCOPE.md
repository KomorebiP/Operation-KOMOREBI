# Formal scope added in v0.6.0

Five production modules extend the prior 31-module development.

- `RootFibers`: actual root and kernel types, explicit coordinate-kernel additive equivalence, translation/coset equivalence, complete root parametrization, finiteness.
- `RadicalCounts`: distinct-prime product, cardinal derivation, exact soluble/obstructed root counts, equality of original radical and integer multiples, quotient cardinal.
- `CyclicQuotients`: actual CRT ring equivalence, cyclic integer quotient, cyclic enumeration of roots, genuine quotient transition and canonical residue-reduction square.
- `CyclicFiniteTargets`: every finite quotient is cyclic squarefree, the constructive converse, exact kernel of any finite surjection.
- `RootConsequences`: coordinatewise normalized root and its uniqueness, unrestricted uniqueness iff m=1, prime-power fiber sizes, and the infinite/nonempty zero-multiplier boundary.

This does not complete the book. Countable-code and infinitely repeated diagonalization semantics, the general graph theorem, subgroup-spectrum classification, rational-dimension clauses, finite-generation structure, oracle semantics, and exact Pro-category interfaces retain their own coverage states.
