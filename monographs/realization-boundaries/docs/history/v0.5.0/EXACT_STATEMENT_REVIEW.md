# Exact statement review — v0.5.0

The source and exported types were compared with the preserved LaTeX statements labeled `thm:rankD`, `thm:procyclic`, and `thm:rankGA`.

## Generation contracts

`endomorphismHull` is the additive subgroup generated by actual images of seeds under all actual additive endomorphisms. Every finite composition is included, and the identity includes each seed. `endomorphismHull_invariant` proves the resulting subgroup invariant. The universal property is not assumed.

`topologicalEndomorphismHull` is the closure of that subgroup inside the original topological group. `ordinaryTopologicalHull` is the closure of the ordinary generated subgroup. A theorem compares them, but the definitions are not identified.

`generationCardinals` quantifies over actual subsets with their true cardinalities. `generationRank` is its infimum. The aleph_0 results are obtained from `generationCardinals_isLeast_aleph0`, which supplies a genuine generating subset and proves minimality. No seed-rank value is inserted into a structure as a field.

## Omitted coordinates

For D every seed has finite total support. For a selector group only support outside the selected set is finite; the marked vector is an explicit counterexample to total finite support. The proof chooses an omitted prime through the injective omitted-index map, so the obstruction cannot be exhausted by finitely many seeds.

`coordinateKernel_closed` uses the inherited actual product/subgroup topology with discrete finite Hausdorff coordinate groups. `coordinateKernel_ne_top` uses the actual prime seed, not an assumed nonzero witness. No continuity hypothesis is imposed on an arbitrary admitted endomorphism: zero preservation was already derived algebraically.

## Product and canonical completion

`finite_coordinate_interpolation` quantifies over any finite set of actual distinct primes and any ambient coordinate vector. Pairwise coprimality is proved from primality and inequality. `ambient_cyclic_dense` then quantifies over every nonempty open set in the product topology. The generator is the actual all-one vector.

The rank-one theorem includes both the singleton upper witness and the nontrivial Hausdorff zero-generator lower bound. `completionGenerator` is in Mathlib's canonical completion and is transported by the existing proved continuous additive equivalence. `paired_seed_rank_separation` includes the canonical completion conclusion in addition to all original-group rank statements.

## Boundary controls

The all-one generator is outside every paired original group and its completion version is outside the original eta range. Its ordinary cyclic subgroup is proper, witnessed by every nonzero prime seed, while its ordinary topological closure is the full product. Allowing every endomorphism yields algebraic generation from one, because arbitrary coordinate multiplication is available. This last statement has an explicitly different operator contract and does not imply finite effective specification.
