Five production modules add 51 explicitly named theorem/lemma declarations. They formalize finite-seed non-generation, least cardinal ranks, actual product-topology cyclicity, and exact transport to canonical completions. The proof-bearing objects are the original infinite groups.

| Module | Principal result |
|---|---|
| SeedGeneration | True orbit-generated subgroup and closed invariant-coordinate certificate. |
| SeedObstructions | Missing coordinates for every finite seed family in D or G_A. |
| GenerationRanks | IsLeast proofs for the actual algebraic and topological rank definitions. |
| Procyclic | Finite CRT interpolation, dense ordinary cyclic subgroup, and rank one of actual completions. |
| GenerationConsequences | Generator absent from original groups; proper ordinary cyclic subgroup; full-operator contract separated. |
