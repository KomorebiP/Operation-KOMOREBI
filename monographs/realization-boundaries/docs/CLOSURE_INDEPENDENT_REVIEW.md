## Findings

**3.1 — exact numbered theorem covered.** The subgroup is an additive subgroup
of the actual D, not an unrelated abstract direct sum. CRT is applied on the
finite support of an arbitrary member and normalizes a nonzero prime coordinate
to the actual prime seed. Finite decomposition proves the converse inclusion.
The resulting order isomorphism is onto every subgroup. Full invariance follows
from the accepted arbitrary-endomorphism zero-coordinate theorem. Abstract
isomorphism classification uses an intrinsic nonzero p-annihilated-element
predicate and does not assume an isomorphism preserves the ambient coordinates.
Union, intersection, and complementary internal decomposition are checked.
The unnumbered paragraph asserting a Cantor-space homeomorphism is not covered
by this source; it should not be claimed solely from the order isomorphism.

**3.2 — continuum clause covered; one narrow interface addition requested.**
The observation fiber contains exactly all selectors agreeing on an arbitrary
finite set of primes. A concrete injection of all subsets of N into that fiber,
and its inclusion into all prime subsets, establish exact continuum cardinality.
Distinct fiber points yield nonisomorphic actual groups by 3.1. The final theorem
in this source establishes uniqueness if two global selectors agree on every
finite observation. It does not by itself state existence for an independently
supplied compatible family of patterns. This review requested that addition;
`ObservationPatternClosure.lean` supplies it separately. No defect was found in
the continuum argument.

**3.5 — exact numbered theorem covered.** `UnaryMachine` has an actual finite
state space and acceptance after iteration of one transition, matching a DFA on
unary words. Finite-state orbit repetition proves ultimate periodicity. The
converse uses the finite range of future acceptance tails as states and proves
its transition and acceptance sequences exactly. The final group theorem uses
prime-spectrum isomorphism classification, so a different accepted selector
cannot become equivalent merely by abstract group isomorphism. No claim is made
that these classical existence constructions provide an effective implementation
from a non-effective periodicity witness; the printed theorem is existential.

**1.5 — exact contract covered.** Valid descriptions are a subset of finite
strings over a countable alphabet, with arbitrary single-valued semantics. Both
countability of the output set and its cardinal bound are proved. The target
can be the set of group isomorphism types, so the generic value theorem gives
the printed group-type claim. No semantic computability is assumed.

**1.8 — exact contract covered.** `packetSum` is the actual dependent
finite-support direct sum of abelian packets. Its finite packet decomposition is
proved. Transfer vanishing is imposed on every primitive additive endomorphism
and arbitrary vector in each source packet. `GraphReach` is identified with the
standard finite reflexive-transitive path relation, including empty words. The
hull is generated by all finite primitive words applied to seeds; support
confinement is then proved through an invariant subgroup. The omitted nonzero
packet gives a non-generation certificate. The topological variant separately
requires continuity of the packet projection into a Hausdorff packet and uses
its closed kernel. Reachability is used only as a necessary condition.

**10.1 — exact contract covered.** Repeated even-coordinate diagonalization
opposes each chosen semantic representative infinitely often. Family membership
is used only under a classical existence branch, with no hidden computability
claim. Odd-coordinate blocks repeat each free bit infinitely often, giving
infinite disagreement for every pair of distinct free inputs. The accepted
unmarked classification and arbitrary-homomorphism obstruction then give
nonisomorphism and no embeddings in either direction. Cardinality is exact
continuum for the actual subgroup range, with pairwise nonisomorphism proved
separately, hence also continuum many isomorphism types. Countability,
reducedness, residual finiteness, and the actual common canonical completion are
preserved. The countable-code extension uses an injection into N and handles
empty or finite code domains through dummy selectors. This is relative escape
from a fixed grammar, not an effective evaluator or absolute indescribability.

**10.2 — exact contract covered.** Semantic translation preserves realizability.
The source shortest length is an actual attained natural-number minimum, so
translating a shortest source description proves the stated overhead inequality
without requiring monotonicity of the overhead function. `WithTop N` complexity
also makes nonrealizability equivalent to infinite complexity. Allowing the
semantic relation to be more general than single-valued grammar outputs makes
the preservation theorem stronger, without changing its application to the
printed grammars.

**8.2 — genuine oracle lower bound covered.** `OracleComputable` is the native

addition proved oracle computable. Equality on these names is ordinary numeric
equality. Repeated addition is constructed by native primitive recursion.
Candidate prime-root tests use this addition and the separately proved

because one actual equation has a root and reads the correct Boolean bit. The

The `RootSearchPresentation` interface alone would be only a conditional
computability lemma. The crucial `OracleGroupCopy.rootSearch` construction proves

**8.3 forward — exact existential lower bound covered; reverse still needed.**
`oracle_unmarked_copy_reduces` uses a valid simpler nonuniform argument than the
printed tail-signature proof: the arbitrary copy bijection has some natural
name for the particular canonical marker, and that one finite natural constant
can be hard-coded into the marked decoder. This does not discover the name
uniformly from an unmarked diagram. Existence of such a name is enough for an
existential Turing reduction. No finite exception bound or tail oracle is
silently supplied. The result is exactly the forward implication that every
oracle-computable copy computes the selector. These lower-bound sources do not
construct an actual oracle-computable copy from selector access, so they do not
by themselves establish the reverse implication, the full iff, or the least
presentation-degree and every-degree conclusions. Those require the actual
upper construction of 8.1.

**3.3 forward — actual semienumeration from an infinite coded copy covered.**
The copy's candidate nonzero p-torsion test is constructed from finite repeated
addition and numeric equality. Native partial minimization has domain exactly
the set of primes with a witness. The intrinsic prime-spectrum theorem then
identifies that enumerable set with the selector. The source contract uses a
bijection from N and therefore applies to infinite copies. Finite selector
groups use the separate finite-domain convention in the book; this source does
not represent them by an impossible bijection from N. The c.e.-selector-to-copy
converse also remains a separate upper-construction obligation. Accordingly
3.3 is not fully closed by these lower bounds alone.

No mathematical defect was found in the reviewed structural or oracle
lower-bound statements. The distinction between lower directions and an actual
copy construction must be preserved in coverage status.

## Historic status normalization for 2.6

The printed 2.6 statement has no topological or algorithmic clause: it asserts
positive-integer bijectivity on the actual quotient P/D, a unique rational module
structure extending that additive group, and no nonzero divisible subgroup of P.

constructing an actual additive equivalence to its divisible hull, and proves
that all such module structures form a subsingleton. `Extensions.lean` proves
every homomorphism from an arbitrary divisible additive group to P is zero and
excludes every injective map from a nontrivial divisible group. This proves the
printed reducedness assertion, rather than only exclusion of rational summands.
The old `COMPLETE_ALGEBRAIC` label describes the subject matter, not a remaining
printed obligation. Normalize it to `COMPLETE` while retaining these exact
accepted declarations as evidence. No theorem change is necessary.
