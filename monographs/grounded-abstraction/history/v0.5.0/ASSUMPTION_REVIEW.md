# Internal assumption review

This review concerns all sixteen statements in the expanded edition. It is an authored mathematical review, not independent peer review or a proof-kernel transcript. Familiar factorization, quotient, hypothesis-testing, invariant-subspace, and perturbation arguments are not claimed as newly discovered foundations.

| Statement | Essential assumptions | Proof route and limit |
|---|---|---|
| Proposition 3.2 | Finite candidate worlds and record alphabets, specified protocol laws, a common target language. A decision sees only its record and independent randomization. | Factor through the family of laws, then through each attainable record's support. Different laws need not give disjoint finite-record supports. No law-estimation or sample-rate guarantee. |
| Theorem 3.4 | Nonempty finite state set, total deterministic operations, common observation map, specified initial record, no later hidden-state access. | Behavioral equivalence is operation stable. Evidence must separate its classes to initialize the quotient. Minimality counts initialized states, not encoder complexity, acquisition work, or causal use. |
| Theorem 4.1 | Finite immutable worlds, finite total nondestructive tests, every test remains available, fixed target and old record. The cost statement concerns one fixed test set used for every initial code. | Evidence factorization gives a pair-cover condition. A pair indistinguishable under every test remains so under adaptive choice. Destructive or history-dependent tests can invalidate the composition argument. |
| Theorem 5.2 | All candidate subsets, including empty, a fixed target, and an evidence family containing the universe and closed under intersection. Filtering does not change the underlying world. | Intersection closure makes correction-signature equality a congruence. A differing coordinate is a one-filter distinguishing witness. Only the declared evidence and target are preserved. |
| Corollary 5.3 | Evidence consists **exactly** of the unions of a fixed partition. All candidate subsets are admissible. | Occupancy of attainable atom/target intersections gives exactly 2^r signatures. Extra cell-splitting events can invalidate this memory, and restricted reachable candidate sets can reduce its size. The evidence hypothesis was tightened during review. |
| Proposition 6.1 | Two worlds with different targets, equal prior weights, one fixed actual transcript law, a common processing channel. | Every correct target decision yields a correct binary test. The positive part of the likelihood difference gives the total-variation bound. No protocol optimality or independent-sample assumption is inferred. |
| Theorem 7.1 | Nonempty finite prediction sets in fixed R^d coordinates, infinity norm, unrestricted real-vector centers. Random-set coverage and uniform model-error events are separately assumed. | Coordinate extremes give the exact radius. A triangle inequality and union bound give the certificate. The model-error and numerical tolerances are nonnegative. Empty sets cause abstention. Coverage is not certified by a small radius, and conditioning on issuance requires a new argument. |
| Proposition 9.1 | Exact consistent linear calibration on U, a known input vector, and every linear extension to V allowed. | A linear functional vanishing on U changes the response outside U. Structural priors, common constraints between actions, and norm restrictions can change this identifiability region. |
| Theorem 9.2 | Finite-dimensional vector space, nonempty finite action set, fixed independently unrestricted linear extensions of the calibrated maps, full-state output. | A descending subspace recursion identifies inputs whose first n-1 intermediate states stay calibrated. At the first exit, two fixed completions disagree on the next operation. The stable core is maximal. The new Proposition 11.1 shows that a nonzero smaller observation has the same identifiable domain under this unrestricted completion class. Structured candidate families require the separate results below. |
| Proposition 10.1 | Bounded linear actual maps on the entire ambient normed space, bounded linear nominal maps preserving L, a relative discrepancy bound on L, and common nonnegative operator bounds. | Propagate the difference along nominal states in L while the ambient bound controls errors outside L. Purely local calibration cannot establish that ambient bound. No contraction or unlimited-error-free reuse follows without further hypotheses. |


| Theorem 8.1 | Finite fixed worlds, finitely many always-available nondestructive experiments with exact likelihoods, and fresh conditional reports. Every prior is included. The memory must preserve both report probabilities and target posteriors, not just target posteriors alone. | Joint likelihood-profile/target masses are closed under Bayes updates. Interpolation on the distinct likelihood profiles recovers each cell from joint target/history probabilities of length at most m-1. Impossible reports do not receive arbitrary posteriors. Minimality is an equivalence-on-priors statement, not a bit count or stable numerical inversion. |
| Corollary 8.2 | Old and new probability memories are cell masses on partitions of the same finite world set. The reconstruction must work for every prior. | Aggregation is possible exactly when the old partition refines the new one. Point masses refute reconstruction after an old cell is split. Reachable-prior restrictions or new observations may change the answer. |
| Proposition 11.1 | Nonzero linear observation Q; known initial vector; the full independently unrestricted linear-extension class of Theorem 9.2, fixed throughout each word. Q=0 is explicitly separate. | At the first uncalibrated input, a rank-one modification can direct uncertainty into any nonzero output. Thus smaller output does not enlarge the domain under this class. A structural prior restricting discrepancy propagation changes the premise. |
| Theorem 12.1 | Finite family of supplied linear maps on the same finite-dimensional space, fixed shared observation, and all finite words over a finite nonempty alphabet. One model index remains fixed. | Block-diagonal paired dynamics and a descending difference kernel give an exact all-word test after finitely many rank changes. A provenance-tracking row construction gives a finite distinguishing word. The illustration code tests subspaces and direct finite words; it is not a general exported witness-generation library. The identifiable initial set need not be invariant. |
| Theorem 13.1 | Same finite model family and action set. The first condition is agreement as linear maps on the entire state space, not only selected initial states. | The invariant closure of all discrepancy images must lie in the output kernel. It gives a common quotient, and the largest reference-unobservable subspace gives the smallest common linear quotient. The shared quotient also supports arbitrary model switching; that conclusion fails for the weaker restricted-initial-state premise. |
| Theorem 14.1 | Initial linear subspace L lies in the fixed-model agreement set. Initial evidence R and all proposed predictor maps are linear. Reference reachability and observability include every finite word. | The initial evidence kernel must lie in the future-unobservable subspace. The reachable/observable quotient is sufficient, and every competing linear realization maps onto it. Minimality is linear state dimension, not arbitrary code length or physical memory. The reference reachable space need not be the physical trajectory space of every candidate. |

## Specific controls

The examples distinguish a common initialized predictor from separate worldwise predictors; nondestructive pair separation from destructive tests; preserved marginals from preserved corrective association; identifiable laws from finite-record certainty; narrow model agreement from coverage of the true world; first-step calibration from an invariant domain; and local residual from global error growth.

The small exact program uses independent elementary calculations where practical. Both implementations are authored within this project. No passing count substitutes for the proofs or authenticates their external interpretation.
