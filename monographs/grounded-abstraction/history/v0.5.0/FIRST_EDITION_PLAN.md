# First-edition scope and closeout plan

**Working edition: v0.5.0.** The intended first edition is a theory of evidence-supported abstraction, not an implemented general learning system.

The first-draft finite identification, correction signatures, and calibrated-core results are retained. This edition adds exact noisy correction memory, memory migration, fixed-model output agreement, structured uncertainty quotients, and minimal evidence-initialized linear prediction.

Before a 1.0 freeze, prioritize one common claim/dependency ledger, final assumption and notation review, and a consolidated running example joining evidence acquisition, retained memory, and observable continuation. Decide explicitly whether one bounded approximate-output theorem belongs in the frozen scope or remains a subsequent research extension. It is not necessary to solve every generalization.

A release checklist should confirm all statement/proof pairs, source lineage, zero-probability and zero-output cases, non-invariant agreeing initial spaces, fixed versus switching models, exact masses versus finite storage, actual source review, clean compilation, visual review, small exact reruns, and frozen archive integrity. The outcome should keep closed conditional results distinct from applications whose premises remain unestablished.

Large-scale learning, autonomous model-class invention, neural attribution, and cross-domain benchmarking are deferred applications rather than first-edition completion criteria. Independent peer review and proof-assistant formalization are separate evidence levels, not facts supplied by the version number.
