# Next mathematical questions

The next revision should strengthen the present argument rather than introduce a large agent implementation.

## 1. Output-relative calibrated continuation

The current core theorem preserves complete vectors. For an observation map Q, seek the largest domain on which Q T_w v is fixed across every compatible operator completion and every admitted word. Hidden uncertainty can be harmless now and return to the observed coordinates later. Intersecting observability kernels for one chosen completion is not automatically valid for the whole compatible family.

## 2. Approximate correction memory

Extend the exact correction signature to likelihood updates and quantify the memory needed for a prescribed posterior or decision tolerance. Keep average loss, worst-record error, rare conditioning, and model misspecification separate. A useful restricted theorem would connect a retained statistic to a uniform bound after a bounded number of future updates.

## 3. Evidence and model-class revision

Adding a candidate model or a new evidence event can invalidate an old sufficient memory. Characterize when old compressed records can be lifted to the enlarged contract, which new measurements suffice, and which discarded associations cannot be reconstructed. Changes to the target alone do not establish an available acquisition channel.

A precise theorem in one of these directions is a complete next contribution. Training, large benchmarks, and an integrated agent are deferred applications, not prerequisites.
