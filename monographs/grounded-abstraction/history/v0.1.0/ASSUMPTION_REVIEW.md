# Internal assumption review

This review concerns the ten statements in the draft. It is an authored mathematical review, not independent peer review or a proof-kernel transcript. Familiar factorization, quotient, hypothesis-testing, invariant-subspace, and perturbation arguments are not claimed as newly discovered foundations.

| Statement | Essential assumptions | Proof route and limit |
|---|---|---|
| Proposition 3.2 | Finite candidate worlds and record alphabets, specified protocol laws, a common target language. A decision sees only its record and independent randomization. | Factor through the family of laws, then through each attainable record's support. Different laws need not give disjoint finite-record supports. No law-estimation or sample-rate guarantee. |
| Theorem 3.4 | Nonempty finite state set, total deterministic operations, common observation map, specified initial record, no later hidden-state access. | Behavioral equivalence is operation stable. Evidence must separate its classes to initialize the quotient. Minimality counts initialized states, not encoder complexity, acquisition work, or causal use. |
| Theorem 4.1 | Finite immutable worlds, finite total nondestructive tests, every test remains available, fixed target and old record. The cost statement concerns one fixed test set used for every initial code. | Evidence factorization gives a pair-cover condition. A pair indistinguishable under every test remains so under adaptive choice. Destructive or history-dependent tests can invalidate the composition argument. |
| Theorem 5.2 | All candidate subsets, including empty, a fixed target, and an evidence family containing the universe and closed under intersection. Filtering does not change the underlying world. | Intersection closure makes correction-signature equality a congruence. A differing coordinate is a one-filter distinguishing witness. Only the declared evidence and target are preserved. |
| Corollary 5.3 | Evidence consists **exactly** of the unions of a fixed partition. All candidate subsets are admissible. | Occupancy of attainable atom/target intersections gives exactly 2^r signatures. Extra cell-splitting events can invalidate this memory, and restricted reachable candidate sets can reduce its size. The evidence hypothesis was tightened during review. |
| Proposition 6.1 | Two worlds with different targets, equal prior weights, one fixed actual transcript law, a common processing channel. | Every correct target decision yields a correct binary test. The positive part of the likelihood difference gives the total-variation bound. No protocol optimality or independent-sample assumption is inferred. |
| Theorem 7.1 | Nonempty finite prediction sets in fixed R^d coordinates, infinity norm, unrestricted real-vector centers. Random-set coverage and uniform model-error events are separately assumed. | Coordinate extremes give the exact radius. A triangle inequality and union bound give the certificate. The model-error and numerical tolerances are nonnegative. Empty sets cause abstention. Coverage is not certified by a small radius, and conditioning on issuance requires a new argument. |
| Proposition 8.1 | Exact consistent linear calibration on U, a known input vector, and every linear extension to V allowed. | A linear functional vanishing on U changes the response outside U. Structural priors, common constraints between actions, and norm restrictions can change this identifiability region. |
| Theorem 8.2 | Finite-dimensional vector space, nonempty finite action set, fixed independently unrestricted linear extensions of the calibrated maps, full-state output. | A descending subspace recursion identifies inputs whose first n-1 intermediate states stay calibrated. At the first exit, two fixed completions disagree on the next operation. The stable core is maximal. It is not the output-relative domain for a smaller observation. |
| Proposition 9.1 | Bounded linear actual maps on the entire ambient normed space, bounded linear nominal maps preserving L, a relative discrepancy bound on L, and common nonnegative operator bounds. | Propagate the difference along nominal states in L while the ambient bound controls errors outside L. Purely local calibration cannot establish that ambient bound. No contraction or unlimited-error-free reuse follows without further hypotheses. |

## Specific controls

The examples distinguish a common initialized predictor from separate worldwise predictors; nondestructive pair separation from destructive tests; preserved marginals from preserved corrective association; identifiable laws from finite-record certainty; narrow model agreement from coverage of the true world; first-step calibration from an invariant domain; and local residual from global error growth.

The small exact program uses independent elementary calculations where practical. Both implementations are authored within this project. No passing count substitutes for the proofs or authenticates their external interpretation.
