## Reproduce and continue

Run `bash build.sh` for the offline publication build. See `BUILD.md` for local dependencies, exact commands, and the distinction between publication checks and Lean replay. Run `python3 checks/verify_payload.py` to check the delivered manifest before rebuilding. `PROGRESS_LEDGER.md` gives the next restart point, and `REVIEW_NOTES.md` records the corrections and remaining obligations.

The mathematics remains relative to specified views, coefficients, covers, protected observables, and analytic assumptions. This edition does not claim one universal space containing all mathematics, unrestricted arithmetic realization, a general infinity-stack theory, or an empirical machine-intelligence result.
