## Interpretive integration corrections

The first edition separates original-controller improvement from the later compiler and acquisition changes, so an old paragraph is not read as denying the later constructions. It distinguishes a changed conclusion from a false proof, and a blocked certificate from a mathematical refutation. It also presents the existing Hyperagents meta-level claims as reported work rather than implying that all prior agents only improve task behavior.

All earlier 28 formal statement-and-proof blocks remain verbatim. No new universal statement is inferred from an assertion count. The new graph manager is a narrow reference implementation whose supplied dependency completeness and primitive checker soundness remain outside its numerical evidence.
