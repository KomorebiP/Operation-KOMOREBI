# Claims and boundaries

| Object | Status in this draft | What is not inferred |
|---|---|---|
| Exact finite diagnostic compiler | Implemented and cross-checked against unpruned tree enumeration on the declared small domains | Efficient synthesis on arbitrary environments |
| Eight-cell diagnostic improvement | One compiled policy, checked on all eight cases under the same query language and fixed budget | Neural abstraction discovery or a self-improving compiler |
| Execution and compiled storage | One tree witnesses both bounds; all branches count | Universal minimal bytecode, compressed-DAG or hardware runtime |
| Whole-investigation transport | Proved for supplied exact correspondences; affine cell relabelings checked | Learned alignment or generalization to genuinely new task structure |
| Least stable representation refinement | Finite complete-table proof and bounded cross-checks | Acquisition of the transition model from partial data |
| Selection and lineage error control | Conditional arguments with explicit uniform or conditional validity assumptions | Ordinary confidence bounds remaining valid after uncharged adaptive data reuse |
| Recursive progress | Finite fully observed common-policy criterion with justified event markers assumed | Unrestricted program synthesis, inevitable future gains or acceleration |
| Proposed Neuralese/OSL architecture | Specified conceptual interfaces and learning targets | A complete trained bridge or historical proof that the integrated system works |
| General intelligence | Motivating research problem and future comparison contract | An achievement certified by these finite constructions |

## Where the proof burden remains

The compiler knows the transition and report tables, the successful repair sets, and the complete finite candidate language. Learning those objects economically is the main unsolved mechanism in the proposed integrated architecture. A further recursive demonstration would require a modified compiler or discovery procedure that improves its ability to produce useful procedures from comparable fresh starting conditions.

The conditional error-spending proposition is a probability statement under its premises. The reference suite checks finite arithmetic consequences; it does not empirically establish those premises for a model or validate a general statistical testing service.

## What is deliberately outside the release

No large-model training, private task bank, neural checkpoint, agent-experiment scoreboard, cloud account, network integration, proof-assistant build, or autonomous external action is included. The manuscript treats authority to modify a system as a separate condition from the existence of a computational modification.
