# Claim ledger — v0.3.0

The central advance is a synthesized internal compiler rule rather than another named complete compiler template. It is a bounded instance of learning a search decision in a supplied grammar. Classical finite synthesis, counting, and search arguments are not presented as new mathematical primitives.

| Claim | Status and explicit boundary |
|---|---|
| Counts alone cannot express the desired rejection decision | Proved feature-fibre criterion and explicit conflicting contexts. Capacity is drawn from a supplied feature registry, not invented autonomously. |
| A compiler rule is composed from primitive syntax | Executed finite counterexample refinement. Grammar, fixed order, complete developmental teacher, and counterexample-retention mechanism are supplied. |
| The selected rule fits the development domain | Exact check of all 198 contexts, with three earlier counterexamples and 190 considered ASTs recorded. This alone is not an extrapolation certificate. |
| The count-prefix rule is valid at larger capacities | Self-contained proof for arbitrary integer counts in its stated domain. An executable structural gate recognizes only the proved canonical expression up to specified symmetries. No proof assistant is used. |
| Streaming pruning preserves the result | Proved under the immutable binary singleton-repair scope and identical search ordering and fallback. The implementation cross-checks exhaustive small query tables, varied supports, and cold larger cases. |
| Fewer model reads means less total work | Not established generally. Predicate work, input validation, compilation, grammar construction and synthesis are separately charged or explicitly excluded from the lookup unit. A negative weighted-cost case is retained. |
| Repair-language changes preserve the old pruning rule | False in general. A universal repair makes the singleton scope invalid. The guard declines the shortcut and the general compiler returns the new one-record solution. |
| The rule transfers to arbitrary environments | Not established. Named finite label changes, report changes, supports, and larger capacities are checked within supplied semantic contracts. |
| The discovery procedure changes | Established in a bounded sense: later controller compilations invoke a synthesized internal decision, which changes reads while preserving outputs in the checked scope. |
| The grammar enumerator improves itself | Not demonstrated. Its language, teacher, order, and scope proof remain supplied. |
| The complete Neuralese–OSL bridge is learned | Not executed. It remains an architectural research target. |
| The system is generally intelligent or accelerates indefinitely | Not established. No neural training, autonomous research run, or general capability experiment is claimed. |

## Supplied and retained objects

The model tables, repair-success sets, immutable scope guard, existing compiler skeleton, structural proof gate, cost conventions, fixed expression interpreter, and primitive grammar are explicit inputs to the scientific interpretation. The retained learned object is the five-node comparison AST, serialized before larger tests. The generated controller is a different downstream artifact.

## Cost ledger

The grammar contains 3,960 literal candidates with 19,440 total AST-node occurrences. The learner considers 190 candidates, performs 282 retained-example checks and 210 teacher comparisons, and the teacher examines 344 possible completion counts. The report also records 1,898 interpreter node visits. These counts are distinct units and are not added to a table-read speedup without a specified conversion. Physical Python memory and construction of the theorem are not measured by those counters.

Full-scan/streaming compilation reads include guard and witness-checking phases. Common input validation is reported outside that compilation allowance. Frozen AST construction, evaluation work, and possible fallback are visible. The unchanged downstream controller means the modification is at discovery time, not improved online diagnostic depth.

## Proof and computation

Five new statement/proof pairs join eighteen retained ones. Forty-eight exact groups exercise finite surrogates. Separate code paths within this project are cross-checks, not independent external review. The source and check inventories are not counts of novel discoveries. The prose proofs, not the number of assertions, support the general conditional statements.
