## Retrieval failures and scope

An attempted Berkeley-hosted synthesis PDF and an attempted author-hosted ICE PDF returned tool access errors. Some overly precise searches returned irrelevant material. Those failures did not count as evidence. The accessible syntax specification and the publisher/university ICE records were used instead, at their actual review depth.

Only two references were added. The bibliography is a targeted source review, not an exhaustive novelty search. Source-audit code checks the twenty citation keys, numbering and use, not scholarly priority. No third-party full paper, private conversation transcript, or standalone font file is packaged.
