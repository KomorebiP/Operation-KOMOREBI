# Claim ledger — v0.6.0

## Supported by stated conditional proofs

- A sound finite expression quotient preserves pointwise realizability, without requiring complete equivalence detection or confluence.
- Keeping earliest original ASTs preserves the fixed ordered learner's teacher proposals, counterexamples, and accepted program, with persistent examples and an extensional deterministic teacher.
- Nonnegative feasible repair-cover weights bound the number of necessary leaves and authorize streaming rejection of overweight prefixes.
- The same ordered weighted search returns the same first tree or finite-horizon infeasibility result, with no more search model reads.
- Acquisition and compiler preservation compose when the actual learned rule passes its unchanged semantic gate. A semantic equivalence is not automatically an economic gain.

## Implemented and checked in bounded domains

The new standard-library code discovers 336 admitted equations from 1,068 probe-matched proposals; prepares 1,362 earliest representatives from 3,960 candidates; reproduces the original pruning-rule acquisition; compares nine new arithmetic targets and a genuine finite grammar-exhaustion control; checks a stronger supplied normalizer; and executes repair-relative full-scan/streaming comparisons with explicit certificate invalidation.

The resulting language is generated without downstream target labels. Finite task agreement still has finite scope. The new library does not expand what the grammar can express.

## Supplied foundations

Primitive arithmetic semantics, the finite schema generator and probe schedule, the local proof search and proof-checking rules, the deterministic grammar order and teacher, the query/repair models, and the algorithms that prepare a quotient and construct repair weights are supplied. A learned library is not a claim to have invented these foundations.

## Important negative controls

Probe agreement can fail at zero. An equation valid only on nonnegative integers can be unsupported by a checker for all integers. Changed operator semantics invalidate the cache. A stronger supplied normalizer removes more candidates. Setup can outweigh per-task savings. A newly added universal repair invalidates old weights. A feasible weight bound does not create informative queries. The greedy weight constructor need not be optimal. Budget interruption is not infeasibility.

## Not established

General intelligence, a learned Neuralese–OSL translation, open-ended physical-model acquisition, a universally better synthesis algorithm, total CPU speedup, self-discovered verification, independently validated mathematical novelty, or indefinitely accelerating outer learning. No historical internal agent experiment is used to establish those claims.
