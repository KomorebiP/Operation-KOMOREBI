# Archive layout

The package contains the complete current formal source, unchanged reviewed-core source/PDF, refreshed reader and editable sources, all controls and exact checkers, both current cold-run receipts and objects, comparison, development attempts, independent review, recovery records and offline reproduction tools.

Historical predecessor objects that were absent from the recovered compact predecessor remain omitted. Their exact inventory is retained in OMITTED_LOCAL_FILES.json; that file concerns historical objects, not the current final19/fresh19 builds. The unchanged predecessor archive is retained under evidence/history18/. Earlier historical recovery limits remain explicit.

No runtime or standalone font binaries are bundled. Font-license notices accompany embedded PDF fonts. Python bytecode caches and temporary build debris are excluded. MANIFEST.json covers exactly the delivered regular files and excludes only itself. Run tools/verify_package.py before creating new outputs. The older scripts/verify_release.py targets a historical format and is not the package verifier.

Frozen root metadata retains its preparation wording. Earlier block guides retain their historical coverage counts and pending-target notices. The accepted current status is in ADMISSION_RECORD.json, REPORT.md and ACCEPTED_PROGRESS_LEDGER.md. The reader's publication checks are separate from the formal gate. Changing proof inputs requires new verification receipts.
