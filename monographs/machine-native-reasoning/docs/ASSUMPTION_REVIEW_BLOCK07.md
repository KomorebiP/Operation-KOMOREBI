## Source statement fidelity

The complete source conclusion is retained: exact nondominated profiles, concrete witness existence, feasibility of one online/storage budget, and completeness of pruning dominated children. The source's positive-cost, scalar or finite-state cases are specializations of the implemented nonnegative vector/finite-support model. The finite case guards are Boolean decision tables. Arbitrary predicates can be attached mathematically using classical decidability; that does not provide a computable checker for arbitrary external programs.

No source-book theorem has been rewritten. Stronger execution and fixed-point lemmas are supporting results, not additional promotions in the27-result book ledger. Core5.3 is not promoted.

## Assurance boundary

The finite field/type definitions are exact. Actual proof terms, not the number of supporting declarations or examples, justify the universal results. The cumulative gate audits transitive axioms and replays every substantive local module. The pinned imported environment is reused, not rebuilt from upstream source. Interpretation of an external experiment or recipient still requires evidence that the supplied model describes it.
