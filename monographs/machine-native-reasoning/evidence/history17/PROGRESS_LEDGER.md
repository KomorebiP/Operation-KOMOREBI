### Source and scientific boundary

The reference is a distinguished whole candidate. Agreement is on every initial
vector and every finite word, not only on reachable data or a bounded test set.
One-step invisibility without propagated invariance is insufficient. A common
quotient preserves the protected readout; it need not recover the full state or
be a minimum-dimensional predictor. The finite-stage construction is algebraic
and uses classical quotient selection, not a verified executable learning or
numerical solver. No Lean claim is made for the Python reference implementation.
