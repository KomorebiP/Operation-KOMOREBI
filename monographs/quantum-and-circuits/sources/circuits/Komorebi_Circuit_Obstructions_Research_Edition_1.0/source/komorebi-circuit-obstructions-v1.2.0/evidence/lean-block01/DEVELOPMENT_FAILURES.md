# Development failures and resolutions

No failed intermediate state is labelled verified.

1. **Toolchain download failed.** Local outbound DNS was unavailable; the file download service also refused the release asset after the web fetch was restricted. Lean was recovered instead from the user's archived `Lean_Compact_01.zip`.
2. **Streaming execution was unavailable.** One attempted session launch returned `StreamingExecNotEnabledContainerError` before running the extraction script. A normal local process was used and completed during the same interaction.
3. **The multi-part portable archive was only partially recovered.** Its first ZIP entry passed ZIP decompression/CRC, but the contained XZ stream ends at the first-part boundary. The extractor reported `unexpected end of data` after the full Lean core modules and required shared libraries had been extracted. Missing later compiler/toolchain files were not asserted restored. The recovered Lean, Lake, and checker run successfully; exact executable hashes and version are recorded. The full upstream distribution digest was not revalidated in this block.
4. **Initial cut proof did not compile.** Boolean XOR notation has low precedence. Two initial helper statements elaborated to Boolean expressions rather than the intended equality types; the cut proof exposed the mismatch. All such expressions were rewritten using explicit `Bool.xor`. The final audit prints the actual elaborated statements. A library-specific `by_contra` tactic was also replaced by core `Classical.byContradiction`, and a false/true contradiction was made explicit. The corrected sources pass.
5. **Initial theorem inventory overcounted a comment.** A broad regular expression interpreted the words "theorem applies" in a comment as a declaration. The generated audit failed on that nonexistent name. The final extractor strips nested comments, anchors declarations, and audits every counted name. The final count of 40 includes a subsequently added actual canonical-specialization theorem; it does not include the comment.

The failed compiler and initial audit logs are preserved in `development/`. The final fresh build, strict checks, axiom inventory, checker replays, and negative controls all pass. These repairs do not add hypotheses to C01 or alter the written theorem.

6. **First PDF build failed on a title comma.** The tcolorbox title argument was not grouped, so its comma was parsed as another key. Bracing the title fixed the build. A later layout pass found an inline table extending beyond the text measure; explicit paragraph boundaries fixed the overflow. The final PDF has 15 pages, no overfull boxes, and has been rendered and inspected. These were document-build faults, not proof failures. The initial LaTeX log is retained.
