# Failed mathematical candidates retained from this turn

1. The exact full profile calculation on all functions through four bits reported no difference between affine-optimized alpha_1 and affine-optimized complete degree b. This observation was considered as a possible general equality. The explicit function (x1 AND x2) OR (x3 AND x4 AND x5) refutes it: the maxima are respectively 3 and 4. The all-size family has maxima 3 and n-1. No extrapolated equality is asserted.

2. An attempted bound charging the nonlinear complexity of an extracted homogeneous grade polynomially to the full function's Toffoli count (without input/linear costs) is false. At m=10 the full affine-factor oracle needs 17 Toffolis and its quadratic projection needs 511. Total gate counts are not similarly separated.

3. An attempted context-free weighted-trace product rule is false when scopes overlap. In GF16 at z=2, trace(w)*trace(1+w)=2 whereas trace(w*(1+w))=0. The tested implementation computes the true trace and does not use this failed rule.

These are mathematical route failures, not execution errors. No nonzero exit from the new scientific checkers occurred in the preliminary runs.
