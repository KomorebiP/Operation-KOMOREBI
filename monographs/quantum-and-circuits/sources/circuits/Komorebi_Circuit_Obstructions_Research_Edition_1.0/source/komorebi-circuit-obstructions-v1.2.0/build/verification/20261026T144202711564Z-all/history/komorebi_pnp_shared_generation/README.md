## Reproduction

Requirements: Python 3.10+ standard library, a C++17 compiler (default `g++`). The tested environment is recorded in the computation manifest.

From this folder run:

```sh
python checks/run_all.py
python checks/validate_manifest.py COMPUTATION_MANIFEST.json --root .
```

The first command rebuilds the finite profile calculator, checks the predecessor's 52 sealed files, replays its documented computation in a separate working copy, and runs all new tests. Commands and completion statuses are recorded. Full truth-table tests are only claimed in the stated small ranges. Mathematical arguments, not test counts, support the universal statements.

The authoritative predecessor is retained under `predecessor/`. It is not overwritten by replay. Generated binary profile tables are derived data. Circuit lists used for calibration are generated by the verifier, not supplied as proof certificates of global optimality.

`ARTIFACT_SEAL.json` checks release-byte integrity. It is separate from mathematical verification. Rerunning intentionally rewrites logs and manifests, so a rerun may no longer match the release seal even though its scientific outputs match.

No Lean build, independent reviewer, asynchronous follow-up, or complete complexity separation is claimed.
