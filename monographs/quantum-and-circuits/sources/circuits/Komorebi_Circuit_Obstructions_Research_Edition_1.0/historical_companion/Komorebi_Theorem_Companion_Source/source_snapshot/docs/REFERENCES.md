# References and dependency scope

The claims in this release carry their own arguments. The references below identify established background tools and terminology. Citation is not a substitute for the missing unrestricted lower-bound theorem.

**S1.** Mathias Soeken. *Determining the Multiplicative Complexity of Boolean Functions using SAT*. arXiv:2005.01778v1 (2020). XOR–AND model and degree-minus-one bound. https://arxiv.org/abs/2005.01778v1

**S2.** Magnus Gausdal Find and Joan Boyar. *Multiplicative Complexity of Vector Valued Boolean Functions*. arXiv:1407.6169v3 (2018 revision of the 2014 preprint). Affine-subspace restriction and quadratic controls. https://arxiv.org/abs/1407.6169v3

**S3.** Chris Beck and Yuan Li. *Represent MOD function by low degree polynomial with unbounded one-sided error*. arXiv:1304.0713v1 (2013). One-sided polynomial immunity context. https://arxiv.org/abs/1304.0713v1

Versioned texts were dependency-checked in the source checkpoint. Bibliographic metadata were checked again during release assembly on September 21, 2026. This is not a novelty search or a review of current best lower bounds. No external article or font binaries are redistributed.
