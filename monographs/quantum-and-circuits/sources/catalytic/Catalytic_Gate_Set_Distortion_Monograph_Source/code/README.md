# Catalytic gate-set distortion atlas

This directory contains exact Python and C++ implementations used by the monograph. The package is deliberately small and audit-oriented rather than a production quantum compiler.

## Quick start

```bash
python -m venv .venv
. .venv/bin/activate
python -m pip install -e . --no-build-isolation
python -m pytest -q
python scripts/run_atlas.py --output ../results/atlas_small.json
```

On Windows PowerShell, activate with:

```powershell
.\.venv\Scripts\Activate.ps1
```

The optional Python three-qubit Clifford census enumerates 1,451,520 binary symplectic states and is intentionally opt-in:

```bash
python scripts/run_atlas.py --full-clifford-3 --output ../results/atlas_full.json
```

For that census, the optimized C++ verifier is recommended:

```bash
g++ -O3 -std=c++20 scripts/clifford_census.cpp -o scripts/clifford_census
./scripts/clifford_census --n 3 --metric total --output ../results/clifford_n3_total.json
./scripts/clifford_census --n 3 --metric total --swap --output ../results/clifford_n3_total_swap.json
./scripts/clifford_census --n 3 --metric entangling --output ../results/clifford_n3_entangling.json
```

## OpenQASM witness circuits

```bash
PYTHONPATH=. python scripts/export_qasm_examples.py
```

This writes the exact two- and three-qubit witness words to `../examples/`. The Clifford census works modulo global phase and Pauli translations, so exported restricted and ambient pairs are certified to have the same binary symplectic action in the stated quotient model.

## Conventions

- Binary matrices use row bitmasks.
- Symplectic states act on Pauli exponent vectors `(x | z)`.
- The restricted Clifford model is the parabolic subgroup generated by `S`, `CZ`, and `CNOT`; the ambient model additionally permits `H`.
- The affine reversible subgroup is generated by `X` and `CNOT`; the ambient model additionally permits `Toffoli`.
- The exact finite Clifford model quotients global phase and Pauli translations.
- All results are exact for the declared finite models. They do not imply hardware speedups under a different gate alphabet, ancilla rule, approximation tolerance, or physical cost model.
