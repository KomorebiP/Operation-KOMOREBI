# Catalytic Gate-Set Distortion

**Subtitle:** Temporary Escape in Quantum and Reversible Circuits  
**Author:** Komorebi P.  
**Form:** symbolic, algebraic, and computational monograph

This repository accompanies a monograph on a general circuit-complexity phenomenon: a target lies in a restricted gate model, yet a shorter ambient realization temporarily leaves that model, reuses the introduced resource, and returns with the resource removed.

The release deliberately separates four levels of claim:

1. **Proved:** symbolic theorems, including the complete unitriangular core, higher connected families, algebraic-rarity results, and tensor amplification.
2. **Exactly computed:** complete finite censuses in explicitly declared models, including small binary symplectic Clifford groups and the three-bit affine-versus-Toffoli search.
3. **Formal skeleton:** fully specified research programs whose missing step is identified, usually a lower bound, classification, or realization theorem.
4. **Conjectural:** candidate mechanisms and open thresholds.

See `THEOREM_STATUS.md` for a compact ledger.

## Build the monograph

A TeX Live installation with `latexmk`, `pdflatex`, and the packages imported by the master source is required.

```bash
python -m pip install -r requirements-dev.txt
PYTHONPATH=code python code/scripts/make_monograph_figures.py
latexmk -pdf -interaction=nonstopmode -halt-on-error \
  -outdir=build Catalytic_Gate_Set_Distortion_Monograph.tex
```

The PDF is written to:

```text
build/Catalytic_Gate_Set_Distortion_Monograph.pdf
```

## Generate the quantum-circuit examples

```bash
cd code
PYTHONPATH=. python scripts/export_qasm_examples.py
```

The OpenQASM files encode the gate words displayed in the Clifford chapters. The exact Clifford census is performed in the binary symplectic quotient modulo global phase and Pauli translations. Accordingly, equality of a restricted and ambient witness pair means equality of the declared symplectic action unless the omitted Pauli and phase data are separately reconstructed.

## Model boundaries

The finite calculations are exact only for their stated models. In particular:

- the Clifford state model quotients global phase and Pauli translations;
- the restricted Clifford generators are `S`, `CZ`, and directed `CNOT`, while the ambient model additionally allows `H`;
- SWAP is absent unless explicitly enabled as a unit-cost primitive;
- the affine reversible model uses `X` and `CNOT`, and the ambient model additionally allows Toffoli;
- no ancillas, measurements, approximations, or hardware topology are silently added;
- a finite census is not promoted to an asymptotic theorem without a separate proof.
