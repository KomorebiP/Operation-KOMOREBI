# Quantum–Arithmetic visual guide

The body source is `Quantum_Arithmetic_Visual_Body.tex`. The main release wrapper supplies the document preamble and page macros. Figures resolve to `../figures/<basename>.pdf` from the visual directory.

Twenty original scientific figures are generated by `../checks/make_visuals.py` and supplied in PDF, SVG, and PNG. They plot exact specified formulas using floating coordinates. No AI-created bitmap figures are used.

The new continuous-phase family is a prose derivation and independently reviewed illustration. Its endpoints are inherited formal results. The continuous family is not claimed as an additional Lean-certified declaration.

The computation contract and bounded-run evidence distinguish the source verifier replay, independent Fraction calculations, and floating diagnostics. Each computational success applies only to its specified range.
