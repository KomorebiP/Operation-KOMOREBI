# Block 35 failure ledger

No item below is counted as successful proof evidence.

## Initial parent import-closure timeout

The first restoration build of the checked v0.34 parent reached 2,745 of 2,748
jobs before the outer command window expired. The run is inconclusive. Its
cache was preserved, and the remaining three jobs later completed with a
terminal successful receipt before Block 35 was compiled.

## Monolithic cumulative build attempts

Several attempts to build every cumulative top-level target progressed into
the final parent targets but did not initially emit a terminal receipt within
the outer execution window. Such runs are not counted as passes. The accepted
minimum verification mode is modular cumulative verification: 133 parent
mathematical sources are checked byte-for-byte against the frozen Block 34
ledger, and the complete Block 35 import closure is rebuilt and audited.

If a later resumed top-level build produces a terminal success receipt, it is
recorded as supplemental evidence rather than retroactively converting the
earlier timed-out attempts into passes.

## Concrete unit-interval witness deferred

An optional concrete interval-partition example was explored. Its elaboration
cost was disproportionate to the load-bearing theorem and it was removed from
the final source. The checked result remains universally quantified over every
measure space satisfying `UnitVolumePartition`.

This does not establish that a named dyadic cubical partition satisfies the
contract; that construction remains a next-block theorem.

## General cell-volume normalization deferred

The final block uses unit-volume cells. A general partition with cell measures
`μ(C_i) ≠ 1` requires weighted discrete coefficients and factors of
`μ(C_i)^{-1/2}` or an equivalent normalized basis. No such formula is inferred
from the unit-volume theorem.

## Density and propagator claims excluded

The refining-family theorem is conditional on the existence of step
approximants converging to the target `L²` state. No attempt is counted as a
proof of dyadic density, continuum Dirac generator consistency, or propagator
convergence.
