# Block 36 failure and exclusion ledger

## Discarded predecessor checkpoint

The earlier Block 36 checkpoint contained no Lean source and recorded only an environment-discovery failure (`NO_LAKE`). It was not used as proof evidence.

## Runtime restoration

The pinned Lean 4.34.0-rc2 runtime was reconstructed from seven retained offline parts. All archive-part hashes and the combined runtime archive hash were checked before use.

## Inconclusive cumulative attempts

Several cumulative builds exceeded the outer command window while populating the project cache. None was counted as a pass. The same preserved cache was resumed until the project emitted the terminal receipt

```text
Build completed successfully (3924 jobs).
```

## Direct Euclidean-cube route deferred

A direct first formalization on Euclidean dyadic cubes would have required substantial boundary, half-open-cell, measurability, and binary-expansion bookkeeping before reaching the density theorem. The checked block instead uses the exact octree address product space, where prefix cells and their product measures are canonical.

This is not an assertion that the address space has already been identified with Euclidean space. That identification remains explicit future work.

## Verification wrapper instability

One long-lived wrapper stalled during sequential Lean invocations despite the same gates passing when executed independently. Its incomplete run was excluded. Final evidence consists only of terminal command receipts and logs from completed gates.

## Nonclaims

The following were deliberately not promoted:

- Euclidean `[0,1]^3` or `ℝ³` identification;
- density of a specific Euclidean cubical mesh family;
- continuum Dirac generator consistency;
- propagator convergence;
- dynamical gauge fields, gravity, or cosmology.
