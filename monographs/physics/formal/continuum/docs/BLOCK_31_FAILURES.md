  execution window after passing its initial runtime and package-pin checks.
  It is inconclusive and is not counted as verification evidence.
- **Parent verifier replay:** replaying the complete v0.30 verifier exceeded the
  outer execution window.  The timeout is excluded.  The frozen v0.30 PASS
  report is inherited only together with byte-for-byte comparison of all 129
  parent mathematical modules.

  stopped near the end of 3,723 jobs without a terminal success line.  Both are
  inconclusive and excluded.  Block 31 therefore uses modular cumulative
  verification: frozen checked parent plus a fresh build of the complete new
  import closure.

  norm would not establish the weighted Hilbert statement.  The proof was
  redirected through an explicit Euclidean `ℓ²` realization and a normalized
  half-cell embedding.

  require a separate error constant.  For unit-circle phases, inversion is
  complex conjugation, so the inverse mismatch has exactly the same norm.
- **Raw fine-state norm:** unscaled endpoint/midpoint replication carries twice
  the coarse Hilbert energy.  The actual fine Hilbert realization includes the
  factor `1/√2`; no raw-counting isometry is claimed.
- **No mathematical counterexample:** none of these events refuted a Block 31
  theorem.  Failed approaches and timeouts were repaired or excluded rather
  than reported as passes.
