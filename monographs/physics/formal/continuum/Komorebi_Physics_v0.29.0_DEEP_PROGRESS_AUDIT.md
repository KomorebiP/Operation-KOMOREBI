# Komorebi Physics v0.29.0 — Deep Progress Audit

## 1. Why the target changed

Block 28 ended with a proposed arbitrary-link estimate controlled only by face
holonomies.  Block 29 audits that proposal and proves that it is too strong.
Two distinct consistency questions had been conflated:

1. **Straight-edge reconstruction:** do two ordered fine half-links reconstruct
   the prescribed coarse link?
2. **Path consistency:** do different fine paths with the same endpoints agree?

Plaquette holonomy governs the second question.  It does not determine the
first.

## 2. Exact straight-edge contract

For a fine phase frame `r`, coarse link `u_i`, half shift `h_i`, and arbitrary
fine link `v_i`, the exact contract is

\[
v_i(h_i p)v_i(p)
=r(\widetilde\tau_i p)u_i(x(p))r(p)^{-1}.
\]

The source defines separate `StraightCompatibleX`, `StraightCompatibleY`, and
`StraightCompatibleZ` predicates.  It proves that the canonical frame links
from Block 28 satisfy them and that each predicate is preserved by simultaneous
coarse and fine gauge transformations.

## 3. Arbitrary-link Clifford refinement

The two-half-step theorem is no longer restricted to the canonical link
formula.  For every Clifford involution `A`, any fine link satisfying the
corresponding straight contract obeys

\[
S_{A,h_i,v_i}^{2} I_r = I_r S_{A,\tau_i,u_i}.
\]

Composing these identities with the exact local half-step relation gives

\[
W_{\mathrm{fine}} I_r = I_r W_{\mathrm{coarse}}
\]

for arbitrary compatible fine links in the full palindromic walk.  No flatness
assumption appears in this theorem.

The arbitrary-link refined walk is also exactly gauge covariant.

## 4. Curvature is transported, not erased

For the canonical links, two `x` half-edges followed by two `y` half-edges
reconstruct the framed coarse `xy` path.  Reversing the order reconstructs the
framed `yx` path.  When the coarse translations commute, the endpoint frame
factors cancel and Lean proves

\[
\Omega^{\mathrm{fine},2\times2}_{xy}(p)
=
\Omega^{\mathrm{coarse}}_{xy}(x(p)).
\]

Therefore exact refinement is compatible with nonzero curvature.  Block 29
contains a theorem returning both exact full-walk intertwining and a nontrivial
large fine plaquette whenever the coarse plaquette is nontrivial.

## 5. Exact arbitrary half-link defect

An arbitrary pair of half-links `a(x)` and `b(x)` reconstructs

\[
u_{\mathrm{prod}}(x)=b(x)a(x).
\]

Two fine half steps exactly implement the coarse Clifford shift generated by
`u_prod`.  Comparing this with a separately prescribed coarse link `u` gives

\[
D_{\mathrm{fine}}\psi
=
I\bigl(S_{u_{\mathrm{prod}}}\psi-S_u\psi\bigr).
\]

The embedding is injective at the endpoint component, so the fine defect
vanishes exactly when the coarse reconstructed-link defect vanishes.

With the half-cell Hilbert normalization, interpolation is isometric and

\[
\|D_{\mathrm{fine}}\psi\|^2_{\mathrm{half-cell}}
=
\|S_{u_{\mathrm{prod}}}\psi-S_u\psi\|^2_{\mathrm{coarse}}.
\]

The source then expands this exactly into the two orthogonal Clifford channels.
The forward channel is weighted by the squared phase difference between
`u_prod(τ⁻¹x)` and `u(τ⁻¹x)`.  The backward channel is weighted by the analogous
inverse-phase difference at `x`.  No cross term remains because the Clifford
projectors are orthogonal.

## 6. Flat but incompatible witness

Let every cubical edge phase be the quarter turn `i`.  Any two-edge face path
has phase `i²=-1`, so parallel paths agree and every plaquette is one.  The cell
is flat.

Now use `i` on both fine half-edges while prescribing the trivial coarse link.
The straight product is

\[
i\cdot i=-1\neq1.
\]

Lean proves that the associated Clifford refinement defect is nonzero on the
first basis spinor.  It also proves the negation of a universal rule saying
that flatness forces this arbitrary-link refinement defect to vanish.

This is the decisive correction:

\[
\boxed{
\text{flat plaquettes do not imply correct straight-edge reconstruction.}
}
\]

## 7. Correct combined picture

The refinement problem now has two independent local defect families:

\[
E_i(p)
=
v_i(h_i p)v_i(p)
\bigl(r(\widetilde\tau_i p)u_i(x(p))r(p)^{-1}\bigr)^{-1},
\]

and

\[
\Omega_f-1.
\]

The `E_i` terms measure straight coarse-edge reconstruction.  The `Ω_f` terms
measure disagreement between alternative paths and cell-gluing orders.  The
next complete estimate must retain both rather than replacing one by the other.

\[
