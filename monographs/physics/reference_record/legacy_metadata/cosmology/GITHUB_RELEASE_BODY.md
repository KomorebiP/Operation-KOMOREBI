# Projector-Refinement Physics, Volume II - v1.0.0

This release publishes the first research-monograph edition of **Cosmology, Dark Sectors, Structure Formation, and Falsifiability** by Komorebi P.

## Assets

- `Projector_Refinement_Physics_Volume_II.pdf` - 157-page monograph
- `Projector_Refinement_Physics_Volume_II_Source_and_Reproducibility.zip` - complete LaTeX source, figures, data, computational records, and build scripts
- `SHA256SUMS.txt` - integrity manifest

## Contents

- relativistic FLRW backgrounds and perturbations
- the additive dominant-shell no-go theorem
- the current scale-covariant refinement dark-sector model
- collisionless, photon, baryon, neutrino, recombination, reionization, ISW, and lensing transport
- nonlinear structure, particle-mesh evolution, halo catalogues, baryonic response, cooling and feedback, and subhalo survival
- linked rejection criteria and an explicit open-problem ledger

## Quality assurance

The PDF contains 157 pages, no blank pages, no unresolved references, no LaTeX or package warnings, and no overfull or underfull boxes. Every page was rendered and inspected, and the clean-source rebuild was compared against the release render.

## Scope

This is a publication-style research edition. It does not claim completed microscopic parameter derivation, a precision data likelihood, historical priority, independent reproduction, or empirical confirmation.
