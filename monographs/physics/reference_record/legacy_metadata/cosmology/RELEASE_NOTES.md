# Release Notes - Version 1.0.0

## First research-monograph edition

This release publishes the first complete Volume II edition of *Projector-Refinement Physics*.

### Included

- 157-page publication-style PDF
- 5 parts, 21 numbered chapters, and 3 appendices
- relativistic backgrounds and perturbations
- the current scale-covariant refinement dark-sector branch
- the additive dominant-shell no-go result as a corrected historical boundary
- collisionless, CMB, reionization, ISW, and lensing calculations
- nonlinear power, particle-mesh, halo-catalogue, baryonic-response, cooling-feedback, and subhalo-core analyses
- frozen data, figures, computational programs, and build scripts
- local claim boundaries and an explicit open-problem chapter

- removed development-log and completion-percentage language
- removed superseded additive branches from the current-theory narrative while retaining the decisive obstruction

- standardized the epistemic status of exact, conditional, numerical, and open statements
- retained negative controls and sign-indefinite satellite results
- added a global reader guide, notation section, part introductions, central formula guide, benchmark summary, and reproducibility map

### Quality assurance

A publisher-final edition still requires a complete scholarly bibliography, a chapter-by-chapter priority audit, independent theorem checking, independent numerical reproduction, and a precision observational likelihood.
