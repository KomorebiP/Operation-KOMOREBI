## Build

Install the pinned Python dependencies, then use the platform wrapper.

Linux or WSL:

```bash
python -m pip install -r requirements.txt
./build.sh
```

Windows PowerShell:

```powershell
python -m pip install -r .\requirements.txt; powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
```

The wrappers validate the frozen package, build into `build/`, and validate the resulting PDF and final LaTeX log. They do not overwrite the frozen data, figures, or a release PDF.

## Validate without building

```bash
python code/validate_release.py
```

The validator is read-only. It prints a JSON result to standard output and returns a nonzero exit code if a release invariant fails.

## Reproduce the bridge calculation

The bridge verification program uses the bundled frozen parent record from the Volume I source release. Reproduce into a new directory rather than overwriting `data/`:

```bash
python code/verify_covariant_backreaction.py --parent-json parent/Scale_Covariant_Dark_Sector_Verification.json --output reproduction/data --figures reproduction/figures
cp data/parent_release_audit.json data/cross_volume_lineage.csv reproduction/data/
python code/generate_latex_values.py --data reproduction/data --output reproduction/generated_values.tex
```

The parent-release audit similarly accepts explicit Volume I, Volume II, and Volume I Technical Supplement roots. Its cross-volume hashes establish provenance, not correctness.
