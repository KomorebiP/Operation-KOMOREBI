## What was run

The deterministic Hilbert suite uses fractions.Fraction with seed 20260913 and
local dimensions 0 through 6. It constructs nonorthogonal rational coordinate
changes, redundant global columns and compatibility rows, and tests actual
projectors, orthogonality, best-image identities, quotient-class invariance,
refinement gains, perturbations, PSD/coercivity witnesses and boundary examples.
The PSD Schur-complement implementation is compared with an independent
all-principal-minors criterion on 100 matrices of dimensions 0 through 4.
Input/output dimensions in the reusable evaluator are capped at 16.

The supplied three-coordinate evaluator example gives realized=(3,0,0),
obstruction=(0,4,0), inconsistency=(0,0,5), error_squared=41 and bound_squared=41.
The sigma_squared=4 certificate is checked exactly. This is a rational executable
example. The separately kernel-checked concrete Lean examples are scalar.
The Python algorithms, PSD checker and JSON parser are tested, not formally
verified or extracted from Lean. No floating singular value or sample residual
establishes a universal theorem.

## Failures and corrections

Drafts failed on projection/continuous-linear-map API names, subtype coercions,
explicit quotient arguments, rewrite ordering, norm inequalities, and warning-fatal
unused section hypotheses. These were corrected with diagnostics retained. An
unsupported pp.width option caused the first supplementary signature dump to fail;
removing that display-only option produced a successful rerun. Container streaming
sessions were unavailable; runtime restoration instead used a monitored process
and the assembled archive hash was checked.

No unresolved production compilation, axiom-audit, kernel-replay, rational-test,
or manifest-validation failure remains. Pure-obstruction and poor-conditioning
examples are intended mathematical counterexamples to overly broad claims.

## Mathematical boundaries

Orthogonal projection existence, and closed realized range in the Hilbert
specialization, are explicit. Finite local dimension supplies some positive
compatibility coercivity constant, not an optimal or family-uniform value.
The harmonic identification is a LINEAR equivalence to the old quotient, not
an isometry. Refinement enlarges realized subspaces with a fixed compatibility
space and metric. Nearest global images exist but canonical minimum-norm source
reconstruction and its sensitivity are separate. No positive, integral, nonlinear
or arithmetic globalization theorem is inferred from linear realizability.
