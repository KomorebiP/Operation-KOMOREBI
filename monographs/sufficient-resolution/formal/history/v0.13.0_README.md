## Check the block

With the preserved Linux x86_64/WSL2 portable runtime available:

```bash
python scripts/verify_block13.py --runtime /path/to/Komorebi_Portable_Lean_4.34.0-rc2 --out verification/local_block13
```

The default recompiles and replays the required project dependency closure serially.
The full-corpus verifier is scripts/verify.py; its existence is not evidence that a
fresh all-module run has been performed. Pinned imported Mathlib artifacts are reused.

## Check a rational inexact certificate

```bash
python scripts/inexact_discrepancy_certificate.py --input examples/inexact_discrepancy_input.json --output certificate.json
python scripts/check_inexact_discrepancy.py
```

The certificate checker uses exact fractions and squared Euclidean norm bounds.
It requires known rational matrices, a candidate source and parameter, tolerances,
and measurement enclosures. It does not compute an inverse or search for a parameter.
The true noise allowance and fixed-operator assumption remain external inputs.
Python algorithms and parsing are tested, not Lean-verified or extracted from proofs.
