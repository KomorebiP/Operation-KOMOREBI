## New principal result

For A:G->V and delta:V->W with delta A=0, put R=range(A), K=ker(delta).
When these subspaces admit orthogonal projections, the actual vectors

    r=P_R v, o=(P_K-P_R)v, i=(I-P_K)v

are the unique orthogonal decomposition of v into realizable, compatible-but-
obstructed, and inconsistent components. The nearest realized image is r and

    dist(v,R)^2 = ||o||^2 + ||i||^2.

The existing algebraic quotient ker(delta)/range(A) is linearly equivalent to
K intersect R^perp, with actual maps and both inverse laws. No quotient-norm
isometry is claimed.

If sigma>0 and sigma||x||<=||delta x|| for x in K^perp, then

    dist(v,R)^2 <= ||o||^2 + (||delta v||/sigma)^2.

Finite-dimensional V supplies some positive sigma, including the zero-complement
case. In finite dimension, a residual-only bound for every v exists exactly when
range(A)=ker(delta). Closed-range Hilbert-space nearest-image existence is separately
proved with closedness explicit.

When R0<=R1<=K, holding K fixed, the squared reconstruction error and squared
obstruction decrease exactly by ||(P_R1-P_R0)v||^2. All three component maps are
nonexpansive under input perturbations.

Exact real counterexamples prove that zero residual does not remove a genuine
obstruction, and that no fixed conditioning constant works across all nonzero
scalar compatibility operators.

actual Euclidean projectors and a global preimage, and checks a whole-map squared
