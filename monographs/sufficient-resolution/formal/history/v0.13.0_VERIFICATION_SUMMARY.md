## Finite tests and executable scope

check_inexact_discrepancy.py uses exact fractions.Fraction, seed 20260914, source and
data dimensions 0..4, and noise allowances 1/2, 1/3, 1/4. Valid noisy data are generated
only by the tests; the checker does not receive the true source. Candidate solves
are genuinely perturbed in 46 positive-parameter cases. Their exact comparison
sources and both correction scales are independently evaluated. Twelve normal solves
are compared with SymPy's exact inverse, a separate algorithm but not a proof kernel.

The evaluator itself performs no inversion and no parameter search. It checks
known rational matrices, candidate sources, actual normal residuals, squared norm
enclosures and protected margins. It includes an optional enclosure for inexact
normal-residual evaluation. Dimensions are capped at 16, input JSON at 1 MB, and
rational coefficients use the preserved strict bounded parser. No floating-point
number is accepted as an exact rational coefficient.

The scalar example is ALSO a Lean certificate: A=1, v=4, lambda=1, x=201/100.
Its normal residual is 1/50, exact source/image correction 1/100, actual fitting norm
199/100 and measured norm 2 with error 1/100. The CLI additionally validates an
inexact normal evaluation 1/100 with error bound 1/100.

Python matrix arithmetic, algorithm implementation and parsing are tested, not
formally verified or extracted from Lean. The finite checks do not prove infinite
limits, infer noise bounds, or validate an unknown forward operator.

## Failures and corrections

Initial drafts failed on an ambiguous residual name, an absolute-value API name,
a reverse-triangle API name, an omitted explicit submodule argument, and dependent
positivity instantiation. A downstream attempt initially lacked its failed dependency
object. The fixes and reruns are retained in development_v0.13.0. No theorem contract
was weakened and warning checks were not disabled. Both final full-closure runs pass.

No unresolved new-block compilation, audit, replay, finite-check or CLI failure
remains. A fresh full-corpus replay was not performed and is not claimed.

## Remaining mathematical boundaries

Fixed bounded real Hilbert operator and a valid true-data noise allowance. Protected
margins and a vanishing source-correction budget remain hypotheses. The exact-noise
parameter schedule is not separately imposed. Raw normal residual smallness alone
does not suffice; kernel ambiguity remains in the limit. Squared certificates use
the actual norm. Margin-window feasibility does not prove arbitrary solver success.
No changing-operator, nonlinear, positive, integral or arithmetic convergence theorem
is inferred. See PROGRESS.md for the next target.
