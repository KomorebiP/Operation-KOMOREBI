# Komorebi Sufficient Resolution — v0.10.0

**Komorebi P.**

Cumulative proof-source package: 728 theorem declarations across 60 modules, with
863 explicitly named declarations. Counts include supporting lemmas and examples,
not independent discoveries. All 53 v0.9.0 production proof sources are unchanged.

The latest block constructs Tikhonov recovery for arbitrary bounded real Hilbert
operators with positive regularization, proves the actual minimization contract,
sharp noise bounds, bias/noise/kernel decomposition and operator perturbation bounds,
and integrates regularization with the native obstruction quotient geometry.

Read BLOCK_10_THEOREMS.md, PROGRESS.md, VERIFICATION_SUMMARY.md and AUDIT.json.
DECLARATION_INDEX_v0.10.0.csv maps names to exact source locations.
Current verification records are verification/release_v0.10.0 and
verification/roundtrip_v0.10.0. Historical generic release folders are not current.

## Reproduce proofs

    python scripts/verify.py --runtime /path/to/Komorebi_Portable_Lean_4.34.0-rc2
    python scripts/validate_manifest.py verification/local-replay/computation-manifest.json --root .

The runtime is not bundled. Use the preserved compact portable kit, pinned to Lean
4.34.0-rc2 and Mathlib aeb72f1e9981b6d35b426b16dca7759be3e7ba06. Imported artifacts
are reused; leanchecker is the SAME Lean kernel, not an independent implementation.

## Exact rational example

    python scripts/tikhonov_certificate.py --input examples/tikhonov_input.json --output certificate.json
    python scripts/check_tikhonov.py

The evaluator assumes known rational matrices and standard Euclidean metrics.
It rejects nonpositive lambda, floating coefficients, invalid sizes and malformed
certificates. Its Python code/parser are tested, not verified or extracted from Lean.

Core mathematical boundaries: lambda>0; bounded real Hilbert operators; no
unconditional source identifiability; no uniform inverse as lambda vanishes;
no claimed general strong-limit theorem, positivity-constrained, nonlinear or
arithmetic realization. The underlying Tikhonov and Lax–Milgram mathematics is
classical. This package does not certify literature novelty.
