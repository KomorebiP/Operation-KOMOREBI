## Main new result

For known linear operations T_i and observation O on a finite-dimensional space X,
let k = dim ker O. Two states have identical observations after every possible
future operation word if and only if they agree for every word of length at most k.
The operations need not commute. The zero-dimensional and zero-observation cases
are included. A finite alphabet is required for a finite enumeration of those words.

The release constructs the finite observation-coordinate model, its actual dynamics
and readout, proves all-future fidelity, and proves minimum exact linear dimension.
A single plateau in the nested invisible subspaces is an exact stopping certificate.

A second certificate theorem says that a candidate q is minimal whenever it is
generated by finitely many original observations, preserves the readout, and
intertwines every operation. The candidate's actual image is minimal; surjectivity
is required to infer minimality of its whole ambient state space.

## Runnable exact-rational minimizer

From this directory:

```bash
python scripts/observable_model.py --input examples/observable_model_input.json --output model.json
```

The included example reduces dimension 3 to dimension 2, preserving both
noncommuting operations and every future observation. The program emits exact
rational matrices and sparse generation certificates. It rejects floating inputs.
It uses only Python's standard library and needs no model training or network access.

The optimized sparse row-saturation code is tested, not formally verified or
extracted from Lean. Generic certificate sufficiency and one concrete example
are Lean-proved. Arbitrary JSON certificates are checked in exact Python arithmetic;
they are not automatically imported as new Lean proof terms.

```bash
python3 scripts/verify.py --runtime /path/to/Komorebi_Portable_Lean_4.34.0-rc2
python3 scripts/validate_manifest.py verification/local-replay/computation-manifest.json --root .
```

The Linux x86_64 portable runtime and its Mathlib cache are not duplicated in this
source/evidence archive. Once that runtime is restored, reproduction is offline.
The Lean reproduction is tested on Linux, not separately on Windows/WSL.

The verifier deletes and rebuilds only this project's proof artifacts, compiles
serially with warnings as errors, audits every explicitly named declaration, and
runs `leanchecker` on every production module. Allowed axioms are only `propext`,
`Classical.choice`, and `Quot.sound`. Production sources contain no `sorry`, `admit`,
custom axioms, `unsafe`, or `native_decide`. Negative controls are isolated and are
not imported by the production library.

Replays use the same Lean kernel and cached imported artifacts, not an independently
implemented proof kernel or a fresh proof reconstruction of all Mathlib.

The new rational tests cover 30 systems with 1,657 exact assertions and 10 rejected
negative controls. The predecessor tests are retained separately. Bounded tests
are not the universal mathematical proof.

The theorem is about known linear operator models and exact complete observations,
not inference of unknown dynamics from finite samples. Positivity, integrality,
continuous-time memory, approximation stability, nonlinear models, and arithmetic
existence remain separate obligations. No literature novelty or priority is claimed.
