## Scope that the traditional and visual papers must retain

| Contract | Exact hypotheses and boundary |
|---|---|
| Redundant-coordinate representation | Modules over a semiring; $sa=I_X$. The encoded identity is $E=as$, and the admissible kernel condition is $E_YKE_X=K$. It is an actual equivalence of global maps and compatible kernels; it presupposes the supplied splitting. |
| Compression and hidden return | Commutative-ring modules; $CR=I_Z$. Splitting need not be orthogonal. A vanishing defect for one pair or depth does not prove closure for all words. Prepared hidden state means $z_0=0$; closure for every hidden initial state is the stronger condition $B=0$. |
| Finite hidden certificate | Over a field, finite hidden dimension $d$, or an explicit monic annihilator of $D$. Check $BD^kG=0$ for $k<d$, equivalently prepared iterates through $d+1$. The first surviving return indexed $k$ alters iterate/derivative $k+2$. The visible space need not be finite-dimensional. Zero hidden dimension is included. |
| Behavioral sufficiency and minimality | All finite chronological words in a supplied operation family, including the empty word. Comparison and minimality concern the reachable image of an exact model map $q$; identifying the entire model with the quotient needs surjectivity. Over a field with finite-dimensional $X$, the horizon is $\dim\ker O$. Infinite alphabets give bounded word length, not a finite list of tests. |
| Finite observable coordinates/certificates | A finite enumerated alphabet is explicit. The coordinate state space is the actual range of the finite observation map, rather than every arbitrary observation table. The certificate supplies generation, intertwining and exact readout proofs. A Python record is not thereby an instance of the Lean structure. |
| Approximate dynamics | Actual continuous linear maps and whole-map norm bounds; no sampling surrogate. Discrete uniform-in-word bounds require a common norm contraction bound on reduced operations and nonexpansive true operations. Readout and initialization errors remain separate. These estimates do not prove approximate minimality. |
| Continuous dynamics | Bounded autonomous generators on real Banach spaces. Flows are actual NormedSpace.exp, with actual derivatives/integrals. Exact identities use all real times; norm-budget statements use $t\ge0$ and supplied flow norm envelopes. Finite Taylor certificates test operator derivatives at zero, not finitely sampled values. No unbounded or time-varying generator theorem is supplied. |
| Globalization metric | The algebraic quotient is $\ker\delta$ modulo realizable vectors lying in that kernel. Writing it as $\ker\delta/\operatorname{range}A$ requires $\delta A=0$. Harmonic and minimum representatives need the stated orthogonal projection hypotheses. The metric is the existing quotient seminorm, not a newly assigned norm. For a nonclosed subspace, a nonzero algebraic class can have seminorm zero. |
| Conditioning and transport | A positive whole-map lower bound on the kernel complement controls inconsistency; it does not remove the obstruction term. Finite dimension supplies some constant, not a uniform constant over a changing family. Quantitative reflection needs a bounded reverse obstruction map with the stated left-inverse law. Quotient refinement keeps local compatibility and its metric fixed while enlarging the realized range. |
| Canonical minimum-norm source recovery | Real Hilbert source, actual range complete; public closed-range version explicitly assumes that the actual range is closed. The best represented vector is unique, while all least-squares sources differ by $\ker A$. The canonical source is the unique minimum-norm member. Closed range is equivalent to positive off-kernel coercivity and to bounded recovery of identifiable sources. |
| Tikhonov limits | Real Hilbert spaces and a bounded operator. Every positive parameter has an actual normal inverse without closed range. Strong source limits recover $P_{(\ker A)^\perp}g$. Operator-norm source convergence requires closed range; the converse requires a nontrivial filter. Arbitrary-data fitted values tend to $P_{\overline{\operatorname{range}A}}v$, which need not be realizable. The nonrealizable approximate-data theorem excludes source norm convergence; it does not assert that norms diverge. |
| Discrepancy and inexact certificates | Exact root requires strict distance floor $<\rho<\|v\|$ and is noncomputable. Total selection includes a small-data branch and retains positive certified allowance, $\tau>1$, and feasibility. Inexact acceptance is proved by actual normal residual and protected measured bands, with independent source/image/evaluation budgets. Noise truth remains an external premise. |
| Changing operators and generalized discrepancy | All operators act between the same Hilbert spaces; uncertainty bounds the whole operator norm. Kernels/ranks may change, and the limit uses the true limiting operator's identifiable source. Candidate-dependent noise $\eta+\delta\|x\|$ removes a supplied source cap from acceptance. Selection existence still needs $\eta>0,\tau>1,\delta\|p\|<(\tau-1)\eta$. Raw selected-source witnesses are noncomputable and take the true operator/source and proof premises; they are theorem-level witnesses, not an extracted available-data algorithm. |
| Calibration | Exact $UR=I$ permits redundant coordinates and guarantees coverage of every source direction. $Y-AU$ and $Y-CU$ are bounded in operator norm; the truth allowance is externally justified. The generated allowance is $(\eta_{\rm cal}+\mathrm{fit})\|R\|$. Approximate reconstruction needs $\|I-UR\|\le\rho<1$, yielding division by $1-\rho$. Hierarchical analyses compose with a product norm bound. Individual noisy sample certification is not proved. Perfect agreement on a proper calibration subspace allows arbitrarily large unseen error. |
