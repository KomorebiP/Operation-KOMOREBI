# Machine-Native Reasoning v1.0.0

This release synchronizes the complete 97-chapter web edition with its PDF and editable TeX. It corrects two prose errors and five chapter-reference labels, aligns the atlas reading route with its 13 plates, and includes the literal source names restored in the web edition. The earlier PDF and full archival source remain available.

The self-contained source archive includes the active TeX, all 131 required figure dependencies, a build script, licenses and verification records. A clean extracted build reproduces all 977 pages in text, geometry and rendered pixels at 36 dpi. All internal PDF links pass; the compiler reports no undefined references, missing characters or overfull boxes. The 16,295 protected mathematical expressions in the active TeX are unchanged.

The earlier manual proofreading covered the welcome, titles, chapter openings, captions and flagged prose; it was not a line-by-line review of every paragraph. A new focused self-review checks seven integration interfaces in Chapters 10 and 12-17. This release does not claim an independent whole-book proof audit or a new Lean execution.

The source package and publication record give the exact source hashes, review scope and reproducibility checks. SHA256SUMS authenticates the PDF and source ZIP.
