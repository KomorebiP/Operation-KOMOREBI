## Important mathematical corrections and qualifications

**Supplementary information needs a dynamic premise.** During proof drafting, the proposed attainment clause was too broad for an arbitrary redundant old representation. A constant-output two-bit system can retain an irrelevant first bit, then admit a swap operation that makes its retained coordinate impossible to update without the second bit. The answer quotient remains trivial. The delivered Proposition 4.2 therefore separates the general lower bound from an attainment claim requiring each expanded behavioral class to lie within one old representation fibre. The old minimal quotient satisfies that premise. The corrected theorem and the redundant-coordinate counterexample are checked in the companion suite. This was a substantive strengthening of an insufficient hypothesis before the final run.

**An experiment can alter the state it measures.** The instrument's new J operation changes its first register. The reconstruction formula returns the post-intervention state and preserves that update. It does not silently restore the old state. Five supplementary values require three bits when coded separately at fixed binary length, even though rounded binary bounds for the old and enlarged joint state differ by two bits.

**Information in a representation is not evidence of causal use.** A probe, decoder or alignment can solve a task while the solver ignores the selected carrier. Arbitrary finite recodings preserve formal operation squares. The draft keeps construction cost, access, interpretation and permissible interventions inside the account rather than excluding inconvenient implementations by terminology.

**Exact transfer is a forward contract.** It guarantees source operations and matched queries after translation. It does not imply reverse reconstruction, coverage of new target operations or agreement under every external intervention. Approximate bounds use fixed matched operation sequences and uniform Lipschitz/error hypotheses. Zero-horizon and zero-Lipschitz cases are explicit.

**Explanation is recipient-relative.** The fixed-length counting bound assumes a fixed interpreter and background. It supplies an information lower bound, not efficient decoding, human comprehension or faithfulness to the actual source solver. A subject explanation and a mechanism explanation remain different claims.

**Correction preservation includes contradictions.** Theorem 9.1 covers all candidate subsets and all attainable observations, including observations inconsistent with the current subset. Preserving an empty update is essential to its necessity statement. Excluding those cases changes the theorem. The result concerns exact deterministic evidence and represented candidate models, not noisy inference, truth of measurements or invention of a missing model.

## Exact implementation scope

The suite uses integers and `fractions.Fraction`. Domains are attached to individual groups in `validation/finite_checks.json`. Checks include all 125 instrument states, finite H/W continuation words, independent partition-refinement and pair-search comparisons on small machines, expanded quotient coding, rational binary-testing cases, a controlled stochastic kernel, exact transport recurrences, fixed-recipient information capacity and all declared finite correction squares. The corrector explicitly tests contradictory evidence and noninjective evidence translation.

These implementations are authored within the same project. The alternative algorithms provide cross-checks, not independent external validation. Passing finite enumerations does not prove arbitrary-state claims. The general arguments are the manuscript's prose proofs.

## Resolved execution and export failures

1. The first figure export failed with `PermissionError` because the plotting process could not write the container-created output directory. Directory permissions were corrected and the four vector figures and previews were regenerated successfully. This failure was disclosed during the interaction.
2. The first LaTeX invocation failed because a title line used the author-separator command `\and` where a line break followed by the word “and” was intended. The source was corrected and the document compiled. The first failure log is retained under `validation/development/`.
3. The first successful layout had 27 pages, including a nearly empty continuation page for the conclusion. Tightening the conclusion removed that orphan page without deleting a formal statement, and references were added to the contents. The final 26-page PDF was rerendered and inspected.
4. A preliminary generic Pandoc conversion did not preserve citation and theorem numbering adequately. It was not delivered. The custom reading exporter now resolves citations and references from the canonical LaTeX auxiliary file before conversion. The LaTeX and PDF remain canonical.

No mathematical assertion failed in the executed final suites. That fact does not erase the proof-hypothesis correction described above.

PDF binary identity, cross-platform equivalence, PDF/A and tagged accessibility were not certified.

The execution record is a transparent project-local receipt, not an independently authenticated external audit service. It records the actual command, time, environment, pinned source/script hashes and output hashes. No repository commit, independent attestation or separately imposed memory cap is available. The final subprocess was bounded by a 20-second wall timeout.

The source package contains the manuscript, code, figures, metadata and audit records. It contains no private conversation transcript, third-party full text or standalone font file. The previous *Machine Societies* deliverables are unchanged.

## What the next revision should address

The main research gaps are bounds that prevent an unrestricted interpreter from supplying the whole task solution, approximate and probabilistic correction transport, minimal-cost acquisition of newly relevant distinctions, and explanatory artifacts usable by recipients with different backgrounds. These are explicitly open parts of the framework, not failures to complete the requested first draft.
