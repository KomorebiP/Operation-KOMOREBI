## Assurance boundary

Same-kernel replay is not independent peer review or an independently implemented checker. Imported objects are hash-checked against the saved runtime inventory, not rebuilt from upstream source or independently authenticated. Project-authored source, receipt and ZIP tools do not replace the kernel. A checksum binds bytes but does not establish semantic completeness or physical premises.

The code does not infer a dependency graph from an arbitrary running agent, verify concurrent host mutation, certify physical sensor reliability, or implement an efficient general proof search. Rank layers and finite input comparisons are stipulated operations, not measured CPU time. The universal-repair example does not automatically restore an old cost comparison. No whole-book Lean completion, neural training, benchmark campaign, Windows execution, external-account action or manuscript rewrite occurs here. The package contains no runtime, standalone fonts, private transcripts or third-party full papers.
