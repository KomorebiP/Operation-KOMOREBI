# Multi-Space Discovery and Causal Triangulation

## 1. Why a second discovery axis is required

For residual state h at layer l, a corpus-averaged Jacobian transport is

\[
J_l = \mathbb E_{x,t,t'\ge t}
\left[\frac{\partial h_{L,t'}}{\partial h_{l,t}}\right].
\]

After composing with the unembedding, its token-indexed rows define verbalizable directions. This deliberately privileges potential verbal report. A successful readout is therefore evidence about verbal accessibility, but it cannot by itself establish a general broadcast workspace.

RRCT v0.61 requires candidate structure discovered without the lens, unembedding, token identities, task answers, or behavioral labels.

## 2. Candidate objects

All bases below are estimated on a development corpus and frozen before causal evaluation. A calibration covariance is used to place every state, write vector, and read covector in common whitened coordinates. Token identity, position, prompt family, sequence length, and residual-carry nuisances are residualized before predictive and persistence fitting. Let X_l contain the resulting source states, Y_l contain states two or more layers later, and D_l = Y_l - X_l.

### V — active verbal frame

For token a with unembedding direction w_a, the source-layer verbal direction is approximately

\[
v_{a,l}=J_l^\top w_a.
\]

The full J-space is the union of sparse nonnegative cones generated by active token directions. The engineering smoke uses the leading span of directions selected by the lens on development traces as a proxy called V. The primary run must use sparse nonnegative decomposition and keep local cones separate.

### P — future-update predictive space

P is learned from the source directions that best predict subsequent residual change:

\[
C_P = X_l^\top D_l,
\qquad
P_l = \operatorname{leftSVD}_r(C_P).
\]

It uses no outputs, vocabulary, lens, or task labels.

### T — persistent space

T contains directions that preserve their coordinate across depth. With regularized source covariance C_X and symmetrized lag covariance S,

\[
C_X=\mathbb E[X_l^\top X_l],
\qquad
S=\tfrac12\mathbb E[X_l^\top Y_l+Y_l^\top X_l],
\]

T is obtained from the leading generalized eigenvectors of S v = lambda C_X v.

### C — empirical write space

Let I_l be the native residual increment entering layer l. The empirical write Gramian is

\[
G_C=\mathbb E[I_l^\top I_l].
\]

Its leading eigenspace identifies directions repeatedly written by upstream computation. In the primary run this is replaced by a true intervention-derived controllability Gramian over attention-head and MLP channels.

### O — structural read space

For downstream component input matrices W_m whose input dimension is d_model,

\[
G_O=\sum_m \frac{W_m^\top W_m}{\operatorname{tr}(W_m^\top W_m)}.
\]

O is its leading eigenspace. It is vocabulary independent and estimates directions broadly available to later computation. The primary run supplements this static approximation with context-dependent Jacobian gain and attention OV label-preservation measurements.

### B — balanced causal space

A direction is workspace-like only if it can both be written and read. Define

\[
M=G_C^{1/2}G_OG_C^{1/2}.
\]

The leading modes of M, mapped back through G_C^{1/2}, define B. This is a balanced write/read candidate, not by itself a workspace.

### F — fuzzy formation field

F is fitted only to predict later residual updates from upstream component contributions. It may never see V, J_l, the unembedding, tokens, outputs, answers, reports, or intervention outcomes. Its memberships define a context-dependent packet field rather than a fixed basis.

### R — relational binding residual

A flat list of active words cannot identify which concept fills which role. For a relation template rho with fillers a and b, define a four-way contrast

\[
r(a,\rho,b)=h(a,\rho,b)-h(a,\rho,b_0)-h(a_0,\rho,b)+h(a_0,\rho,b_0).
\]

R is the low-rank frame of these interaction residuals. Causal tests keep the same concepts active while swapping their roles or relation. A workspace account that only detects the bag {a, rho, b} fails this gate. R is a held-out functional diagnostic and is not counted as an independent consensus estimator.

## 3. Convergence without circularity

For orthonormal bases Q_A and Q_B of equal rank r, normalized overlap is

\[
\Omega(A,B)=\frac{\|Q_A^\top Q_B\|_F^2}{r}.
\]

Estimators are first grouped by dependence. P and T form a temporal family D. C and O define B and therefore form one balanced causal family rather than three votes. The primary run adds the independently frozen fuzzy dynamic family F. The independent consensus projector excludes V and weights families equally:

\[
P_D=\tfrac12(P_P+P_T),
\qquad
\bar P_{-V}=\tfrac13(P_D+P_B+P_F).
\]

Its leading eigenspace is W_ind. V is compared against W_ind only after W_ind is frozen. The engineering smoke has no fitted F family, so its two-family bisector is diagnostic only and cannot pass the primary convergence gate.

Required nulls are:

- isotropic random rotations of matched rank in the engineering smoke
- covariance-matched, spectrum-preserving rotations in the primary run
- future states shuffled within matched token, position, length, and task strata for P and T
- layer-permuted states
- matched-rank PCA
- matched-norm random and nonverbal directions
- estimator-family leave-one-out consensus
- split-half and prompt-family stability

Convergence is not declared from one favorable pair. At least three independently admissible estimator families must form a stable convergence component, and V must align with the frozen independent consensus beyond corrected null thresholds.

## 4. Local rather than global geometry

A single fixed workspace basis is not assumed. For each prompt state x, active directions may form a local cone or local subspace W(x). Stability is measured with principal angles and Grassmann distances across neighboring layers, tokens, prompts, and task families.

If orientation changes systematically with context, the correct object is a dynamic subspace field. The fuzzy memberships may parameterize that field. If dimension changes, it is treated as a stratified family rather than forced into one rank.

## 5. Decisive causal chain

The primary formation claim requires:

1. an upstream F packet is identified without workspace information
2. packet transplant changes later independently defined W_ind content
3. the local active verbal cone changes in the same preregistered direction
4. behavior changes accordingly
5. clamping W_ind removes at least half of the behavioral effect
6. clamping only V is compared against clamping W_ind
7. a matched non-consensus clamp does not mediate the effect
8. direct restoration of W_ind recovers at least half of the effect

The primary mediation analysis is a treatment-by-mediator factorial using clean, upstream treatment, treatment plus clean mediator restoration, and direct donor-mediator patch conditions. Attenuation alone is not sufficient. Negative controls require equivalence bounds rather than interpreting nonsignificance as evidence of no effect.

If only the verbal clamp mediates the result, the allowed conclusion is restricted to verbal report. If the independent consensus mediates several downstream operations, a broader workspace claim becomes possible.

## 6. Emergence versus inference

A frozen-model experiment can discover organization already produced by pretraining. It cannot show emergence over training time. Emergence requires a longitudinal checkpoint family, identical estimators frozen in advance, and evidence that independent geometry, convergence, causal function, and fuzzy formation appear in a reproducible temporal order. Multiple optimizer seeds for one frozen model quantify fitting stability but are not independent model replications.
