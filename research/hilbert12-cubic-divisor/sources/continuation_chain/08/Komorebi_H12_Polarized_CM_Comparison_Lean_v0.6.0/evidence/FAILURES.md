1. A streaming container invocation was unsupported. No file was created by that invocation, and its immediate follow-up failed because the proposed restore script did not exist. The script was then created and run synchronously. The runtime archive hash was verified and extraction succeeded.
2. A monolithic Lean cube certificate exceeded the execution limit. It was replaced by five small exact polynomial reductions with the same final identity. The timeout source is retained as a text evidence file, not counted as verified code.
3. Development Lean corrections: an unused formal parameter was renamed `_b`; a commutative-product proof was reformulated over a commutative ring using `ring`; the field division form retains its nonzero norm hypothesis; a redundant tactic was removed; complex extensionality and conjugation notation were corrected to the available API. The conceptual incidence identity is valid for commutative groups, but the compiled algebraic variant deliberately states a commutative-ring version sufficient here.
4. Several attempts to replay the complete inherited project exceeded the outer execution limit. The first six inherited modules and SignedGeometry completed in individual runs. The combined signed-module replay did not finish; subsequent individual progression stalled at H12SignedAlgebra. No cause has been proved, and this is not evidence of a false theorem. The full replay remains uncompleted rather than relabeled as a success.
5. The accepted bounded verifier compiles only the three new modules and the inherited cubic-branch dependency in a clean directory. It passes, audits every new theorem's transitive axioms, and rejects the false control. The cumulative source count 172 must not be described as a 172-theorem clean replay in this release.
6. A primary mpmath documentation URL returned HTTP 403. A readthedocs mirror was used when available; no theorem or numerical conclusion is based on the failed request.

The exact field computation found that deleting absolute values from the earlier modulus formula is mathematically false. The correction has norm one but its sixth power is not one. This is a proved negative result about that naive lift, not a failure of the original gamma conjecture.
