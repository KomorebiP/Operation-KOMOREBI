## Setting
Fix a prime p, r >= 0, R = Z/(p^r), a finite coordinate type I of size N,
a finite alphabet D, an initial vector v, and R-linear maps T_d : R^I -> R^I.
Write t[d,j,i] = (T_d e_i)_j. These are entries of the complete summed maps,
not unions of branch supports. Define nu(0)=r and, for nonzero residue x,
nu(x)=min(r,v_p(x.val)), using its canonical nonnegative integer representative.
For 0 <= c <= r put J(c)=p^(r-c)R. Thus J(0)={0} and J(r)=R.

## Exact generator test
For 0 <= c,b <= r:

    t J(c) subset J(b)  iff  max(0,c-nu(t)) <= b.

Indeed J(c) is generated by p^(r-c). Multiplying the generator by t has
capped valuation min(r,r-c+nu(t)). Every other element is a scalar multiple
of that generator. Conversely inclusion applies to the generator itself.
No inverse of p is used. Zero and nilpotent coefficients are included.

A product J(c)=product_i J(c_i) is an invariant product containing v exactly
when

    r-nu(v_i) <= c_i,
    max(0,c_i-nu(t[d,j,i])) <= c_j  for every d,i,j.

Necessity uses a vector supported at a single coordinate with value p^(r-c_i).
Sufficiency expresses (T_d x)_j as a finite sum of terms in J(c_j), which is
closed under addition. Correlations between distinct inputs are not assumed.

## Least closure and finite termination
Define

    Phi(c)_j = max(c_j, r-nu(v_j),
                       max_(d,i) max(0,c_i-nu(t[d,j,i]))).

This is monotone and inflationary on {0,...,r}^I. Start at the zero profile.
Every nonstationary step increases sum_i c_i by at least one, and this sum
is at most N*r. Once a step is stationary, all subsequent steps agree.
Therefore Phi^(N*r)(0) is fixed. Every closed profile bounds every iterate,
by induction and monotonicity. Its terminal value c* is consequently least.

This is leastness among products of the coordinate p-power ideals. It is
NOT leastness among correlated invariant submodules, minimum automata, or
presentations under arbitrary changes of basis. The generic Lean generator
construction uses positive p; the simplified valuation subtraction law uses
primality. The actual mask application retains the inherited prime hypothesis.

## Exact state reduction
Use the submodule {x in R^I | x_i in J(c*_i) for all i}. Initial membership
and transition closure give its initial vector and restricted linear maps.
The embedding is ordinary inclusion. It commutes with every transition and,
by induction, every ordered digit word. Composing the predecessor output
with inclusion preserves all output values.

The old coordinate-support product is a closed candidate (capacity r on
retained positions and 0 elsewhere). Leastness therefore embeds the new
ideal machine into the Block28 support machine. Applying this to the actual
maskSupportSystem, not an unrelated matrix model, transports the canonical
all-coefficient theorem without adding a supplied-series hypothesis.

## Cyclic normalization
For 0 <= c <= r, define

    encode_c : Z/(p^c) -> J(c),  y |-> p^(r-c) * y.val mod p^r,
    decode_c : J(c) -> Z/(p^c),  x |-> x.val / p^(r-c).

Membership ensures the integer division is exact. The canonical integer
x.val is less than p^r, so the quotient is less than p^c. Conversely
p^(r-c)*y.val is already less than p^r. These facts prove both roundtrips.

Changing y by p^c changes the product by p^r. Hence encoding is additive,
and for a in R it satisfies

    encode_c((a mod p^c)*y) = a*encode_c(y).

Thus the product of ideals has an additive equivalence, with the stated
scalar compatibility, to product_i Z/(p^(c*_i)). Its exact cardinality is
p^(sum_i c*_i). Capacity-zero factors are Z/1 and can be removed by an
explicit equivalence. This does not assert an optimized memory allocation.

The normalized transition is encode^{-1} T_d encode. For coordinate j,
compute the full residue

    z_j = sum_i t[d,j,i] p^(r-c*_i) y_i  mod p^r,

then divide its canonical representative by p^(r-c*_j). Closure proves that
this division is exact. Individual ring entries are not divided by nonunits.

## Distinguishing examples
In Z/4, v=(2,0) and T(x0,x1)=(0,2*x0), the old support contains both
coordinates and admits 16 vectors. The least ideal capacities are (1,0):
J(c*)={0,2} x {0}. This has two vectors and normalizes to Z/2 x Z/1.
The normalized transition is zero. The fact 2*2=0 is now represented.

In Z/5, v=(1,1,0), T(x0,x1,x2)=(0,0,x0-x1), the ideal closure still permits
all three coordinates independently. The correlated submodule
{(a,a,0):a in Z/5} is smaller and invariant. Coordinate ideals alone do not
capture its relation. This is the next, distinct reachable-submodule target.

## Integration and limits
The mask assumptions remain: prime p, positive r, integer A,B, p not dividing
B(0), and equal constants modulo p^r. The inherited canonical solution is
constructed, not supplied as an oracle. Only output compatibility is claimed
across precisions, not equality of the coordinate types.

The mathematical implementations use noncomputable library interfaces. The
Python implementation is an exact reference, not a formally proved compiled
refinement. No timing, memory, bit-complexity, minimal-automaton, novelty,
independent-kernel, or canonical-basis claim is made.
