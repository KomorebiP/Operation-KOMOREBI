# Block34 proof boundary

PROVED: intrinsic prefix-residual R-module and its actual seed/digit/output maps;
reachability and observability; future-output map kernel exactly equal to the
inherited unobservable submodule; image of the reachable span exactly the residual
module; unique surjective simulation from any reachable realization to any
reachable-observable realization of the same all-word behavior; unique intertwining
R-linear isomorphism between reachable-observable realizations; cardinality minimum
against ALL finite linear realizations, using the reachable part of arbitrary
competitors; finite-length comparison horizon b+c; actual-mask residual equivalence,
full simulation, all-word behavior, minimum cardinality, and proof-carrying package.

Same coefficient ring and alphabet are required in every comparison. All-word
behavior equality, not only canonical-digit output equality, is the hypothesis.
No field, freeness, or arbitrary nonunit cancellation is used. The actual masks
retain p prime, r>0, p not dividing B(0), and A(0)=B(0) modulo p^r. The canonical
series is constructed by inherited results, not supplied by an oracle.

NOT PROVED: an efficient executable Lean polynomial/lattice compiler; formal
Python-to-Lean executable refinement; minimum deterministic automaton size;
canonical literal coordinate matrices; cross-precision state morphisms or a
profinite machine; a general filtered obstruction-resolution compiler theorem;
wall-time, bit-complexity, memory, novelty or priority. Noncomputable theorem-level
compiler construction is not promotion of the audited Python engine to verified
machine code. Generic infinite alphabets have a finite word-length horizon, not
necessarily a finite set of tests.

Goal I's mathematical canonical/minimum-cardinality realization theorem is now
closed under this contract. The efficient verified implementation requirement in
the larger roadmap remains open. A chosen presentation is not a canonical basis.

The checked lane is Lean4.34.0-rc2 and pinned cached mathlib. Dependencies are not
independently rebuilt. leanchecker uses Lean's own kernel. Stable4.34.0 compatibility,
independent-kernel, and independent-human review remain unperformed. This block's
checks are self-review with orthogonal finite reference routes, not independent
human research review.
