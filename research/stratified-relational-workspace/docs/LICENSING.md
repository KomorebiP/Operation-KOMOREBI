# Licensing status

The current repository release uses an all-rights-reserved notice. The files are public for reading, citation, and scholarly review, but no general permission to copy, modify, or redistribute them is granted.

This conservative choice avoids silently assigning a reuse license on the author's behalf. Public visibility and open licensing are different decisions.

A later release may adopt separate licenses for different material, for example:

- a scholarly-content license for the monograph and documentation;
- a software license for the Python verification and build scripts;
- a data license for generated benchmark datasets, if any are later added.

Any change should be deliberate, reflected in `LICENSE`, `CITATION.cff`, and release notes, and reviewed for compatibility with external contributions. This document records repository policy rather than legal advice.
