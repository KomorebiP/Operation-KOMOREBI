# Audits

This directory contains review aids rather than additional proofs.

- `statement_index.md` and `.csv` index every theorem-like environment.
- `priority_register.csv` records the present assessment of inherited machinery, adaptations, synthesis claims, and empirical claims.
- `verification_report.md` records the final document checks for version 1.0.0.
- `completion_notes.md` records the scope of the final foundational extension.
- `github_readiness_report.md` records the repository, clean-checkout, packaging, and visual-regression audit.

The priority register is provisional and should be revised when specialist review or closer prior work changes the assessment.
