# Security policy

This repository contains LaTeX source, Python verification scripts, and GitHub Actions workflows. It does not operate a network service or process untrusted production data.

Report security concerns involving workflow permissions, dependency substitution, malicious archive contents, command injection, or release-asset integrity through GitHub private vulnerability reporting when available. Do not publish exploit details before the maintainer has had a reasonable opportunity to assess them.

Mathematical errors, citation problems, and ordinary build failures should use the public issue templates instead.
