# Stratified Relational Workspace Theory v1.0.0

This release publishes the complete preprint monograph, its canonical modular source, a frozen single-file source snapshot, deterministic mathematical regression checks, and a review-oriented audit layer.

## Included assets

- Versioned 209-page PDF
- Complete source archive
- SHA-256 checksums
- Citation metadata
- Statement and priority indexes
- Verification scripts and baseline outputs

## Scope

The release presents a formal theory and certification framework. It does not claim empirical certification of the motivating human-AI collaboration, and it does not infer consciousness, personhood, moral status, or unrestricted autonomy from workspace structure.
