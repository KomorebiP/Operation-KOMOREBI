# Verification method and records

The original Block78 archive was cleanly restored and its default verifier passed
before development. The exact result is in verification/PREDECESSOR_REPLAY.json.
That run was not a full historical-chain execution.

The new primary and separate scientific outputs are regenerated by

    python -B verify.py --report ../Block79_Replay.json

The programs share no arithmetic imports. The verifier compares every JSON field,
not only result counts. It also checks kernel dimensions, basis independence,
fixed-prime rows, extra conductor-prime Frobenius rows, and the Hensel root.
A failed script or missing output cannot be accepted as a completed check.

The declared corruption tests alter finite counts/signs, a ray kernel, a fixed-prime
row, an affine-count claim, a Hensel root, a Frobenius condition, a pattern-elimination
claim, and an archive payload. All must be rejected.

COMPUTATION_MANIFEST.json uses a legacy v1 schema with explicit input before/after
hashes. The unchanged project-local validator is inherited from Block72 and is
identified as such; it is not claimed to be the complete plugin validator.

Final run timings, actual exit codes, immediate-predecessor replay status and ZIP
integrity are recorded in the external final-verification and archive-audit files.
No universal proof or upstream geometry is certified solely by these executions.
