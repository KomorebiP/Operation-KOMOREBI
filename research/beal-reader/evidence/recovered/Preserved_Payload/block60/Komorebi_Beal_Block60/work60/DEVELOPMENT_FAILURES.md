# Failures and non-conclusions

1. The intended exclusion of the four remaining primes by diagonal period
powers did NOT succeed. Explicit primitive local Frey families pass the full
49-torsion criterion at each prime. This is a mathematical obstruction to that
particular exclusion route, not an environment failure and not a Beal counterexample.

2. Passing the old off-diagonal test is not sufficient for full49-torsion.
At each survivor prime, changing A by a primitive-root seventh power produces
an actual local family passing the7-level test but failing49. These controls
are retained, as are variants failing even7.

3. Broad source discovery returned irrelevant pages. Only directly opened
primary mathematical sources were used for the comparison. No failed search
was treated as a novelty theorem or a mathematical obstruction.

4. The exact rational smoothing exploration used SymPy to check algebraic
expressions. Production verification uses only the standard library and two
independently written arithmetic implementations. No SymPy computation is a
required external proof input.

No execution failure occurred in the observed startup replay or initial runs
of the two new production programs. Final replay status is recorded separately.
Intentional arithmetic/payload tampering is a negative control, not an ordinary
failed run. No new Lean compilation or independent mathematical review was
attempted or completed. All predecessor failures remain nested unchanged.

5. A later packaging-only edit attempted to rewrite an already-correct backslash
path check and instead introduced an unterminated string in verify.py. Python
stopped at parse time, before any scientific job ran. The check was replaced
with the unambiguous chr(92), its syntax compiled, and the replay rerun. The
failed lines and exact error are retained in verification/FAILED_verifier_escape_attempt.txt.
No mathematical output was changed by this incident.
