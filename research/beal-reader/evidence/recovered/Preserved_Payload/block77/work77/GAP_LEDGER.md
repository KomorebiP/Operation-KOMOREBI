# Gap ledger after Block 77

## Critical path

### G77-A — Affine first-stage matching

The equation `dp=-alpha cup beta` has global solutions, but the actual local
geometry may restrict the permissible local representatives of `p`.  Determine
whether one global `p` can simultaneously lie in every required local affine
condition.

### G77-B — Affine q-Selmer matching

For an admissible global `p`, the H^2 obstruction is local-global.  If it
vanishes, choose one global solution `q_0`.  The remaining question is whether
`q_0` can be shifted by a class in `H^1(K,k(chi))` to satisfy all prescribed
local `q` conditions, in particular the fixed-seven period/mixed-trace value.

### G77-C — Arithmetic computation of the local conditions

Translate the toric endpoint data, tame-lift constraints, fixed-prime geometry,
and fixed-seven uniformizer defect into explicit affine subspaces/cosets in the
local cohomology groups used by G77-A/B.
