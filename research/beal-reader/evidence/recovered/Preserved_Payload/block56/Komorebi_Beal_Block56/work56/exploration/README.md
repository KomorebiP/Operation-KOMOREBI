# Exploratory records

The initial auxiliary_scan_original.py.txt used NumPy 2.3.5 and the restored
Block52 module through an absolute sandbox path. It computed every admitted
weighted orbit at197 and491, including N2 on rows that the final staged
certificate can reject earlier. q197.json and q491.json retain those full
exploratory results. The original text is provenance, not a portable command.

The release uses only the standard library. Its fresh staged computations
and independent canonical-orbit implementation are in ../computations/.
The authoritative finite assertion does not need the redundant N2 counts
on split491 orbits already rejected by rational trace modulo7.

This directory is checksum-protected, but it is not an additional universal
proof or an asserted bound on the primes dividing C.
