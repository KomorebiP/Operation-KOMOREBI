# Authoring and recovery corrections

This record distinguishes intermediate failures from the final reviewed release. Scientific and formal replay failures are recorded separately in their own reports.

1. The first historical extraction script assumed each archive had one predecessor. It stopped at Block 51, which contains four predecessors. The replacement traversal authenticated all ZIP nodes and deduplicated them by SHA-256. It recovered 35 archives and 2,046 nonZIP payloads. The original archive bytes were never changed.
2. A source inspection requested `README.md` from Block 47. That file does not exist in the recovered package. The command stopped at the missing file and was corrected to its actual `REPORT.md`. No source was edited.
3. An initial guide coordination message accidentally described the final affine ranks as 9/10. The source reconstruction gives ranks 7, 7, 8, 7 for patterns A, B, C, D, with kernel dimensions 3, 3, 2, 3 and cokernel dimensions 8, 8, 7, 8. The guide author received the correction before accepting figure data. The localization matrix J has rank 10, which is a different matrix.
4. A coordination message incorrectly expanded the authors' initials PV. The recovered source headers identify Ariel Pacetti and Lucas Villagra Torcomian. The literature record and reader use those actual authors and the exact source version.
5. A fresh historical Lean compatibility attempt with the cached Lean 4.19/mathlib 4.19 environment failed because an imported mathlib module belongs to the original Lean 4.34 environment. The failed snapshot was retained. The exact historical mathlib commit was then acquired for a separate replay. Its final outcome is recorded in `FORMAL_STATUS.md`.
6. An intermediate metadata diagnostic assumed every JSON record was an object. The formal validation summary is a list, so the diagnostic raised `AttributeError`. A type-aware read recovered its seven records. This diagnostic did not run or change any mathematical computation.
7. The first paper layout invocation used the unsupported flag `--project paper`. The command exited with an argument error before rendering. The supported command `python3 quality_check.py --only paper` rendered all 48 pages and passed the automated page-boundary and TeX-warning checks.
8. The first packaging attempt stopped at its nested-archive guard. An authenticated duplicate of the original cumulative archive was still in the release staging directory. That duplicate was removed only after verifying that the unchanged original remains outside the release. Three other ZIPs are bounded snapshots of this edition's own figure development, not historical cumulative archives. Their exact hashes, member types, figure-only PDF/PNG paths and CRC were checked before the packaging policy admitted them. No release ZIP was produced by the stopped attempt.

Final mathematical and display corrections included integral hypotheses in the local depth theorem, the definition of the aligned valuation coordinate, higher-precision index ranges, the complete left-null condition, the distinction between a character and its coordinate parameter, exponent absorption preserving base prime support, and the primewise ramification bound. The guide's group-word exponent and matrix residue key were also made explicit. These corrections were reviewed before final source pinning.

The new reader incorporates corrections from mathematical review and current primary-source checks. Preserved historical statements and disclosures are evidence of earlier revisions, not replacements for the corrected reader. No failed attempt is reported as a successful scientific or formal check.
