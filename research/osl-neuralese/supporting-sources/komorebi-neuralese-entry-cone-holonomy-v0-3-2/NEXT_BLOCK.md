# Next Block — Independent Holonomy Replication, Then Quotient Repair

**Author:** Komorebi P.

## Why replication should come before repair

v0.3.2 found a coherent finite diagnostic pattern, consistent with a candidate
mechanism, but it also exposed strong checkpoint asymmetry. Checkpoint 0 exits
only under `F²`; checkpoint 1 also has
`R⁴`, `FRFR`, and `RFRF` exits. Optimizing a repair immediately against this
panel risks fitting the diagnostic peculiarities of these two checkpoints.

The next work should therefore be split into a confirmatory phase and a causal
intervention phase.

## Phase A — independent confirmatory replication

### Primary question

Do delayed identity-loop exits, and the relative prominence of `F²`, recur
across independently trained models and genuinely held-out task families?

### Minimum design

- Treat independently trained checkpoints—not coordinate changes—as the
  statistical units.
- Include a held-out task family or group representation never used in this
  adaptive lineage.
- Generate matched word banks under a blinded, frozen random seed.
- Increase both axes: suffix horizons beyond `H=8` and inserted budgets beyond
  64 tokens.
- Freeze first-exit survival curves and censoring rules before inspecting learned
  endpoints.
- Freeze spectral hypotheses and numerical tolerances ex ante.
- Use model-level uncertainty or exact randomization inference; do not count
  aliases, coordinate episodes, or suffix decisions as independent samples.

### Primary endpoints

1. model-level probability of any fresh cone exit by budget;
2. first-exit survival curve by relation;
3. delayed-reveal depth distribution;
4. reference-versus-randomized-control severity contrast;
5. predictive value of predeclared spectral and nonnormality features.

### Decision rule

Proceed to a mechanism-specific repair claim only if identity-loop exits
replicate on held-out models and are distinguishable from the blinded control
distribution. A failure to replicate would reclassify v0.3.2 as a useful
checkpoint-specific case study.

## Phase B — quotient-holonomy repair and transverse contraction

### Mechanistic target

Construct a semantic map `π` and operators satisfying, approximately,

```text
π(F_g(h)) = ρ(g)π(h),
```

with neutral or isometric semantic dynamics and contracting transverse fibers.
The first target should be `F²`, because it is the sole relation with v0.3.2
exits in all four checkpoint × episode-half strata.

### Four mandatory arms

| Arm | Quotient relation constraint | Transverse contraction |
|---|---:|---:|
| Compute-matched baseline | No | No |
| Algebra only | Yes | No |
| Fiber only | No | Yes |
| Combined | Yes | Yes |

An optional ambient-metric-only arm is useful as a negative control: it tests
whether a flexible metric merely downweights delayed-observable directions.

### Training principle

Do not train only on the four named relators. Sample arbitrary identity words
and nonidentity endpoint-matched words, hold entire word families out, and
penalize behavioral holonomy on the declared observable quotient. Contract only
directions demonstrated to be transverse; reversible semantic directions must
not be collapsed.

### Success criteria

- Preserve D4 accuracy, causal interventions, entry repair, and the positive
  `H=8` cone buffer.
- Shift first-exit survival curves rightward on held-out models and words.
- Reduce angular holonomy, not merely raw norm or a learned-metric norm.
- Improve arbitrary held-out identity words, not only `F²`, `R⁴`, `FRFR`, and
  `RFRF`.
- Show that contraction does not erase behaviorally delayed directions.
- Retain restricted cross-model transport or improve it under the same frozen
  bridge class.

## What would change our theory

| Outcome | Interpretation |
|---|---|
| Replication succeeds; algebra-only repairs exits | Relation curvature is primary |
| Replication succeeds; fiber-only repairs exits | Transverse leakage/amplification is primary |
| Only combined arm repairs exits | Holonomy and transverse dynamics interact |
| Metric-only looks stable but hard exits persist | Metric suppression is cosmetic |
| No held-out replication | Current phenomenon is checkpoint- or lineage-specific |
| Repairs work only on named relators | Overfitting, not causal completion |

This sequence preserves the best part of the current theory: it gives both the
holonomy proposal and the causal-quotient proposal a way to fail cleanly.
