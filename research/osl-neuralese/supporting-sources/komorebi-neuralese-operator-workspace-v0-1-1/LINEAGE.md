# Lineage and integration points

This package extends, but does not silently merge, four existing Komorebi lines.

## Controlled semantic J-space

Inherited principle: separate **functional shared semantics** from claims about spontaneous origin. The new assay retains exact lesions, donor replacements, random controls, and finite-bandwidth interpretation.

## Controlled temporal-relay workspace

Inherited principle: a shared subspace and correct causal timing do not guarantee a shared language. The new assay therefore tests held-out coordinate systems, internal operator replacement, and cross-seed continuation rather than relying on subspace rank alone.

## OSL Discovery Bridge

Inherited principle: neural proposals are untrusted until their finite action and claimed laws are independently checked. Here, exact action tables and group relations provide the oracle. Version 0.1 emits JSONL audit receipts. A later bridge should convert stable learned operator candidates into bounded OSL admission proposals.

## OSL-Core 0.5 semantic independence

Inherited principle: provenance, numerical claims, transport, and intertwiner checks should remain separately auditable. This package records source digests, per-arm receipts, exact counterfactual targets, and a fitted transport map. Direct Core 0.5 execution is intentionally deferred until a stable matrix/transport certificate format is frozen.
