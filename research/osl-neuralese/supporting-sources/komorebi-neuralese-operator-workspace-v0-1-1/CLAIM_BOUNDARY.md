# Claim boundary

## What a positive result supports

A successful run can support the following bounded statement:

> On randomly conjugated finite operator systems, the tested recurrent architecture learned a compact hidden state and episode-specific operator codes that supported exact composition, controlled counterfactual interventions, and cross-seed coordinate transport under the evaluated distributions.

## What it does not support

The package does not establish:

- spontaneous formation of a language-like latent code
- the internal architecture or behavior of Astra or any proprietary model
- the same mechanism in large language models
- semantic universality across arbitrary tasks or algebras
- open-ended symbol or operator discovery
- faithful natural-language reporting of hidden computation
- autonomous recursive self-improvement
- subjective experience, awareness, or consciousness

## Architectural confound stated directly

The `linear_hyper` model is built so that an operator table is converted into a latent matrix and recurrently applied to a hidden state. This is the intended positive control. Terminal supervision must still learn a common state coordinate system and the table-to-matrix map, but the existence of an operator-shaped computational channel is supplied by the architecture.

The scientifically important comparison is therefore not “operator structure from no prior.” It is:

- how much the supplied operator-form bias improves systematic depth generalization
- whether its state and operator channels pass exact causal interventions
- whether relation pressure improves path independence
- whether independently trained coordinate systems admit a behavior-preserving transport map

A subsequent version must progressively relax the operator-shaped architecture before making an emergence claim.
