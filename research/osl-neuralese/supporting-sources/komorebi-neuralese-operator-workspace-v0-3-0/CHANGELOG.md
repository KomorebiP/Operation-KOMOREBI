# Changelog

## 0.3.0 — 2026-09-02

- Added a sign-canonical QR recurrent operator with fixed `G = I`; retained
  matrix-exponential, Cayley, polar, and learned-diagonal variants as
  developmental backends.
- Added fail-closed hard-operator health checks and depth-2,048 finite,
  endpoint-norm, minimum-step-norm, transient-gain, orthogonality, and
  minimum-singular-value audits.
- Matched hard and soft arms on raw initialization tensors while explicitly
  documenting that projected effective dynamics and compute are not matched.
- Replaced rejection-heavy training generation with an exact cached conditional
  sampler over valid coordinate/word pairs.
- Required every nonempty contiguous subword action in every sampled training
  word to hash to the train map partition; recorded exact support sizes and
  SHA-256 receipts for lengths 1--4.
- Added a separate split-conditioned final-action assay in which the primitive
  tables and full finite word action are test-ranked.
- Added an independent exact table oracle that fails closed on action order,
  closure, finite-depth, and stability checks.
- Added per-gate seed pass fractions and kept scientific failure distinct from
  operational completion.
- Ran and disclosed development-only 4,000-step, 8,000-step, alternative-
  architecture, and four-seed qualification work. The retained qualification
  passed 8/8 engineering gates.
- Sealed the 4-arm x 12-seed Stage A primary before opening test coordinates.
- Completed all 48 primary cells, six transport pairs, and 49,152,000 directly
  conditioned training examples with zero split violations and an exact-oracle
  pass.
- Recorded bounded recovery orchestration after the original process was
  interrupted by its execution supervisor; existing cells were validated
  before only missing work was added.
- Primary result: **8/26 gates passed; conjunctive hypothesis failed**. All
  positive learned-semantic gates failed. Hard QR preserved norm through depth
  2,048 by construction but underperformed the soft arm at medium depth.
- Added 100,000-resample seed-paired post-hoc descriptive intervals. These do
  not revise the frozen gate decisions.
- Added an exact `hard_correct` seed-300 replay: metric records and all model
  tensor bytes matched exactly after declared provenance exclusions.
- Added an immutable sparse GF(5)^4 learner-input boundary, exact affine
  identifiability, monomial representability, and bounded/global train-closure
  certificates. No Stage B model primary was run.
- Added a developmental functional-transport API for residual-within-codebook,
  bidirectional cycle, operator, commuting-square, and component-specific
  assays. Stage A continues to use the legacy eight-state transport diagnostic.
- Preserved the v0.2.0 and v0.1.1 archives with exact hashes.
