## Parent outcome

The v0.1.1 terminal linear checkpoint was already known to be accurate at moderate depth and unstable at long depth. All v0.2 work is therefore developmental unless a later run uses outcome-independent frozen seeds and gates.

## Revision 1

The first stability smoke used the learned anchor metric directly in the ambient hidden coordinates. The exact anchor-closed operator passed accuracy, causal, null-cycle, and isometry checks, but the relation checkpoint's metric condition number was approximately 606, exceeding the frozen limit of 256.

That failed smoke is retained under `results/stability_smoke_v2`.

## Revision 2

The same closed action was transported into its canonical one-hot semantic chart. This is a similarity-coordinate correction, not a change to the abstract operator action. It makes the recurrent metric exactly Euclidean, with condition number one. The revised smoke and pilot evaluate both the ambient and canonical charts and keep the failed revision-1 artifacts visible.

Matched episode streams were also adopted across variants after the first smoke so differences are paired rather than affected by Monte Carlo variation.

## Projective training screen

An exploratory two-seed run found that normalizing the hidden ray after every learned operator application greatly improved long-depth terminal-only performance. The developmental pilot thresholds in `PROJECTIVE_PREREGISTRATION.json` were frozen after that screen. They are not outcome-independent confirmatory thresholds.

## Numerical audit correction

The first stored observability report centered the float32 decoder before promoting it to float64. The rounding residue made the centered decoder appear rank eight even though common-logit invariance limits it to rank seven. Version 0.2.0 now promotes before centering and uses a relative singular-value tolerance. The centered decoder is rank seven, while the finite future-observability stack remains full rank eight. The scientific conclusion—no detected fixed additive future-null packet—therefore remains unchanged.

## Residual-holonomy screen

After the terminal-only projective pilot, an interactive one-seed development screen added anonymous anchor-intertwining pressure. A strong weight improved depth-512 D4 accuracy to approximately 0.86, but depth-1024 accuracy remained approximately 0.53 and hidden loop angles remained nonzero. This unarchived screen is not a retained result or gate. It is recorded only to explain why the package stops at the more defensible conclusion: structural pressure can delay projective drift, but exact learned path flatness has not yet been demonstrated.
