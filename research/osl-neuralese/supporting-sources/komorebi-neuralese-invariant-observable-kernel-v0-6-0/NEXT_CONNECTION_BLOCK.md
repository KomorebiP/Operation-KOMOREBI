# Next connection block: exact quotient functors and synchronized ambient lifts

**Author:** Komorebi P.  
**Status:** design synthesis; no experiment has been run under this design  
**Provisional name:** Synchronized Exact-Sequence Connection (SESC)

## Executive decision

The next operator block should not search for another coefficient that makes an
approximately invariant subspace look exact for longer. The v0.6 failure mode
is structural: a small generator-level intertwining residual is still nonzero,
and a long product can eventually rotate that residual into the centered-logit
interface. Orthogonal recurrence removes radial explosion, but it cannot turn
an approximate quotient into an exact one.

The immediate next block should therefore put three properties in different
parts of the construction:

1. **Radial stability** is enforced by an exact metric-isometric
   parameterization.
2. **Semantic flatness** is enforced by an exact representation/functor on the
   behavioral quotient, preferably with categorical error correction rather
   than repeated multiplication of approximate dense matrices.
3. **Ambient curvature** is carried only by a typed vertical action that is
   algebraically unable to affect the quotient.

The learned question then becomes narrower and cleaner:

> Can a model learn the anonymous synchronization between contexts and select
> the correct exact semantic functor, while the quotient law, radial bound, and
> separation from ambient curvature are guaranteed rather than encouraged by
> competing losses?

This would be a hybrid neural/algebraic mechanism result. It would not yet be
spontaneous continuous Neuralese. That limitation is a feature of the design:
it isolates whether context identification and transport can be learned without
confounding them with accumulating numerical connection error.

Useful ambient memory should **not** be claimed in this D4 block. A fixed
isometric linear D4 system with an invariant observation kernel necessarily
splits. A separate typed `WRITE`/`HOLD`/`QUERY` path-category task is required
to test memory.

## 1. What v0.6 teaches

The learned-intertwiner strategy asks an unrestricted recurrent system to make

\[
\Pi M_g\approx T_g\Pi
\]

through a weighted loss. Even when the one-step residual is small and moderate
depth behavior is strong, this does not create the algebraic zero needed for a
permanent quotient. The relevant telescope is exact. For a word
\(w=g_n\cdots g_1\), define

\[
E_g=\Pi M_g-A_g\Pi.
\]

Then

\[
\Pi M_w-A_w\Pi
=
\sum_{j=1}^{n}
A_{g_n}\cdots A_{g_{j+1}}
E_{g_j}
M_{g_{j-1}}\cdots M_{g_1}.
\]

If both actions are isometric in their registered metrics and
\(\lVert E_g\rVert\le\delta\), the generic bound is

\[
\lVert\Pi M_w-A_w\Pi\rVert\le n\delta.
\]

If the total maps can expand by \(\kappa>1\), the corresponding bound is
geometric. Likewise, if a learned null loop is \(H=I+R\), then

\[
\lVert H^m-I\rVert
\le (1+\lVert R\rVert)^m-1.
\]

These are worst-case bounds, not predictions that every trajectory saturates
them. They explain why more training or a larger penalty can move the failure
horizon without establishing closure. The next block should replace the
residual by an identity that holds by construction.

The three desired properties are logically independent:

| Property | Exact statement | What it prevents | What it does not imply |
|---|---|---|---|
| Radial stability | \(M_f^\mathsf T G_yM_f=G_x\) for a transport \(f:x\to y\) | norm explosion | semantic path independence |
| Quotient flatness | \(\pi_yM_f=A_{q(f)}\pi_x\) with \(A\) a functor | any future semantic leakage from relation paths | full latent flatness |
| Ambient curvature | vertical holonomy \(V(v)^{-1}V(u)\ne I\) for \(q(u)=q(v)\) | nothing; it is a deliberately retained degree of freedom | useful memory or causal relevance |

## 2. The two exact sequences

There are two quotients in the problem and they should not be conflated.

For each visible context \(x\), let
\(F_x^+=\Sigma_x^*\) be the free positive-word monoid generated by its visible
operator slots. Its exact finite action is

\[
q_x^+:F_x^+\longrightarrow G_x\le S_8.
\]

At the monoid level, semantic equality is the kernel congruence

\[
u\sim_xv\quad\Longleftrightarrow\quad q_x^+(u)=q_x^+(v),
\]

not merely the set of words mapping to the identity. If the generators are
formally inverted, write \(\mathbb F(\Sigma_x)\) for the resulting free group.
The normal relation subgroup is the kernel in

\[
1\longrightarrow R_x\longrightarrow \mathbb F(\Sigma_x)
\xrightarrow{q_x}G_x\longrightarrow1.
\]

The implementation need use only the monoid. The group sequence is invoked
only for inverse-based holonomy and cohomology statements. Below, \(q_x\)
denotes the appropriate monoid map or its group extension when the distinction
is immaterial.

Independently, the latent observation boundary is

\[
0\longrightarrow N_x\longrightarrow H_x
\xrightarrow{\pi_x}\bar S_x\longrightarrow0,
\qquad \dim(H_x,N_x,\bar S_x)=(12,5,7).
\]

Vector-space exactness is automatic once \(\pi_x\) is surjective. The
scientific content is equivariance of this sequence, a noncollapsed quotient,
and correct held-out behavior.

The total recurrent lift \(\rho_x\) is a representation of the free path
system. The semantic action \(A_x\) factors through the finite action group:

\[
\boxed{\pi_x\rho_x(w)=A_x(q_x(w))\pi_x.}
\]

This single naturality equation has the desired permanent consequence. If
\(q_x(u)=q_x(v)\), then for every suffix \(s\),

\[
\pi_x\rho_x(s)\rho_x(u)
=A_x(q_x(s)q_x(u))\pi_x
=\pi_x\rho_x(s)\rho_x(v).
\]

No finite suffix observer is needed to extrapolate this equality. It is true
for every path admitted by the algebraic model.

The total lift need not factor through \(G_x\). For a relation word
\(r\in R_x\), the quotient action is the identity while \(\rho_x(r)\) may act
nontrivially on \(N_x\). This is the precise place where harmless ambient
holonomy can live.

Categorically, the clean object is:

- a total functor \(\rho\) on the free path category \(\mathcal F\);
- a semantic functor \(A\) on its relation quotient \(\mathcal C\), with
  quotient functor \(q:\mathcal F\to\mathcal C\); and
- a surjective natural transformation \(\pi:\rho\Rightarrow A\circ q\) on
  the common source category \(\mathcal F\).

Calling the total lift a D4 representation when its relation words rotate the
fiber would be incorrect. Only its quotient factors through D4.

## 3. The splitting obstruction

The ambient-space question exposes a useful no-go theorem.

### Fixed-kernel isometric splitting

Let \((H,\langle\cdot,\cdot\rangle_G)\) be finite-dimensional with \(G>0\).
Suppose every generator satisfies

\[
M_g^\mathsf TGM_g=G
\]

and a fixed subspace \(N\) is invariant. Since \(M_g\) is invertible,
\(M_gN=N\). For \(x\in N^{\perp_G}\) and \(n=M_gm\in N\),

\[
\langle M_gx,n\rangle_G
=\langle M_gx,M_gm\rangle_G
=\langle x,m\rangle_G=0.
\]

Thus \(N^{\perp_G}\) is also invariant. In the
\(G\)-orthogonal chart \(N^{\perp_G}\oplus N\), every generator is block
diagonal. The apparent lower-left semantic-to-fiber write block vanishes.

This result is generatorwise; it does not require the generators to satisfy
D4 relations. Global isometry plus one fixed invariant kernel already forbids
a genuine linear write into that kernel.

### Finite-group strengthening

If the total action really is a real representation of the finite group D4,
the conclusion is stronger and does not require an initially supplied metric.
Given any projection \(p:H\to N\), average it:

\[
P=\frac1{|G|}\sum_{g\in G}\rho(g)p\rho(g)^{-1}.
\]

Then \(P\) is equivariant, \(P|_N=I\), and \(\ker P\) is an invariant
complement. This is the finite-dimensional real form of Maschke's theorem.
Every linear extension splits.

In a chosen nonorthogonal section, a split action can appear triangular:

\[
\rho(g)=
\begin{bmatrix}
A_g&0\\
C_g&V_g
\end{bmatrix}.
\]

For a finite-group representation, the apparent cocycle is removable by a
shear. There is an \(X\) for which

\[
C'_g=C_g+XA_g-V_gX=0.
\]

Affine cocycles are likewise translated away by the averaged fixed point.
Consequently, a nonzero displayed \(C_g\), a decodable fiber coordinate, or
fiber energy is not evidence of intrinsic memory.

### Consequence for this program

The v0.6 curved \(K\) control is coherent precisely because its total fiber
maps do **not** obey all D4 relations. The quotient is D4-flat; the fiber is a
representation of free paths and can retain relation holonomy. With no
semantic/fiber coupling and natural states initialized at \(K=0\), that
curvature is dormant gauge motion.

A Markov D4 endpoint task neither needs nor identifies memory. Trying to make
the same fixed-kernel, globally isometric linear system demonstrate useful
ambient memory would contradict the structure above. The stable quotient
benchmark and the useful-memory benchmark must be separate claims.

## 4. Exact ambient-aware construction

The most economical positive construction uses the eight-dimensional
permutation carrier directly. Let

\[
J_8=I_8-\frac18\mathbf1\mathbf1^\mathsf T,
\qquad
\widehat H=\mathbb R^8\oplus\mathbb R^4.
\]

The first summand decomposes as the centered semantic space plus the common
logit line. In canonical coordinates,

\[
\widehat N=\operatorname{span}(\mathbf1)\oplus\mathbb R^4,
\qquad
\widehat\pi(z,k)=J_8z.
\]

For a visible operator slot \(a\), let \(P_x(a)\) be its exact eight-state
permutation matrix. Choose a vertical generator \(V_x(a)\in O(4)\), and set

\[
\widehat M_x(a)=P_x(a)\oplus V_x(a).
\]

Extend this assignment multiplicatively to free words. Since every
permutation fixes \(\mathbf1\) and commutes with \(J_8\),

\[
\widehat\pi\widehat M_x(w)
=P_x(q_x(w))\widehat\pi.
\]

The quotient is therefore exact. The vertical generators are not required to
satisfy the D4 relations. If \(u\sim v\),

\[
\widehat M_x(v)^{-1}\widehat M_x(u)
=I_8\oplus\bigl(V_x(v)^{-1}V_x(u)\bigr).
\]

This gives zero semantic holonomy and potentially nonzero vertical holonomy
without any semantic leakage.

The canonical anchors and decoder can be

\[
\widehat b_i=(e_i,0),
\qquad
\widehat D(z,k)=z.
\]

Their centered interface has rank seven, the common-logit line and four-fiber
directions form the exact five-dimensional kernel, and the eight anchors are
orthonormal.

### Dense coordinates and Komorebi covariance

Let \(F_x\in GL(12)\) be any registered well-conditioned frame and transport
all objects together:

\[
M_x(a)=F_x\widehat M_x(a)F_x^{-1},
\quad
\pi_x=\widehat\pi F_x^{-1},
\quad
b_{x,i}=F_x\widehat b_i,
\]

\[
D_x=\widehat D F_x^{-1},
\qquad
G_x=F_x^{-\mathsf T}F_x^{-1}.
\]

Then

\[
M_x(a)^\mathsf TG_xM_x(a)=G_x,
\qquad
\pi_xM_x(a)=P_x(a)\pi_x.
\]

This is the coordinate-independent object: the exact sequence, metric,
operators, observations, and anchors are co-transported. A dense coordinate
change may make every displayed matrix look mixed. It cannot change kernel
invariance, descended action, holonomy conjugacy class, or causal behavior.

For the first implementation rung, \(F_x\) should be fixed and orthogonal.
General-\(GL\) transport belongs in the assay, with the metric carried along;
it should not be introduced as an optimization gauge.

### Curvature choice without coefficient tuning

The flat-fiber control makes \(V_x\) factor through the same finite action, so
all vertical relation holonomies vanish. The curved-fiber control assigns
predeclared noncommuting, orientation-preserving signed-permutation generators
in \(SO(4)\) to the visible slots. One concrete registered choice is
\(V_f=R_{12}(\pi/2)\) and \(V_r=R_{23}(\pi/2)\), represented by exact
zero/one/minus-one matrices. The semantic relator \(f^2=e\) then has

\[
V_f^2=\operatorname{diag}(-1,-1,1,1)\ne I_4.
\]

Thus nonzero vertical relation holonomy is proved by the construction rather
than inferred from generic noncommutativity. No curvature loss or target
magnitude is optimized.

Signed permutations are preferable for the first control because their
products are exact in float32. Continuous \(SO(4)\) generators obtained from
\(\exp\Omega\), \(\Omega^\mathsf T=-\Omega\), can be added only after the
integer-valued control validates the assay.

## 5. Cocycle controls: motion is not memory

The general no-leak lift in a selected splitting has form

\[
\rho(f)=
\begin{bmatrix}
A(q(f))&0\\
c(f)&V(f)
\end{bmatrix}.
\]

Multiplicativity requires the crossed-cocycle law

\[
c(fh)=c(f)A(q(h))+V(f)c(h).
\]

For a relation word \(r\), \(A(q(r))=I\), and repeating it gives

\[
\rho(r)^m=
\begin{bmatrix}
I&0\\
\displaystyle\sum_{j=0}^{m-1}V(r)^jc(r)&V(r)^m
\end{bmatrix}.
\]

The component of \(c(r)\) in the fixed space of \(V(r)\) grows linearly with
\(m\). A finite repeat bank can therefore make a nonsplit-looking cocycle seem
stable while merely postponing its failure.

The correct bounded shear control constructs only a coboundary. For a fixed
map \(B:\bar S\to K\), let

\[
J_B=
\begin{bmatrix}I&0\\B&I\end{bmatrix},
\qquad
\rho_B(f)=J_B
\begin{bmatrix}A(q(f))&0\\0&V(f)\end{bmatrix}
J_B^{-1}.
\]

Its displayed write term is

\[
c_B(f)=BA(q(f))-V(f)B,
\]

and it is isometric in the transported metric
\(G_B=J_B^{-\mathsf T}J_B^{-1}\). This arm must be recognized as a gauge shear
of a direct sum. If an attribution assay calls it useful memory, that assay is
invalid.

For near-identity unconstrained models, a posthoc cohomology diagnostic may
fit the least-squares \(B\) and report the residual

\[
\min_B\sum_g\lVert C_g-(BA_g-V_gB)\rVert_F^2.
\]

This quantity is interpretable as a cohomology residual only after a fixed
invariant \(N\) has been certified, the upper-right leakage block is zero, and
the extracted \(A_g\) and \(V_g\) approximately obey their own composition
laws. Otherwise it is merely a shear-fit residual. In either case it is a
diagnostic, not a training objective and not a proof of memory.

## 6. Context connection and group synchronization

Random conjugation creates a family of local semantic charts. The next learned
target should be their synchronization.

Let \(P_\star:G_\star\to S_8\) be a reference action. A complete
synchronization candidate for context \(x\) is
\(\eta_x=(\widehat P_x,\alpha_x,J_x)\), where \(\widehat P_x\) is a proposed
completion of the partially observed action, \(\alpha_x:G_x\to G_\star\) is a
group isomorphism, and \(J_x\in S_8\) is a state-coordinate bijection
satisfying

\[
J_x\widehat P_x(a)=P_\star(\alpha_x(a))J_x
\qquad\text{for every }a\in G_x.
\]

Let \(Z\in\mathbb R^{7\times8}\) be any fixed orthonormal chart of the
centered subspace, so \(ZZ^\mathsf T=I_7\) and \(Z^\mathsf TZ=J_8\). The
reference representation and the candidate-induced local frame are

\[
\sigma(b)=ZP_\star(b)Z^\mathsf T,
\qquad
Q_x=(ZJ_xZ^\mathsf T)^{-1}.
\]

Thus \(Q_x\) is not an independently learned continuous gauge. It is induced
by the selected finite state/action isomorphism. The local representation is

\[
A_x(a)=Q_x\sigma(\alpha_x(a))Q_x^{-1}
=Z\widehat P_x(a)Z^\mathsf T.
\]

The semantic transport from context \(x\) to \(y\) is

\[
T^{S}_{xy}=Q_yQ_x^{-1}.
\]

Because transports are derived from node gauges rather than learned
independently,

\[
T^S_{yz}T^S_{xy}=T^S_{xz}
\]

holds exactly. For the corresponding element map
\(\beta_{xy}=\alpha_y^{-1}\alpha_x\), naturality is

\[
T^S_{xy}A_x(a)
=A_y(\beta_{xy}(a))T^S_{xy}.
\]

For finite D4 contexts, build one universally ordered candidate catalogue
without consulting any held-out table entry, then filter it using only the
registered partial demonstrations. Candidate IDs are freshly permuted or
stripped before every episode so their order cannot reveal the withheld
completion. The native simulator retains the true \(P_x^\star\) behind the
evaluation seal. A neural synchronizer should output a **joint node
assignment** over the connected context graph, not independently marginalized
per-context choices. At execution it selects one joint candidate with a frozen
tie-break; it must not execute a convex mixture of incompatible isomorphisms.

The gauge orbit must be defined operationally, not declared from the abstract
automorphism group alone. A common reference transformation
\((\gamma,U)\) is gauge only when

\[
UP_\star(b)U^{-1}=P_\star(\gamma(b))
\]

and the reference codebook, frame, and every affected output label are
co-transported by \(U\). If output labels are held fixed and \(U\) changes a
held-out observable action, the candidates are scientifically distinct.
Training may marginalize only over one shared global
observational-equivalence orbit for the entire context graph. The
wrong-synchronization control is demonstration-consistent but selected outside
that orbit and has a preregistered held-out distinguishing witness.

The exact pairwise transports are then induced from the selected node labels.
This is group synchronization rather than a triangle-consistency penalty.
Cycle consistency is guaranteed, while held-out naturality and transported
behavior against the separately sealed native simulator determine whether the
selected synchronization is correct. In particular, evaluation uses the true
relative map \(\beta_{xy}^\star\), not
\(\alpha_y^{-1}\alpha_x\) induced by the prediction. A cycle-consistent but
semantically wrong assignment is an explicit control.

### Full context connection with vertical curvature

With local dense frames, a full transport may be written

\[
\Gamma_{xy}
=F_y
\begin{bmatrix}
J_{xy}&0\\
0&W_{xy}
\end{bmatrix}
F_x^{-1},
\]

where \(J_{xy}=J_y^{-1}J_x\) is the eight-state lift induced by the same
selected synchronization, including the common-logit line, and
\(W_{xy}\in SO(4)\) is a vertical edge transport. It is not an independent
semantic map. The full transport obeys

\[
\Gamma_{xy}^\mathsf T G_y\Gamma_{xy}=G_x.
\]

Node synchronization makes semantic loop holonomy exactly trivial.
Independently assigned vertical edge maps may have

\[
W_{x_0x_m}\cdots W_{x_2x_1}W_{x_1x_0}\ne I.
\]

Thus the quotient connection can be flat while the total bundle is curved.
The vertical connection is not called cross-context language unless it also
satisfies separately tested operator naturality and causal transport criteria.
After float serialization, the exact triangle and isometry identities become
numerical-tolerance integrity checks rather than literal real-arithmetic
equalities.

## 7. Exact execution and discrete error correction

Repeated dense multiplication is the wrong place to demand exact finite-group
closure. Once a context synchronization has been selected, maintain the
semantic state as a categorical action element or state index and update it by
the exact Cayley/action table. Retrieve its registered latent representative
only at the observation boundary.

Equivalently, let \(\{z_a:a\in G_x\}\) be a finite semantic codebook with
minimum metric separation

\[
\Delta=\min_{a\ne b}d_G(z_a,z_b).
\]

A neural proposal \(\widetilde z_{t+1}\) is projected to the nearest valid
codeword after each step. If its local error is strictly below \(\Delta/2\),
nearest-codeword projection recovers the exact state. By induction, correct
local proposals do not accumulate angular error at all.

This does not make the system infallible. It changes the failure mode from
gradual drift to an explicit discrete misclassification. Report both:

- the categorical error rate; and
- the certified correction radius/margin before every projection.

Crossing \(\Delta/2\) only removes the guarantee; it does not by itself imply
an error. The positive control must therefore move a proposal across a known
Voronoi facet into a registered neighboring codeword, rather than merely add a
large undirected perturbation.

The visible-table executor is an explicit symbolic upper bound, not learned
Neuralese. The scientifically interesting arm must infer the anonymous
synchronization or missing action entries from demonstrations and then use the
same exact executor. A later rung can remove the codebook projection and ask
whether an unrestricted continuous model converges to the same structure.

## 8. Optimization without structural loss coefficients

The next block should not use a weighted sum of anchor, readout,
intertwining, relation, and curvature terms.

The construction contract is:

1. Metric isometry, kernel invariance, semantic homomorphism, and synchronization
   cycles are identities enforced by parameterization.
2. Vertical curvature is fixed by the chosen flat or curved control; it is not
   rewarded.
3. The only learned discrete variable is the context isomorphism/action
   candidate. Train it with one categorical likelihood, marginalized over the
   valid joint observational-equivalence orbit.
4. If partial demonstrations leave several candidates genuinely equivalent,
   retain and propagate that posterior rather than inventing a label.
5. On pre-certified identifiable cases, use a hard candidate and exact
   execution. On genuinely ambiguous cases, score the candidate set and answer
   only invariant queries; report forced tie-break behavior separately. Report
   coverage, ambiguity, and calibration without discarding contexts.
6. Any posthoc fit of a frame, shear, or unrestricted model to the exact
   extension manifold is a separate least-squares audit performed after the
   checkpoint is frozen.

One likelihood removes explicit coefficient competition, not implicit
weighting. The candidate prior, context and stratum sampling measure,
likelihood temperature/noise model, ambiguity rule, tie-break, stopping rule,
and checkpoint-selection rule must all be sealed before the fresh screen.

A useful terminal-only form is

\[
\mathcal L_{sync}
=-\log\sum_{\boldsymbol\eta\in\mathcal A_{\mathcal X}}
p_\theta(\boldsymbol\eta\mid\text{demonstrations on }\mathcal X)
\,p(y_{\mathcal X}\mid\boldsymbol\eta),
\]

where \(\mathcal A_{\mathcal X}\) is the exact finite joint
observational-equivalence orbit for the connected context graph and the
executor defines \(p(y_{\mathcal X}\mid\boldsymbol\eta)\). There is no free
coefficient balancing this loss against structural equations.

## 10. Acceptance predictions and falsifiable hypotheses

The `C` statements below are compiler/assay acceptance predictions, not
learned scientific discoveries. H1 is the primary empirical hypothesis. M1 is
a matched mechanism comparison; H2 combines a theorem-backed acceptance test
with unconditional learned performance.

### C1 — exact separation contract

`direct_quotient_curved` will simultaneously show:

- metric-norm preservation;
- exact rank-seven centered quotient and rank-five kernel;
- zero semantic relation holonomy and zero cross-kernel leakage;
- nonzero vertical relation holonomy; and
- identical semantic outputs after arbitrary registered suffixes and nonzero
  vertical interventions.

Failure rejects the implementation or assay, not the mathematical statement.

### M1 — soft residual accumulation comparison

The inherited soft-intertwiner arm is evaluated alongside a per-word
telescoping certificate computed from its measured generator residuals. A
separate analytic control inserts a planar semantic loop rotation of size
\(\epsilon\) and tests repeats only while \(m\epsilon\le\pi/4\); its measured
angle must equal \(m\epsilon\) within the numerical contract. Fixed
logarithmic \(\epsilon\) levels, depths, directions, and the endpoint statistic
must be preregistered. The bound is not itself treated as a predicted
correlation. If the soft arm reaches numerical-zero intertwining and passes
the same sealed depth gates, the premise for replacing it is rejected.

### H1 — synchronization is learnable

From partial anonymous demonstrations, the categorical synchronizer will
select the correct joint global isomorphism orbit on unseen coordinate
conjugations and operator-slot assignments. Its transported continuations will
match native execution and beat wrong-orbit and random-map controls.

### H2 — learned execution avoids gradual angular drift

Conditional on a correct synchronization, categorical execution will show no
depth-induced accuracy degradation and will retain a uniform registered lower
margin over every codeword stratum. Injected proposal noise below half the code
distance will be corrected indefinitely. Targeted perturbations across known
Voronoi facets will produce the registered neighboring categorical error.
Unconditional end-to-end behavior must also pass, so selector mistakes cannot
be conditioned away.

### C2 — curvature separation contract

Changing or transplanting only the vertical generator/connection maps will
change registered vertical loop holonomy while leaving all centered logits,
semantic margins, categorical states, and causal semantic interventions
unchanged. A cross-block-leaky control must violate this invariance.

### C3 — coboundary recognition contract

The `coboundary_shear` arm will exhibit nonzero displayed semantic-to-fiber
blocks but admit an exact shear back to a direct sum. This block gates only
recovery of that registered equivalence. Necessity-specific memory verdicts
are deferred to the typed memory experiment in Section 14.

## 11. Go/no-go gates

Overlapping numerical and behavioral thresholds should be inherited unchanged
from v0.6. New thresholds must be sealed before a fresh seed. No threshold may
be relaxed because an exact construction misses it.

### Gate A — algebra and assay integrity

All must pass before learned results are interpreted:

1. Integer action tables satisfy identity, inverse where applicable, and
   composition bit-for-bit.
2. The serialized float32 direct construction passes the existing rank-seven,
   rank-five, projector, centered-readout, and gauge-covariance checks.
3. Generator isometry and intertwining residuals are within the registered
   dtype-derived numerical tolerance.
4. `direct_full_flat` has zero semantic and vertical relation curvature.
5. `direct_quotient_curved` has zero semantic curvature and exceeds the
   existing v0.6 minimum vertical-curvature gate.
6. The leaky, rank-collapse, identity-collapse, wrong-sync, random-map, and
   coboundary-shear controls receive their preregistered classifications.
7. Connection cycles induced by every selected node assignment close within
   serialization tolerance; this is an architectural integrity check, not
   evidence that the assignment is correct.
8. Separate operator, decoder, context-edge, and mixed-composite
   \(N\to S\) leakage controls are detected by both spanning-basis and
   worst-singular-vector interventions, including a near-threshold positive
   control.

### Gate B — exact persistent quotient

For the exact curved arm:

- robust native accuracy passes the existing v0.6 depth-512 and loop gates and
  a new depth-4096 extension;
- worst semantic relation defect, worst generator leakage, and worst
  suffix-visible null effect remain at numerical tolerance;
- every registered nonzero vertical intervention is eligible and retains the
  native semantic prediction and margin;
- matched semantic interventions retain the existing causal-patch accuracy and
  specificity gates; and
- replacing the vertical connection changes vertical holonomy but changes no

Failure is `ASSAY_OR_CONSTRUCTION_INVALID`; it is not a negative learned result.

### Gate C — learned synchronization

## 12. Induction ladder from compiled exact to learned

Each rung removes exactly one scaffold. Results from different rungs must not
be pooled under one claim.

| Rung | What is compiled | What is learned/tested | Maximum justified claim |
|---:|---|---|---|
| 0 | canonical action, split, metric, decoder, flat fiber | assay only | exact oracle validity |
| 1 | canonical action and exact sequence; curved free-path fiber; registered dense frame | coordinate-covariance assay only | coordinate covariance with dormant curvature |
| 2 | finite candidate action set and exact executor | anonymous context synchronization | learned connection selection |
| 3 | exact categorical composition engine | missing generator actions from partial demonstrations | learned operator identification with compiled closure |
| 4 | only the exact-sequence/functor parameterization | representation and synchronization jointly from demonstrations | structurally induced quotient representation |
| 5 | nothing in the recurrent core | posthoc extraction tested on frozen unrestricted models | evidence for emergent continuous quotient structure |

Advancement rule: a rung is attempted only after the previous rung passes its
absolute gates. A failure is retained; the removed scaffold is restored rather
than compensated for with new auxiliary weights.

Rung 5 requires more than fitting a projector. A frozen unrestricted model
must admit an out-of-sample map to the exact extension manifold that preserves
held-out causal interventions, relation products, context transports, and deep
continuations. Low reconstruction error alone is insufficient.

## 13. Lie-algebra and holonomy audit

After whitening by the registered metric, for a near-identity orthogonal
holonomy \(H_c\) with no eigenvalue on the principal-log branch cut, define

\[
\Omega_c=\operatorname{Log}(H_c).
\]

In an exact-sequence chart, report separately

\[
P_S\Omega_cP_S,
\quad
P_S\Omega_cP_N,
\quad
P_N\Omega_cP_S,
\quad
P_N\Omega_cP_N.
\]

The first is semantic curvature, the cross terms are infinitesimal leakage,
and the last is vertical curvature. The exact curved arm should have only the
last component.

The matrix logarithm must not be forced through an eigenvalue at \(-1\).
First report the determinant component. For identity-component holonomies,
including principal-log branch-cut cases, use the conjugacy-invariant rotation
angles \(\theta_j\in[0,\pi]\) from a real Schur decomposition. With the
half-Frobenius Lie-algebra metric, report the canonical \(SO(q)\) geodesic
magnitude

\[
d_{SO(q)}(I,H_c)=\left(\sum_j\theta_j^2\right)^{1/2}.
\]

A determinant-negative control lies in the disconnected component of
\(O(q)\); it receives its own discrete flag rather than a fictitious finite
geodesic to the identity. The primary curved-fiber construction stays in
\(SO(4)\).

Logarithms are diagnostics, not the definition of flatness. Exact
intertwining, path behavior, and cross-block zeros remain the gates.

For context triangles, apply the same split to

\[
H^S_{xyz}=T^S_{zx}T^S_{yz}T^S_{xy}
\]

and to the corresponding vertical product. Quotient synchronization requires
\(H^S_{xyz}=I\); vertical triangle holonomy may be nonidentity.

## 14. Separate future block for useful ambient memory

Useful memory requires two histories to share the same present quotient while
retaining different payloads that a declared future consumer can recover. The
decisive task should construct paired histories with:

1. the same D4 quotient state;
2. different continuous payloads;
3. identical required outputs throughout `HOLD`; and
4. predictably different required outputs only on `QUERY`.

The full dynamics must be a typed path monoid or small category, not an exact
D4 representation. Merely adding affine offsets does not evade the finite-group
obstruction: an exact affine action of a finite group has an averaged fixed
point and can be translated to a linear action. The evasion must come from
noninvertible or contractive monoid dynamics, phase-dependent observation, or
an explicitly typed read/release arrow. Three essential arms are:

| Arm | Dynamics | Expected result |
|---|---|---|
| fixed-isometric fixed-kernel | one invariant \(N\), every arrow a \(G\)-isometry | no-go control; cannot both write and later reveal payload |
| contractive/nilpotent writer | \(k' = Sk+bu\), typed query head reads \(k\) | bounded finite memory, as in ANC-4 |
| phase-indexed orthogonal write/read | `WRITE` and `READ` change the active observation split; `HOLD` preserves it | reversible typed storage without a globally fixed kernel |

A nonlinear compact skew product is a later fourth arm:

\[
s'=a_g(s),
\qquad
k'=F_g(s,k,u),
\]

with a query-specific head or release map. In every valid memory arm, \(K\) is
null only to the hold-phase interface, not to all future consumers.

The memory gates are causal and provenance-sensitive:

- deleting \(K\) at a matched quotient state destroys the query answer but
  not pre-query behavior;
- transplanting \(K\) transfers the exact donor answer at query while
  retaining recipient semantics before query;
- energy-matched random and semantic-only transplants fail;
- long holds remain bounded and preserve the payload within a registered
  tolerance;
- payload origin, write time, and authorized query path are recoverable from
  the execution receipt; and
- the fixed-isometric/fixed-kernel no-go arm does not pass through an
  undeclared side channel.

This memory block should follow, not be pooled with, the SESC operator block.

## 15. Claim boundary

A full pass of the immediate block could support:

> In a finite anonymous operator environment, a learned synchronizer can select
> the correct equivalence class of context connection, after which an exact
> categorical semantic functor supports stable deep execution. The total
> latent lift can retain nontrivial vertical path holonomy while its invariant
> five-dimensional observation kernel prevents that holonomy from affecting
> any semantic continuation.

The words “exact” and “stable” in that statement refer to the parameterized
algebra and the registered numerical execution contract. They do not imply
that a neural network discovered the laws without scaffolding or that physical
floating-point execution is literally infallible at infinite depth.

The block would **not** establish:

- spontaneous Neuralese;
- a learned continuous invariant kernel in an unrestricted model;
- useful ambient memory;
- that vertical curvature carries task information;
- a non-split real linear D4 extension;
- architecture-independent or open-ended group discovery;
- consciousness, awareness, preference, or subjective experience.

The most important negative boundary is mathematical, not rhetorical:

> Under a fixed positive-definite isometry and a fixed invariant observation
> kernel, the linear system splits. Under an exact finite-group action, real
> linear extensions split even without that supplied metric. Genuine ambient
> memory therefore requires typed time, changing observation access,
> non-group dynamics, nonlinearity, or an explicitly non-isometric write.

That boundary turns the ambient space from an unspecified reservoir into a
typed object. Some vertical motion is gauge curvature. Some vertical state is
memory for a declared future query. The experiment should be designed so those
two possibilities cannot impersonate each other.
