MICRO OSL OFFLINE LAB v0.1.1 — WINDOWS QUICK START

This package creates its own executable training text. It does not download a
pretrained model or an external dataset.

From Anaconda PowerShell Prompt, open this extracted folder and run the next
confirmatory experiment:

conda activate komorebi-full
powershell -NoProfile -ExecutionPolicy Bypass -File .\RUN_NEXT_OSL_TEST.ps1 -Device cuda

That one runner performs the dependency and package checks, one engineering
smoke test, a 2-data-seed by 3-model-seed confirmatory matrix, and aggregation.
Completed cells are preserved. Re-run the same command to skip completed cells.

The comparison keeps answer-only training untouched and contrasts two matched
same-volume calibration arms: one correct and one meaning-scrambled. All three
use a shared tokenizer, verified common initialization, eight fixed epochs, and
final checkpoints. Evaluation nonce words are disjoint from training nonce
words, so the test asks whether binding content transfers within a new episode
rather than whether extra text or a memorized alias explains the result.

All generated corpora, checkpoints, predictions, reports, and PowerShell
logs are written below the results folder. Existing completed results are not
overwritten unless you explicitly use -Force.

Read README.md for the experimental design, evidence ladder, controls, and
individual generation, training, evaluation, resume, and verification calls.
