# v0.1.0 standard-run findings that motivated v0.1.1

The completed v0.1.0 standard run used one dataset/model seed, 20,000 training records, and 2,000 records per reported split. Package, dataset, and checkpoint integrity passed.

The answer-only arm reached 0.6583 aggregate accuracy, 0.6415 on held-out pairs, 0.6015 on held-out triples, 0.5660 on lexical transfer, and 0.5010 on episodic renaming. The strongest frozen controls reached 0.6090 on held-out pairs, 0.6250 on held-out triples, 0.5055 on lexical transfer, and 0.5245 on renaming. Pooled pair/triple accuracy improved over TF-IDF by only 0.0045. The pair improvement was concentrated in the resources world rather than shared by all worlds.

Answer-only counterfactual change sensitivity was 0.4317, invariance specificity was 0.7907, pair-level completeness was 0.2991, and pair-level specificity was 0.4789. These results showed task learning and partial lexical robustness, not causal completeness.

State supervision greatly improved canonical composition but reduced lexical and renaming robustness. Combined supervision reduced renaming accuracy to 0.3705. Equivalence regularization stopped early and did not improve the main hard tests. This pattern motivated a direct test of the hypothesis that fixed global operator identities can improve canonical tasks while entangling representations with their names.

The v0.1.0 IID split was also used for early stopping and checkpoint selection. Therefore it was validation, not an independent test. Only one standard seed was run.

Version 0.1.1 addresses these issues by separating IID validation and test data, balancing evaluation cells, adding complete canonical/correct/scrambled renaming triplets, reserving disjoint nonce pools for training and evaluation, comparing matched correct- and scrambled-calibration training arms under a shared tokenizer and fixed budget, separating data and model seeds, and preregistering behavioral gates. No result from v0.1.0 is treated as evidence that a spontaneous internal symbolic language was established.
