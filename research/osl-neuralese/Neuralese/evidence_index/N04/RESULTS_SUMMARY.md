# Packet-closure results index — v0.4.0

The sealed official outcomes are generated under
`results/packet_closure_pilot/`. Read `REPORT.md` for the human-readable
result, `GATES.json` for registered adjudication, `RESULTS.json` for full
metrics, `CHECKPOINT_SEAL.json` for pre-evaluation checkpoint receipts, and
`EVAL_BANK.json` for the post-seal audit bank.

This root index deliberately does not prestate pilot outcomes. It is part of
the source sealed before the untouched pilot seeds are consumed.

Earlier evidence remains separate:

- `results/packet_closure_screen_dev/` contains the original eleven-arm
  learned-metric developmental screen.
- `results/packet_closure_screen/` contains the corrected four-arm seed-71
  implementation screen.
- `results/ambient_pilot/` contains the v0.3 frozen-checkpoint diagnosis that
  motivated this training block.

No developmental directory can satisfy an official v0.4 pilot gate.
