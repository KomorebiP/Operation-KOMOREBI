# OSL and Neuralese — manuscripts and LaTeX only

Research edition1.0, Komorebi P.

This compact bundle contains the18-page OSL paper,21-page Neuralese paper,8-page visual guide, their LaTeX/style/reference files, and the manuscript build wrapper. It does not contain the historical experiment archives or executable OSL runtime. Those are in the separate complete edition.

Build using `python build_manuscripts.py --output ../rebuilt_papers`. A TeX installation with latexmk, newpx, TikZ, tcolorbox and the packages listed in style.tex is required. No font binaries are supplied.

The new papers distinguish fresh finite checks from retained learned results, failures, and unspent experiments. No Lean proof or general learned language is claimed. Original component licensing is not replaced by this bundle.
