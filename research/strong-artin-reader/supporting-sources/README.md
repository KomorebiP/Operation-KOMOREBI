# Supporting mathematical sources

These files preserve distinct earlier mathematical source branches and their recorded evidence for strong-artin-reader. Current statements and proof boundaries remain those of the current publication. Historical projects keep their original assumptions and are not one combined build.

`ARCHIVAL_SOURCE_MAP.json` identifies each original archive revision, every retained source, and exact-content duplicates already available elsewhere in the collection. Older compiled manuscript PDFs, packaged runtimes, caches and superseded visual render bundles are omitted from this source supplement. Scientific editable manuscripts, code, formal sources, data, figures and existing license notices are retained where unique.
