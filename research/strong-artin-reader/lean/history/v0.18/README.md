## Main results

### 1. Finite cyclic H¹ quotient

For a finite cyclic group generated by `g`, a representation `A`, and zero norm operator,

```text
A.norm = 0,
```

Lean proves

```text
H¹(G,A) ≃ A / range(A(g) - 1).
```

The map sends a coefficient vector `x` to the cohomology class whose cyclic-generator value is `x`. Equality of two classes is exactly congruence modulo `range(A(g)-1)`.

### 2. Frobenius matrix quotient is actual finite cyclic H¹

If the cyclic generator acts on matrices by conjugation with `F`, then

```text
range(A(g) - 1) = frobeniusCoboundaries F.
```

Consequently,

```text
Matrix / frobeniusCoboundaries F ≃ H¹(G, Rep.of ρ).
```

This replaces the earlier purely algebraic quotient by a genuine group-cohomology object in the finite cyclic model.

### 3. Perfect cyclic H¹ trace pairing

Composing the preceding equivalence with the v0.17 perfect trace pairing gives

```text
frobeniusCentralizer F ≃ Dual k H¹(G, Rep.of ρ).
```

On a class represented by `X`, the value is exactly

```text
trace(P * X).
```

Every functional on cyclic `H¹` has a unique Frobenius-centralizing matrix representative.

### 4. Tame Taylor–Wiles relation space

At residue-field norm `q = 1`, v0.17 identifies the linearized tame relation space with the Frobenius centralizer. v0.18 therefore proves the exact capstone

```text
tameInertiaRelationSpace F 1 ≃ Dual k H¹(G, Rep.of ρ),
```

again with representative formula `trace(P * X)`. Every cyclic `H¹` functional has one unique tame-relation representative.

### 5. Tate normalization up to a unit

On a one-dimensional local quotient line, any two nonzero scalar functionals differ by one unique unit. Therefore, once an arithmetic comparison equivalence with the finite cyclic `H¹` model is supplied and the arithmetic Tate functional is known to be nonzero,

```text
Tate functional = unit × transported trace functional.
```

In particular,

```text
Tate(x) ≠ 0 ↔ trace(P * X) ≠ 0.
```

Thus the Taylor–Wiles detector does not require the exact sign or unit normalization of local Tate duality. Those conventions matter for an exact formula, but not for the one-prime nonvanishing interface used by v0.15.
