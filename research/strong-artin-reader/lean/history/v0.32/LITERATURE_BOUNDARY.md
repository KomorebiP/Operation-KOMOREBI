# Literature and library boundary

The proof uses standard geometric-sum identities, characteristic-p Frobenius
power identities, divisibility by X-lambda, and invertibility of a central unit
plus a commuting nilpotent. The source declarations used were checked in the
pinned Mathlib revision, and their file hashes are in LITERATURE_SOURCES.json.

Official documentation consulted on 2026-09-12:
- Mathlib.Algebra.CharP.Lemmas, including sub_pow_char_pow.
- Mathlib.RingTheory.Nilpotent.Basic, including isUnit_add_left_of_commute.

The online documentation can change; the formal evidence uses the pinned source
and cache, not an assumed API from the live documentation. No exhaustive novelty
survey was performed and no historical novelty is claimed. The new project work
is formal composition with the actual square-zero norm and mismatch criterion,
plus a fully constructed arbitrary dual-number matrix action and its controls.
