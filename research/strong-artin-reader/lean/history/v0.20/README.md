## Purpose

v0.19 proved an abstract nonlinear Hensel theorem under two arithmetic-facing hypotheses:

1. one approximate right inverse remains correct modulo `pi` throughout the residual fibre;
2. the nonlinear Taylor remainder of a depth-`n` correction lies one level deeper.

v0.20 proves both properties automatically for a broad finite-coordinate class.  Polynomial equations are represented by an intrinsic expression syntax generated by constants, coordinates, addition, negation, and multiplication.  A finite family of such expressions is a polynomial system.

## Main theorem

Let `q : R →+* k` be a surjective ring homomorphism to a field, and suppose

```text
RingHom.ker q = Ideal.span {pi}.
```

Let `system` be a polynomial system in finitely many coordinates over `R`.  If:

```text
pi is nilpotent,
the base point x₀ solves system modulo pi,
the residual Jacobian matrix mapped through q is surjective,
```

then Lean proves:

```text
∃ x, x - x₀ ∈ pi X ∧ evalSystem system x = 0.
```

The capstone is:

```text
Komorebi.StrongArtin.SurjectiveResidueHomPolynomialHensel.
  exists_exact_solution_of_surjective_residue_jacobian
```

Symbolically:

```text
surjective residual Jacobian
  -> residual matrix right inverse
  -> entrywise lift to the coefficient ring
  -> composite = identity + pi * error
  -> polynomial Jacobian stability on the residual fibre
  -> automatic Taylor-remainder gain
  -> v0.19 nonlinear Hensel iteration
  -> exact root over the nilpotent thickening.
```

## Polynomial Taylor theorem

For every scalar expression `e`, the directional derivative is defined recursively by the sum and product rules.  Lean proves:

```text
PowDivisible pi n delta
  -> PowDivisible pi (n+1)
       (eval e (x+delta) - eval e x - deriv e x delta)
```

for every `n >= 1`.

The product step uses the exact identity

```text
R(fg)
 = R(f) * g(x+delta)
 + f(x) * R(g)
 + Df(x,delta) * (g(x+delta)-g(x)).
```

The first two terms have depth `n+1`; the last has depth `2n`, hence at least `n+1`.

## Polynomial systems

A system is a family of scalar expressions.  The coordinatewise directional derivative is packaged as a genuine linear map.  The scalar Taylor theorem gives the variable-Jacobian remainder condition required by v0.19 automatically.

## Residual-fibre Jacobian stability

For polynomial expressions, Lean proves:

```text
x - y ∈ pi^n X
  -> D_x - D_y is entrywise pi^n-divisible.
```

Hence a matrix right inverse valid modulo `pi` at the base point remains an approximate right inverse at every point in its residual fibre.

## Lifting the residual right inverse

If a residual Jacobian over a field is surjective, Lean constructs a linear right inverse by choosing preimages of the standard basis and extending linearly.  It converts this to a matrix `Rbar` satisfying

```text
Jbar * Rbar = 1.
```

A surjective residue map lifts `Rbar` entrywise.  Because the residue-map kernel is `(pi)`, the lifted product satisfies

```text
J * R₀ - 1 is entrywise pi-divisible.
```

That error is converted to an endomorphism `E x` with

```text
D_x ∘ R₀ = id + pi • E x
```

throughout the residual fibre.

## Boundary

This checkpoint closes the nonlinear algebra for **finite coordinate polynomial presentations over a principal nilpotent thickening**.  It does not prove that the actual Strong Artin deformation/Hecke problem has already been placed in such a presentation, nor that its residual Jacobian is the augmented Jacobian produced by the earlier Taylor--Wiles pipeline.

Still required:

1. construct a patchable determinant-bearing residual finite-Satake automorphic complex;
2. identify the actual global deformation/Hecke equations and residual coordinate Jacobian;
3. prove the global Selmer--Jacobian comparison and identify arithmetic auxiliary variables with the checked columns;
4. complete the continuous local Galois cohomology and Tate-pairing comparison;
5. apply Chebotarev to the prepared finite conjugacy classes;
6. establish relative patching or a finite-depth carrier, twist equivariance, and ramified local attachment.

The capstone also does not cover an arbitrary non-Noetherian formal power-series system without a finite polynomial reduction.  At a fixed Artin level, such a reduction is expected in finite-coordinate settings, but that truncation theorem is not asserted here.
