## Not claimed

The matrix discovery program and Smith constructor are not Lean-verified programs.
The universal reduction from matrix certificates to exact quotients, and the
minimum FREE LINEAR coordinate count of that new adapter, have written proofs and
fixed-instance symbolic certificates, not new composed Lean endpoints.

A finite-state cardinality minimum is not a free linear-coordinate count. The
concrete exporter proves the former for its explicit tables. The large 2^128
source-state example has a symbolic matrix certificate, NOT a Lean all-state
instance generated by enumerating those states.

The quotient theory is generic but does not cover arbitrary multi-input contexts,
approximate models, stochastic semantics, or all cross-ring transports. The rank
lemma is generic arithmetic; identifying it with the Python loop's module length
is a written argument, not verified executable termination.

The exact base-change defect sequence is a written standard module argument.
The code is deterministic and no learned search policy or held-out performance
study was run. All proof interpretation review is self-review.
