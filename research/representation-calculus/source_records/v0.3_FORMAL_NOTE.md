## 1. Source semantics

A source has state vectors x in R^d, unary deterministic operations indexed by a
finite alphabet, matrices A_a, and observation rows O_j. EVERY source vector is
an admissible initial state. The construction is not the minimization of the
orbit of a single distinguished vector.

Words act left to right: a word [a,b] sends x to A_b A_a x. Empty words are included.
Write A_w for this product and define

    Beh(x)(w,j) = O_j A_w x.

The generic matrix identities work over any `Lean.Grind.Semiring`. Nothing in the
proof uses subtraction or cancellation. For noncommutative semirings this is the
explicit left-multiplication matrix action, not an unstated left-module linearity
claim. In all generated instances R is the standard modular ring `Fin (p^r)`.

The intended arithmetic profile, JSON source, and emitted Lean source must be
kept distinct. The kernel verifies the latter. It does not prove that a human's
original informal task was represented by the correct input matrices.

## 2. The finite certificate and its universal theorem

A certificate supplies an encoding P with t rows, target matrices C_a, observation
decoder D, actual observation words (w_l,j_l), and a coefficient matrix W. Define
G_l = O_(j_l) A_(w_l). The required exact identities are

    P A_a = C_a P,      O = D P,      P = W G.

The rows G are defined from their true word semantics in the generic certificate,
not assumed arbitrary tests carrying plausible-looking names.

### Theorem 1: all-state, all-word preservation [Lean]

For every x, w, and j,

    Beh_source(x)(w,j) = Beh_target(Px)(w,j).

Proof. The first matrix identity yields P(A_a x)=C_a(Px). Induction on w yields
P A_w x=C_w P x. Apply O=D P. The formal proof constructs the inherited `Transport`
from these matrix identities and applies its all-word theorem.

Endpoints: `matrixTransport`, `matrix_all_words`, `checked_matrix_all_words`.

### Theorem 2: exactness, not just sound compression [Lean]

For any source states x and y,

    Beh_source(x)=Beh_source(y)  iff  P x=P y.

If encodings agree, Theorem 1 implies all outputs agree. Conversely equal complete
behaviors imply Gx=Gy, since every row G_l is a real permitted future observation.
P=WG then implies Px=Py. This second implication is why word provenance is a
load-bearing part of the certificate.

Endpoint: `matrix_behavior_exact`.

### Theorem 3: the actual image is the exact quotient [Lean]

Define Y={y in R^t : exists x, Px=y}. The matrix equations prove that every C_a
preserves Y. The encoding onto Y is surjective and two encoded states are equal
exactly when their source behaviors agree. Distinct members of Y therefore have
some distinguishing future observation.

For ANY competing system U on a state type Z and encoding e:R^d->Z preserving
all future outputs, there is an injection Y->Z. Neither linearity nor a local
intertwining equation is demanded of that competitor.

Proof. Choose a source representative of each element of Y and send it through e.
If two such encoded representatives agree, their entire future behaviors agree.
The exact quotient property forces the original Y-elements equal.

Endpoints: `imageSystem`, `imageTransport`, `image_surjective`,
`image_encoding_exact`, `image_separated`, `image_minimal_semantic_encoding`.

The exact quotient is Y, not necessarily the whole free array R^t. In the zero-row
case, Y has one state even though t=0. Seventeen executed fixtures have t=0.

## 3. A small proof trace replaces long recomputation

Directly reducing a dense word-matrix expression can repeat the same computations
many times. Instead the exporter shares row calculations.

A base row is checked equal to one O_j. A later row f is checked equal to g A_a,
where g already has a proof that it represents observation j after word w. Then

    f x = g(A_a x) = O_j A_w A_a x

is exactly observation j after the PREPENDED word a::w. This direction matters
because state words are read left to right. Local row equations are kernel-checked
only over their finite coordinate indices. The all-vector conclusions are reused.

`valid_from_rows` proves that a family of such row proofs, together with the three
finite certificate identities, supplies the generic certificate's true semantic
provenance. Row extensionality is proved by evaluation on finite unit vectors.

Endpoints: `observed_row_base`, `observed_row_prepend`, `valid_from_rows`.

This does not assert constant proof cost, an optimized compiler theorem, or a
measured advantage against another proof representation. It provides a compact,
reusable proof DAG whose nodes describe coordinate calculations, not source states.
The executed 202-fixture suite has 643 such nodes.

## 4. Necessity of discovered tests is now a formal statement

For each accepted test row f_i, the discoverer retained a difference delta_i with

    f_j delta_i=0 for j<i,        f_i delta_i !=0.

The exporter kernel-checks these equations and each f_i's actual-word proof. The
new generic theorem concludes that delta_i and 0 agree under all earlier tests
but are NOT observationally equivalent under the complete source profile.

Endpoint: `witnessed_growth_excludes_merge`.

Thus a growth witness is evidence against the PREVIOUS representation. It is not
a claim that each accepted row remains a final independent generator or that the
search's order is optimal. Linear combinations and subsequent Smith elimination
can reorganize the accepted rows. All 643 executed growth witnesses have this
Lean interpretation, not merely a Python Boolean result.

## 5. Smith data describes actual images [Lean]

Suppose t<=d and the certificate supplies weights w_i, a square matrix V and its
inverse with

    V V_inv=I,    V_inv V=I,    P V=[diag(w_i) 0].

Then for every y in R^t,

    (exists x, P x=y)  iff  (for every i, exists a_i, w_i a_i=y_i).

Proof. For a given x, express x=V(V_inv x); its encoded image has exactly the
required multiples. Conversely choose a_i for each coordinate, extend that vector
by zeros to d coordinates, and apply V. Its P-image is y. The constructions do
not divide by nonunits. They also work for zero weights.

`smith_image_iff` and explicit inverse maps identify the actual encoded image with
this principal-multiple subtype. Over the concrete commutative residue rings these
are precisely products of principal ideals. The equality is not based on rank
modulo p; all nonzero torsion coordinates survive.

Endpoints: `smith_image_iff`, `imageToPrincipal`, `principalToImage`,
`smith_image_roundtrip`, `smith_principal_roundtrip`, `checked_smith_image`.

The generic theorem does NOT prove that a supplied arbitrary list of weights is
a sorted invariant-factor list, nor count its image numerically. Generated weights
are the unchanged p-powers supplied by independently checked Smith certificates.
Actual invertibility and the diagonal identity are separately checked in Lean.

## 6. The large instance: a compact proof, not enumeration

Use the frozen synthetic eight-coordinate source over R=Z/65536Z. Its complete
initial-state set has 2^128 elements. The unchanged discoverer receives its action
matrices and observations, not the invertible coordinate change used to construct
the fixture. It accepted two tests and examined five candidates in the previous
release. Re-execution here returns exactly the same certificate.

The encoding has two rows with Smith weights 1 and 4. The generic formal theorem
therefore identifies its actual image with R x 4R. In addition, this release
constructs an explicit bijection

    Fin (2^30)  <->  EncodedImage(P).

For 0<=q<2^30, map

    q -> (q mod 65536, 4*floor(q/65536)).

The inverse is

    (y0,y1) -> y0+65536*floor(y1/4).

The Smith-image theorem supplies y1 mod 4=0, and the Fin bounds prove the maps are
mutual inverses. Lean's arithmetic reasoning proves these identities universally;
no list containing 2^30 elements is generated.

Endpoints: `exactImageCode`, `decode_codeImage`, `code_decodeImage`.

### Exact state and coordinate minima for this instance [Lean]

The generic injection theorem and a proved finite pigeonhole lemma force every
finite competing exact all-state encoding to have at least 2^30 states. The actual
image attains that count.

A state array with zero or one residue coordinate has at most 65536 possible
values. Such an array cannot encode 2^30 distinguishable behaviors, even if its
transitions and encoding are nonlinear. The certified two-coordinate machine
exists, so the minimum number of full residue coordinates is exactly TWO.

Endpoints: `every_finite_competitor_needs_2pow30`, `no_one_scalar_competitor`,
`minimum_two_scalar_coordinates`.

The two coordinate array has 2^32 ambient states but only 2^30 are admissible image
states. A compact code therefore uses 30 bits rather than storing two unrestricted
16-bit residues. This is a model-relative exact encoding statement, not a general
space-complexity lower bound for computing a single scalar answer.

## 7. The remaining generic minimum theorem [written, not ported]

For general prime-power certificates with t nonzero cyclic factors, the minimum
FREE LINEAR coordinate count is t, using the chain-ring generator argument from
v0.2. The actual-image theorem now supplies the formal quotient and factorization,
but this Std-only branch has not yet assembled the general residue-submodule
generator bound and its lower-bound application to arbitrary matrix certificates.

The injection of the exact image into every competitor IS formal for all
certificates. That is a state-space statement. Simply comparing cardinalities
usually gives a weaker free-coordinate bound and cannot replace the missing
chain-ring argument. For example, two nonzero order-two factors modulo 16 require
two linear generators while their four states fit into the set of one residue
coordinate. The large fixture happens to admit a sharp cardinality lower bound.
Do not generalize its specialized proof by analogy.

## 8. Executable, input, and evidence boundary

`tools/export_symbolic_lean.py` first invokes the unchanged independent matrix
checker with the separately supplied intended source. It then emits literal
matrices, word-provenance rows, growth witnesses, Smith data and proof terms.
Kernel evaluation uses ordinary `decide`, not native_decide or a trusted success
flag. State values remain arbitrary variables in the conclusions.

The exporter, JSON parser, discoverer and Smith routines are NOT verified
executable programs. An independent Python pass reparses literal matrices from
the emitted source and compares them to the external source/certificate JSON.
That audits transcription but is not a proof that a human's mathematical problem
was encoded correctly. Changing a source hash is not sufficient to authorize a
changed source: the actual equations must hold again.

The 202 inherited synthetic instances include zero observations, nonzero torsion,
delayed observations and hidden-coordinate fixtures. They are regression inputs,
not independently held-out new scientific families. The source/certificate pairs
are not modified. Each generated file has a real kernel-checked all-state,
all-word theorem; the finite source rings do not introduce a word-horizon cutoff.

## 9. Next obligation

The immediate missing formal statement is the generic sharp free-linear dimension
theorem for every accepted prime-power matrix certificate. It should reuse an
explicit chain-ring module-generator lower bound, not a cardinality shortcut.
After that, a separately frozen structurally held-out task can test representation
proposal quality against matched baselines. No trained proposer, performance
comparison, stochastic/multi-input generalization, or novelty verdict is supplied
here. These are distinct obligations, not consequences of compilation success.
