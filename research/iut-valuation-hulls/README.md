# Komorebi × IUT — Valuation Hulls and Reconstruction, B05

This is a self-contained Lean source continuation of the Hodge Reduct B04
formalization (the four original IUT PDFs are not redistributed). It proves
local valuation saturation, optimal ideal enlargement costs, a stronger F17
addition-reconstruction obstruction, and a discrete quantitative witness
criterion. It does **not** prove or disprove IUT III Corollary 3.12 or abc.

## Start here

1. `RESEARCH_NOTE_B05.md` — mathematical statements, proofs, explicit model limits.

## Reproduce

From `formalization/lean`, with the appropriate pinned toolchain:

```bash
lake build -KwarningAsError=true
```

For a full independent check of each Lean source and deliberate negative controls:

```bash
LEAN_BIN=/absolute/path/to/lean LAKE_BIN=/absolute/path/to/lake \
    python verification/verify_b05.py
```

Run the last command from the package root. On Windows, replace the Unix-style
environment assignment syntax as appropriate for PowerShell. The verifier
records a warning-as-error compilation of every source, a preserved-source
audit, interface checks, and rejection of three intentionally false claims.

## Additional outputs

The reproducible plot is generated by `figures/make_b05_figure.py` and saved
in PNG and SVG formats. It illustrates only the toy ideal and valuation model.
