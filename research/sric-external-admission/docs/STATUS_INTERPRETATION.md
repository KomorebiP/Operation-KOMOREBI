# Status Interpretation

The status hierarchy is lexicographic. A later status is not considered when an earlier prerequisite fails.

`CONTENT_SPECIFIC` in this package means that a same-answer trace from a different proof instance is not functionally interchangeable with the recipient trace while a semantic-preserving premise-order twin is approximately interchangeable.

It does not establish a distinct reasoning algorithm. `PROCEDURE_SPECIFIC` is reserved for a follow-up with varied proof structures and a structure-far versus structure-near contrast.

`CAUSALLY_VALIDATED` is the maximum package status. It means that a sealed low-rank quotient passed observable construction gates, an audit-only post-seal witness, and controlled subspace patching. It does not mean complete, unique, or verbalized access to hidden thought.
