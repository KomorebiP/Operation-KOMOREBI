# AVOC v0.28.0 — targeted gap update

No earlier established scope is reset. v0.27 root documents are retained in history/v0.27.0_release_top.

## Richer exact semantic domain

CLOSED FOR DIMENSION-TYPED AFFINE PROGRAMS OVER RINGS.

Signature equality is a complete all-input test; zero plus basis probes suffice. Normalization composes typed maps and pointwise sums. One-hole contextual replacement is semantically sound and additive-cost monotone. The executed interface instantiates GF(5). It is no longer necessary to enumerate every input vector to certify this domain's equivalence.

## Typed weighted cost certificates

LOWER-BOUND AND ATTAINING-WITNESS THEOREMS CLOSED; NONTRIVIAL GLOBAL AFFINE OPTIMIZER OPEN.

The certificate induction generalizes beyond the fixed Boolean grammar to dimension-indexed composition, sum and weighted primitives. It is not a delivered all-affine optimality table. A global minimum-factorization algorithm or finite certificate framework for a fixed richer grammar remains to be built.

## G20: canonical semantics versus evaluation economics

A COMPILE-ONCE FUSION COMPARISON AND COUNTEREXAMPLE ARE PROVED.

A dense normal form may be more expensive than a low-dimensional factorization. The guard preserves a cheaper original, and the lifecycle check charges coefficient construction. No global factorization optimizer, cost-optimal search, full physical-cost model or profitability claim for every normalization is supplied.

## G27: recursive improvement

NO NEW AUTONOMOUS IMPROVER OR LIVE PROMOTION CLAIM.

This provides a second certifiable implementation domain. The earlier Bool3 feedback and cost-optimal library stay available, but are not automatically applied to the affine grammar. The current CLI is a read-only checker/normalizer, not a campaign that discovers and persists new factorizations.

## Next useful objective

Use the complete affine signature as the protected equivalence key for a restricted, dimension-aware factorization search. Retain factored execution plans and compare compile-plus-deployment costs instead of indiscriminately densifying. Start with a fixed primitive catalogue and bounded intermediate dimensions so coverage and cost claims can be stated honestly. A symbolic cost lower certificate for that catalogue would then connect to the new typed induction theorem.

Alternative operational work remains distinct: authenticated arbitrary-Lean artifacts, measured workloads, dynamic proof graphs and a unified physical-cost research workflow.
