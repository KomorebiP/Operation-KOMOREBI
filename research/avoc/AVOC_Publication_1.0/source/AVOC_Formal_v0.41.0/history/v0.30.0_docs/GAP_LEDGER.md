# AVOC v0.30.0 — targeted gap update

## Reusable affine certificates
CLOSED FOR CHECKED LINEAR-KEY REUSE AND A FIRST PROTECTED SNAPSHOT ADAPTER.

A previously valid minimum-width certificate can now be imported after revalidation and reused for any new bias with the same linear coefficients. New source programs are compared afresh, so free identities and useful original factorizations are not discarded. All valid width certificates for the same linear map yield the same factor tariff.

Remaining: general protected multi-task library governance, authenticated provenance and paid/cost-optimal memory management. The new adapter is not a formal filesystem refinement or a generalized recovery protocol.

## G20: pre-search economics
ONE-SIDED OPPORTUNITY EXCLUSION CLOSED FOR THE DECLARED AFFINE MENU.

A cheap zero/nonzero test gives a valid width lower bound without factor generation. Maximum possible deployment savings are compared against mandatory remaining generation/revalidation tariffs. Cold/warm denial has a theorem; passing preflight does not ensure profit. Sunk preflight is retained and a negative-net counterexample passes the optimistic gate as expected.

The controller does not optimally choose among all possible probes, sparse representations or future cross-task investments. Tariffs are not measured physical costs, and no complete net-optimal metareasoning result is claimed.

## G27 and empirical effectiveness
UNCHANGED. Generated reusable mathematical evidence now avoids repeated factor generation in fresh processes; that is a concrete memory mechanism, not an autonomous multi-generation discovery benchmark or production LLM calibration.
