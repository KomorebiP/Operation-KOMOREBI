# AVOC v0.25.0 — development failures and repairs

No unresolved failed theorem is presented as checked. This record separates development
errors, environment interruptions and final evidence.

1. An attempted interactive container execution was unsupported by the host. Ordinary
   bounded commands were used instead. The failed execution was not a successful run.
2. Portable-runtime assembly passed all compressed-part checks, but the outer call
   interrupted extraction. The completed compressed archive was retained and completely
   re-extracted. No claim of independently comparing every extracted runtime byte follows.
3. First grammar-length arithmetic needed explicit multiplication association. Initial
   node-bound and grammar-completeness inductions retained dependent variables in the
   wrong place. Generalizing them, clearing a dependent hypothesis and escaping the
   `variable` constructor repaired those scripts.
4. A Bool-conjunction helper name was unavailable in the pinned API. A direct simplification
   proof replaced it. A deprecated if_pos use failed warnings-as-errors and was removed.
5. The first durable replay proof did not simplify let-bound authority aliases through
   dependent fields. Explicit typed equalities tied begin/finish to the exact authority.
6. An entrypoint attempted to compare Except results with an unavailable Boolean equality
   instance. Pattern matching replaced the comparison.
7. Exact campaign examples initially failed kernel reduction because the authority's
   objective used reprStr(reference), a formatting operation not suitable for that proof.
   A fixed literal metric name replaced it. The semantic reference and declared calls
   remain fixed in the Authority and protected runtime job, so the semantic contract is
   not reduced to that string. The final concrete campaign equalities now use ordinary
   kernel-checked decide; no native-evaluation axiom was introduced.
8. During one development shell chain a parent module failed while later commands could
   see older development outputs. Those commands were not final verification evidence.
   The local release rebuild, descendant invalidation and final direct-import hash checks
   ensure every delivered proof record is for the final source/import closure.
9. Build/test execution was bounded to the available host. Interrupted or setup-dependent
   development commands were rerun. The collector requires successful current per-target
   records, substantive negative diagnostics and final-source test provenance.

The final source census, 136 targets, 1,310 axiom reports, 63 negatives, 747 campaign
comparisons and 16 live cases all passed. The demonstration remains a bounded symbolic
proposer, not autonomous recursive improvement or full physical-cost optimization.
