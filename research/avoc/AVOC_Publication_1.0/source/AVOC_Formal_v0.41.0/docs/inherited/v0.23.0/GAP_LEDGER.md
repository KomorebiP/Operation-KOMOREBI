# AVOC v0.23.0 — targeted gap update

Previously closed v0.22 and earlier objectives retain their exact boundaries.
This block follows the recursive-improvement proposal in the consolidated bundle.
It does not relabel unrelated gaps as solved.

## G25. Protected component promotion
CLOSED FOR FIXED AUTHORITIES WITH SOUND CONTRACT/UTILITY EVIDENCE.
The gate, finite/adaptive invariants, source-version/core/objective requests,
all-trial accounting and strict utility improvement are proved. The executable
uses an immutable three-version catalogue and executes its selected component.

## G26. Demonstrated component optimization
ONE CHECKED SPECIALIZATION DELIVERED.
The existing retry action can be computed without dynamic lookahead under the
already-proved NoRevival condition. A fixed workload goes from 70 to 7 state visits.
No new universal search algorithm or physical speedup measurement is claimed.

## G27. Recursive improvement of the improver
OPEN. No LLM generated this candidate inside the runtime, and no experiment feeds
an accepted version back to produce better subsequent candidates. Candidate design,
proof, evaluation and promotion need to be automated and compared with a frozen
improver under matched total resource budgets before claiming recursive gains.

## G20. Costed cognition and improvement search
ADVANCED, NOT CLOSED. All funded trial/switch tariffs are retained. A model can
certify net gain only when its utility/evidence/cost obligations justify it. The
new checker does not cost its own actual planning, proof checking or evaluation.

## G18. General proof-artifact backend
UNCHANGED. Fixed compiled strategies are not arbitrary source certificates.
Arbitrary Lean/mathlib backend, live dependency-bearing tasks, parser semantics,
full provenance and exact integration with the protected deployment store remain.

## G16. Live execution and recovery
UNCHANGED. The new campaign evaluator is read-only. It does not replace, migrate,
or weaken the existing store, receipt gate, retry authorization or crash protocol.
A future deployed upgrade protocol must bind the frozen authority and campaign
ledger to the actual artifact store and reconcile failed deployment attempts.

## G21. Real-system identification
OPEN. The experiment is exact symbolic computation. Utility bounds for real
workloads, meaningful physical costs, leakage-resistant adaptive evaluation, and
measured research-productivity gains are not supplied by this block.
