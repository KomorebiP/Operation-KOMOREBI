# Decision rule after Pilot 0.1

```text
ADAPTER_INVALID
  → repair adapter only; do not reinterpret model

LATENT_UNUSED
  → preserve underutilization result; test another task or checkpoint

LATENT_UNORDERED / LATENT_MAGNITUDE_ONLY
  → add stronger temporal and covariance controls

SURFACE_UNSTABLE
  → compile context-indexed charts before semantic naming

LATENT_GENERIC
  → study generic answer preparation; do not claim proof semantics

PROCEDURE_SPECIFIC
  → begin Block 23 / Pilot 0.2 with endogenous semantic-witness discovery
```

The next stage is determined by the result status, not by a fixed expectation of success.
