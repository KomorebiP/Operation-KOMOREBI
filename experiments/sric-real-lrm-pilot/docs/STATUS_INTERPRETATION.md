# Status Interpretation

| Status | Interpretation | Next action |
|---|---|---|
| `ADAPTER_INVALID` | Captured trace does not replay the ordinary computation. | Repair adapter; make no model claim. |
| `LATENT_UNUSED` | Removing the trace has insufficient effect. | Change task/model or study latent underutilization. |
| `LATENT_UNORDERED` | Trace helps, but recurrent order is not established. | Test generic conditioning and stronger temporal controls. |
| `LATENT_MAGNITUDE_ONLY` | Structured content is not separated from activation magnitude. | Add covariance controls and packet interventions. |
| `SURFACE_UNSTABLE` | Declared semantic twins do not share a compatible trace. | Build context-indexed charts or narrow the claim. |
| `LATENT_GENERIC` | Useful ordered computation is largely interchangeable across same-answer problems. | Diagnose generic answer preparation. |
| `PROCEDURE_SPECIFIC` | Same-answer far-proof transplantation is harmful while the declared twin is stable. | Proceed to endogenous semantic discovery. |

None of these statuses means that a word-for-word hidden monologue has been recovered.
