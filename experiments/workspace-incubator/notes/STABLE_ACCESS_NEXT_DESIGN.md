# Next target: access that preserves its own future usability

Unexecuted design after v0.6. The main and calibrated results remain unchanged.

Compare matched additional training on single/few-step recall against training
on full relevance-switching trajectories. Retain two parent lineages, the same
phase-local architecture, fixed native working dynamics, unchanged eight-value
message channels, and matched forward calls/episode presentations.

For each stored world, expose sequences of ordinary and stressed working programs,
then multiple factual cues and short working continuations. Train only terminal
answers and private recall. Hold out longer retrieval depths and distinct cue
transition generators. Do not enforce hidden coordinates or a literal raw-state
fixed point. Preserve all adverse effects on clean inputs.

Require current accuracy, later all-fact recall, private invariance, legal working
reuse, return consistency, and stable repeated access on the SAME saved state
trajectory. A four-branch reset audit alone is insufficient for that trajectory
claim. Include both reset branches and sequential no-reset comparison.

The objective is observable memory-preserving access, not a new external readout.
An exact engineered read-only interface can serve as an assay control, but cannot
be counted as an emergent protected memory partition. A frozen network's retained
information and a learned retrieval process remain distinct proof obligations.

Even a successful trajectory-level repair would need a new native localization,
reciprocal writing, no-communication and partner-transfer audit before any
stronger J-space promotion. None is presumed from one-shot retrieval accuracy.
