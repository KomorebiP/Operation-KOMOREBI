What is controlled?

All branches use the same weights, cues, operations and late consumers. The edit is applied once. Work runs continuously without extra monitoring ticks. At each checkpoint, the usual silent delay, output reads and factual audits run on copies. After the final working step, reloads update the real test state in sequence. A factual reload intentionally resets the desired content to the remembered world.

Reference errors are displayed, not excluded from the record. A valid donor history is not evidence that the projected hybrid is native. A donor prepared from a captured live snapshot inherits that snapshot’s provenance limitation. Natural support, generalization and consciousness are not certified.
