## Five counterfactual branches

1. **Original:** no hidden edit.
2. **One-agent edit:** write the selected component to the writer only.
3. **Original first packet restored:** same writer edit, but its first outgoing
   packet is replaced with the original branch's packet.
4. **Edited first packet only:** neither agent is initially edited. At the first
   exchange, the writer's outgoing packet is replaced by the edited branch's packet.
5. **Whole donor reference:** both states follow the actual donor program. This is
   a broader competence reference, not localized-state evidence.

Both messages are computed simultaneously before either receiver updates. Only
one outgoing packet at the FIRST exchange is changed in the restoration/replay
controls. Afterward all branches use their own evolving learned messages. An
initial effect can disappear; a first-packet restoration can stop blocking it.
Those later outcomes remain visible.

Native-work mode executes the original operation-conditioned local update followed
by exactly the model's ordinary message exchanges. The separate bare-exchange mode
omits local work and is explicitly a diagnostic schedule. It is not part of the
main native-work assay. Silent readout steps run on copies at each checkpoint.
No query, answer, or world-truth array participates in the neural transition.
Monitoring and final memory audits do not alter the running trajectory.

## What first-packet rescue and replay actually prove

Write the recipient update as F(h_R, m_W). Immediately before the first exchange,
the original, edited and replay branches have identical recipient states. Local
working updates are independent across agents. Restoring the original message
therefore makes the restored recipient update exactly equal to the original.
Replaying the edited message makes it exactly equal to the edited recipient.

These equalities follow from deterministic input matching and the architecture's
message-only cross-agent interface. Their exact reproduction validates the
implementation and identifies the causal path. They are NOT independent evidence
of workspace emergence. Whether the changed message produces the intended semantic
answer, whether it persists, and whether it preserves other functions remain
empirical questions.

The message table is not a semantic legend: eight message coordinates are not
identified as eight named facts. Softmax values in the plot are class probabilities,
not independently calibrated confidence estimates.

In B, Agent 1 → Agent 2, nine of the 31 first-exchange successes disappear by the

Random and complement edits produce the intended recipient donor pair in **0/32**

establish uniquely privileged J geometry: same-rank alternatives worked in earlier

All 32 first-packet restoration controls in each J cell return the factual
recipient answer. Replays exactly reproduce the recipient's edited effect,
including failures. At the first exchange the two state-equality errors are zero
in every trace, as expected from the interface construction.

At final J-edited states, all eight facts are recalled by both agents in 32/32
cases for A 1→2 and both B directions. For A 2→1 the per-agent totals are 31/32
and 31/32. All tested final private labels are preserved. These four-branch memory

## Interface behavior

The run freezes context and settings. Changing the source while it is running
cancels the stale computation. The earlier preview and committed session are
unchanged. The user can inspect before-send, after-local-work and after-receive
checkpoints, change the late consumer without recomputation, inspect actual message
values, and export raw states, packets, outputs, input metadata and hashes.

The optional fixed-setting bank uses 8,16 or32 histories in the currently chosen
lineage and tests both writers on each identical history. It does not optimize
strength per case. All completed cases are inspectable. A cancelled attempt is
retained as an incomplete partial case and excluded from completed-case counts.
The app does not import external prediction fields into its neural outputs.
