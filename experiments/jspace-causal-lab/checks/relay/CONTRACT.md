# Relay assay 1.4: first-packet causal path

Scope: frozen weights and fixed frames inherited unchanged from editor 1.3.
No training or candidate selection. A development smoke used seed 271414 index 0.
The recorded assay uses a different bank seed 271449 with indices 0..31.

Two model lineages A/B, calibrated retrieval for final memory checks, two writer
positions, methods J / random / complement / native, alpha 1, offsets zero.
32 input histories reused across lineage, writer and method. 512 trajectories,
not 512 independent input histories. Each trajectory receives native work ISLR
(eight-bit factual worlds, pre-existing 0/3/6-operation prefixes and equal-duration
two-operation preparation). Both op aliases can occur during initialization and
prefix; the four continuation operations use alias zero. Work send/receive
scheduling is inherited without added exchanges. All four later consumers are read
on copies through the standard silent delay; they cannot change the trajectory.

Five branches: original, unilateral initial edit, unilateral edit with first
writer packet restored from original, original with first edited writer packet
replayed, whole donor. Only the first writer message is intervened upon; afterward
all branches proceed freely. No zero-message condition is substituted for restoring
matched original content. Report both recipient and writer, first and last exchange,
all reference failures, and final factual/private recall. A same-value comparison
is an engineering control in tests, not part of the nonzero-target main bank.

At the first exchange the untouched recipient states agree. With matched incoming
messages, identical recipient transitions are therefore expected by construction.
Exact rescue/replay equalities validate implementation/path specificity, not an
independent emergence hypothesis. Whether those messages induce the desired
counterfactual answer, whether the effect lasts, and whether it preserves facts
are empirical and not guaranteed. Do not hide reference failures or use an
undefined eligible ratio as 1. Native means whole donor reference has an actual
program history; a one-agent donor transplant is not a native paired-state claim.

Bare exchange sequences are a separate UI diagnostic outside the regular work
schedule and are not included in this bounded native-work assay. No proof of
Jacobians' uniqueness, reliable reciprocity, natural-localization, autonomous
writing, pretrained-language-model J-space or chat-model intervention follows.
