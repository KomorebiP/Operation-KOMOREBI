What is running

This page contains the original float32 weights from two v0.5 parents and their v0.6 main and calibrated access repairs. It performs recurrent inference locally in JavaScript. There is no remote API, training loop, or hidden rule-based substitute for neural predictions.

The two parent networks inside a dyad have separate weights and only communicate through eight-value messages. The repaired versions share the byte-identical frozen base weights with their parents; only the access-phase modules differ. Lineages A and B are different training histories, not the two agents inside a single dyad.

What the exact reference does

An independent two-bit interpreter applies I, L, R, and S to calculate the intended working answer. It also keeps the original eight factual bits for scoring. Neither the reference working value nor stored world array is passed to neural readout or retrieval.

Scope of the live episode

Eight set events initialize the world in seed-dependent order with seed-dependent aliases. The seed also fixes the private labels. The interactive generator is not the published evaluation bank and makes no population-level performance claim. A custom or long sequence can expose genuine model errors.

Validation & boundaries

The port was compared against the original PyTorch routines on 72 model/episode combinations, including long programs, successive cues, and message cuts.

JavaScript dot products use double-precision accumulation and float32 tensor outputs. Minor numerical differences remain; this is not bit-exact inference on every browser or all possible inputs.

Projected-state naturalness, no-wire competence, unilateral workspace writing, and unknown-partner transfer remain unresolved in the source work. This lab does not certify J-space, consciousness, or subjective states.

Controls that change state

Running or stepping a program, retrieving a cue, cycling cues, and manual working operations update the live state. The four-branch memory audit does not. Reading a different late query never updates state. Cutting the wire affects only future retrieval exchanges.
