# J-space causal output editor: implemented and tested

**Komorebi P. — September 27, 2026**

**Disposition:** A working browser interface for actual upstream activation interventions on frozen small neural models. Sampled causal output effects verified. No new training, certified natural-space localization or language-model J-space claim.

## User-facing advance

The previous interactive lab displayed raw activations and ran native operations but did not expose candidate-state editing. This successor adds a direct editable three-dimensional candidate in each 64-dimensional agent state. It changes activations before silent recurrence, any selected continuation and the learned output head. The evaluator cannot overwrite predictions.

In the predetermined default case, both network answers are [0,1] before the edit and [1,1] after the bilateral J edit. Both agents recover all eight original facts in the default four-branch memory audit. A subsequent native swap uses the edited content. This single demonstration is not substituted for the sampled evaluation below.

The interface exposes target-conditioned donor replacement, continuous strength, three manual local-coordinate offsets, all four late consumers, common working continuations, independent factual-memory checks and raw-trial JSON export. The old live workbench and historical evidence explorer are retained.

## Construction

The underlying float32 weights are unchanged from the prior browser package, SHA-256 `5a3e9e80c8d7173295db73b058bc11bdc223533abf79041631f2f2546e58626b`. Both source lineages are previously competence-selected dyads. The original observation, work, silent and answer modules are shared byte-for-byte by each lineage's parent and repaired variants. The copied access modules differ only for later retrieval.

For each lineage, 768 calibration contexts use eight binary factual inputs, a random ordered cue, and prefixes of length 0,3 or6. Four two-operation alternatives follow. Each agent's exact-report gradients are averaged through the frozen silent delay. Four centered report rows yield a three-row SVD frame. This is output-informed, and the rank bound follows from four centered classes. It is not evidence of an independently discovered three-dimensional language.

A fixed interaction-covariance frame, same-rank PCA and seeded random frames accompany it. Frames were saved and hashed before the independent evaluation bank was generated. This is a bounded development/instrumentation check, not an original RRCT primary or an independently replicated study.

## Sampled effects

The assay used 256 fresh procedural histories per lineage, with each of the two agents scored. Donors change one or two temporary bits using legal equal-duration operations while preserving the input world and private labels. Reports are taken either after silent delay alone or after a shared native swap and silent delay. The query is absent during state formation and editing.

The same bilateral J candidate also gives 100% exact donor-pair answers after the common swap. All measured contrast-bearing late-consumer cases follow the donor under the J edit. Noncontrast cases, such as parity after a two-bit change, are counted separately in the raw report and are not presented as output changes. A one-agent edit gives approximately 50% aggregate immediate donor consistency because the untouched partner retains its factual answer before any further communicating operation. It does not establish bidirectional propagated writing.

The different-program same-value J sham preserves the factual pair in the immediate assay. It is not the same donor used for wrong-value interventions.

Current private-label outputs remain correct in these banks. All-eight recall uses four independent branches from the same post-edit state, not a sequential recall success claim. Lower recall does not prove that every missed fact was erased; previous studies exposed the distinction between retained information and native access.

## Scope of causality and J terminology

The edited coordinates affect output causally in the literal experimental sense: the inputs and weights remain fixed while an intermediate state component is replaced, and subsequent unchanged computation produces a different result. This is more than displaying or decoding the activation.

It is not a certificate that the replacement lies on the model's native state family. No new support discriminator or natural-geometry gate was passed in this block. Artificial projection failures reported earlier remain unresolved. Whole native state replacement is labeled separately. At strengths other than zero or one, a whole-state blend would not have a native witness; the UI prevents that operation from being mislabeled native.

Same-rank PCA and interaction candidates also control output. The experiment therefore does not establish uniquely privileged Jacobian geometry. The app is a four-class GRU task, not a vocabulary-linked pretrained-language-model assay and not access to the chat assistant's private neural activations.

## Engineering verification

The inherited engine reproduced all 4,608 saved reference decisions. The new causal API reproduced 1,344 PyTorch decisions across 168 reference paths with reused input histories in Node and Chromium. Maximum sampled final-state difference was 2.414e-6; maximum logit difference was 1.240e-5. The two implementations are not bit-identical.

Contract checks verify zero-strength identity, exact whole-donor endpoints, unedited-agent preservation, forbidden native interpolation, invalid inputs, nonmutating memory audits and candidate/complement decomposition. UI checks exercise late-query nonmutation, defaults, target edits, manual axes, controls, native continuation, lineage/variant changes, live-state capture, JSON export, historical tabs and 390-pixel mobile layout. There were no page errors or external requests in the tested sessions.

An independent scalar/NumPy audit reconstructs inputs, working values, donor targets and 680 reported metric entries from 266,240 recorded prediction entries. Those entries reuse the same histories across methods, agents, consumers and continuations; they are not independent experiments.

No training was executed or claimed. The rebuilt HTML and source package retain the original weights, fixed analysis frames, raw result arrays, independent reference generation, original model definitions and verification code.
