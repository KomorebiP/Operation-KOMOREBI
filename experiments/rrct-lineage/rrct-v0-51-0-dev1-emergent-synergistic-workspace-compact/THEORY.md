# Recursive Resolution Closure Theory

## Status of the proposal

Recursive Resolution Closure Theory, abbreviated RRCT, is a testable architectural hypothesis. It proposes that a candidate functional core for machine awareness would require a persistent, integrated loop in which a system's resolved model of itself helps determine its own future information selection, memory, prediction, and behavior.

The prototype tests the causal and functional part of that proposal. It does not test whether subjective experience is present. No output of the current software should be reported as a consciousness score, a sentience probability, or evidence of an inner point of view.

## Central hypothesis

The central hypothesis is:

\[
\boxed{
\text{A resolved self-model becomes globally and temporally causally effective within a closed recurrent loop.}
}
\]

This is stronger than storing a representation called `self`. The self-model must change which information is resolved, retained, broadcast, and used later. Its causal contribution must remain detectable under intervention after visible task performance and computational budget are controlled.

## State and dynamics

Let the complete implemented state at time \(t\) be

\[
X_t=(z_t,q_t,w_t,s_t,m_t,e_t),
\]

where:

- \(z_t\) is the local specialist state
- \(q_t\) is the current multiresolution representation
- \(w_t\) is the recurrent workspace
- \(s_t\) is the compact self-model
- \(m_t\) is bounded episodic memory
- \(e_t\) is prediction error and confidence-related state

Given observation \(u_t\), the system evolves through

\[
\begin{aligned}
q_t &= P_{\rho_t}u_t,\\
z_{t+1} &= F_z(z_t,q_t,Bw_t),\\
w_{t+1} &= F_w(w_t,z_{t+1},s_t,m_t),\\
s_{t+1} &= F_s(s_t,w_{t+1},m_t,e_t),\\
m_{t+1} &= F_m(m_t,w_{t+1},s_{t+1}),\\
(\rho_{t+1},a_t) &= \pi(w_{t+1},s_{t+1},m_{t+1},e_t).
\end{aligned}
\]

Here \(B\) is the workspace broadcast map and \(\rho_t\) selects the active resolution. The essential closure is that \(s_t\) and \(w_t\) affect \(\rho_{t+1}\), memory formation, and action, while the consequences of those choices update the future self-model.

## Balanced causal initialization

Version 0.2 initializes learned linear maps with a balanced semi-orthogonal construction. For a map with shape \(m\times n\) and declared gain \(g\), the \(\min(m,n)\) nonzero singular values are all initialized to \(g\). This construction is used for the specialist, workspace, self-model, controller, and explicit closure maps that previously used normalized random matrices. The structured workspace skip remains an identity map plus a small balanced perturbation.

The purpose is experimental control. A randomly ill-conditioned map can suppress some directions and exaggerate others before any causal mechanism is tested. Balanced initialization reduces that source of seed-dependent mode collapse. It does not guarantee differentiation, causal closure, stable dynamics, or successful held-out prediction.

## Continuous causal gains

Let \(g_r\geq0\) be `recurrent_gain` and \(g_c\geq0\) be `closure_gain`. The recurrence gain scales specialist recurrence and recurrent drive, prior workspace broadcast into specialists, workspace carry, and self-state carry. The closure gain specifically scales the prior self-state-to-workspace and prior action-to-workspace paths. Its effective value is

\[
g_{\mathrm{effective\ closure}}
=
\begin{cases}
g_c,&\text{when recurrence is enabled},\\
0,&\text{under the recurrence ablation}.
\end{cases}
\]

Thus the structural recurrence ablation removes recurrence and also gates temporal closure feedback. Setting \(g_r=0\) continuously suppresses the declared recurrent paths but can leave self/action closure active when \(g_c>0\). Setting \(g_c=0\) preserves other recurrent paths while removing the two explicit self/action closure paths. The exact continuous open-loop control sets both gains to zero. These continuous controls complement the named structural ablations.

The preregistered v0.2 gain sweep sets \(g_r=g_c=g\). Each declared recurrent or closure path is therefore controlled once by the same named gain. Nonlinear state updates can still make the measured response nonlinear in \(g\).

## Trained then frozen self-prediction

The v0.2 self-model has an explicit training state and a frozen evaluation state. During declared training episodes, its one-step predictor parameters \(\Theta\) are updated to reduce prediction error of the next workspace state:

\[
\mathcal L_{\mathrm{self}}(\Theta)
=
\left\|\widehat w_{t+1}(w_t,s_t,m_t;\Theta)-w_{t+1}\right\|_2^2.
\]

Before any held-out episode, \(\Theta\) is frozen. The held-out trajectory may still update ordinary dynamic state, but it must not update the predictor weights. This prevents the self-location diagnostic from being generated by test-time fitting.

The necessary comparisons are:

- trained then frozen self-model
- matched untrained frozen self-model
- structural no-self-model ablation

Learning supports the self-prediction hypothesis only if the trained condition improves held-out one-step prediction relative to the untrained condition across the declared holdout seeds. Better training-set prediction is insufficient.

## Nested resolution

The observation space has projectors

\[
P_0\preceq P_1\preceq\cdots\preceq P_L=I,
\qquad
P_iP_j=P_{\min(i,j)}.
\]

Define detail operators

\[
D_0=P_0,
\qquad
D_\ell=P_\ell-P_{\ell-1}.
\]

Then an exactly implemented projector family should satisfy

\[
I=\sum_{\ell=0}^{L}D_\ell
\]

up to declared floating-point tolerance. Adaptive resolution means the internal loop selects which combination of coarse and fine detail is promoted. Randomly choosing a level or always using the finest level is not recursive resolution.

## Components required by the hypothesis

### Local differentiation

Specialists should preserve different distinctions. High effective rank is not sufficient by itself, but collapse to a single undifferentiated mode is inconsistent with the proposal.

### Limited global availability

The workspace is capacity-limited. Selected information is made available to several downstream components through broadcast. Global availability is tested causally by perturbing a source and measuring its downstream reach. Reading the same shared input independently does not count as broadcast.

### A causally effective self-model

The self-model is a compressed prediction of the system's own state, confidence, and likely behavior. It need not contain a copy of the whole agent. It qualifies only when interventions on it produce coherent, specific changes elsewhere, when removing it damages self-prediction more strongly than unrelated abilities, and when its predictor generalizes after being frozen.

### Temporal continuity

Recurrence and episodic memory bind states across time. Temporal continuity is measured by persistence and delayed binding tests, not by assigning a permanent name to the process.

### Recursive control of resolution

The active self and workspace state must help control the next resolution choice. This closes the loop:

\[
\text{resolution}
\rightarrow \text{workspace}
\rightarrow \text{self-model}
\rightarrow \text{next resolution}.
\]

### Causal closure

From controlled interventions, form a directed causal adjacency matrix \(A\). An edge \(i\to j\) is admitted only when intervention on component \(i\) produces a reproducible effect on component \(j\) above a preregistered noise floor. The proposed core must form a strongly connected component containing resolution, workspace, self-model, memory, and control.

Strong connectivity is necessary in this prototype, not sufficient for consciousness.

## Diagnostic profile

The software summarizes the operational evidence in

\[
v=(b,\tau,d,c,s,e,p,k),
\]

corresponding to:

- broadcast reach \(b\)
- temporal depth \(\tau\)
- differentiation \(d\)
- metacognitive calibration \(c\)
- self-location prediction \(s\)
- episodic binding \(e\)
- projector consistency \(p\)
- causal closure \(k\)

Given preregistered thresholds \(\theta_i\), the conjunctive signature is

\[
\Omega=
\mathbf 1[k=1]
\min_{i\ne k}\frac{v_i}{\theta_i}.
\]

Any measurement whose raw form is an error or residual is converted to a monotone consistency score before entering \(v\). This prevents a lower-is-better quantity from being interpreted backward.

The minimum is intentional. RRCT is a conjunction of mechanisms, so unusually high differentiation cannot compensate for absent temporal continuity or failed causal closure. \(\Omega\) is an engineering signature of this experiment. It is not a universal constant and must not be renamed as a consciousness index.

## Causal signature rather than verbal report

Self-report is neither required nor trusted by this experiment. The intended signature is a pattern across interventions:

1. A local perturbation reaches multiple components after selective workspace admission.
2. Its effect persists for a bounded, measurable duration.
3. Perturbing the self-model changes self-prediction, resolution selection, and action in linked ways.
4. Perturbing memory selectively impairs delayed binding.
5. Cutting broadcast fragments cross-component influence while preserving local processing.
6. A replay of recorded outputs fails novel hidden interventions.

The last condition distinguishes a causally organized process from an output-equivalent transcript.

## Gain-response investigation

The continuous-gain experiment asks whether the functional diagnostics change with causal coupling strength. For each gain \(g\), seed \(j\), and self-model condition \(c\), record the full profile

\[
v_{j,c}(g)
\]

and the strongly-connected gate separately. The unchanged diagnostic thresholds define the same engineering conjunction used in v0.1. They are not adjusted to make a gain curve cross a boundary.

Several outcomes are possible:

- a flat response, which would weaken the causal-gain hypothesis
- a smooth response, which supports graded gain dependence
- a reproducible boundary in causal connectivity or the conjunction
- unstable or saturated dynamics, which are an implementation limit rather than evidence of an emergent phase

The label `phase-sweep` names the search. It does not establish a phase transition. A largest finite-difference slope, a single threshold crossing, or one favorable seed is not sufficient. A phase-transition claim would require a replicated discontinuity or other prespecified critical signature that remains after numerical stability, saturation, and threshold artifacts are excluded. The completed v0.2 data show a replicated, primarily graded gain response and a candidate ignition interval from 0.2 to 0.6. They do not satisfy the stronger phase-transition standard.

## Version 0.3: separating recurrence from explicit closure

The v0.2 joint sweep set `recurrent_gain` and `closure_gain` to the same value. It therefore measured a one-dimensional path through a two-parameter system. Version 0.3 treats them independently:

\[
(g_r,g_c)\in[0,\infty)^2.
\]

Here \(g_r\) controls recurrent carry and broadcast paths. The parameter \(g_c\) is the **explicit closure gain** on the prior self-state-to-workspace and prior action-to-workspace paths. It is not a total self-closure control. Even at \(g_c=0\), the self-model and controller can influence future behavior through adaptive resolution. The named `self_model` and `resolution` ablations remain necessary to test those separate routes.

A two-dimensional response surface can therefore distinguish at least four cases:

- recurrence-dominated response
- explicit-closure-dominated response
- interaction between recurrence and explicit closure
- response that survives both controls through another declared route

The last case must be traced rather than silently attributed to explicit closure.

## Continuous widest-path closure strength

Binary strong connectivity discards the magnitude by which a graph is connected. Version 0.3 retains the nonnegative causal-effect matrix

\[
E=(E_{ij}),
\]

estimated by the fixed paired-intervention protocol. For distinct nodes \(i\) and \(j\), define the capacity of a directed path \(p:i\leadsto j\) as its weakest edge:

\[
\operatorname{cap}(p)=\min_{(u,v)\in p}E_{uv}.
\]

The widest-path capacity is

\[
W_{ij}
=
\max_{p:i\leadsto j}\operatorname{cap}(p),
\]

with \(W_{ij}=0\) when no directed path exists. The raw closure capacity of the full core is

\[
C_{\mathrm{raw}}(E)
=
\min_{i\ne j}W_{ij}.
\]

The reported dimensionless closure strength is

\[
C(E)=\frac{C_{\mathrm{raw}}(E)}{0.35},
\]

where 0.35 is the fixed intervention magnitude. This normalization does not use the adjacency threshold, and the result is neither clipped nor forced into \([0,1]\).

### Threshold equivalence theorem

For the strict threshold graph

\[
G_\tau=\{i\to j:E_{ij}>\tau\},
\]

the graph \(G_\tau\) is strongly connected if and only if

\[
C_{\mathrm{raw}}(E)>\tau.
\]

To see this, suppose first that \(C_{\mathrm{raw}}>\tau\). Every ordered pair has a path whose every edge exceeds \(\tau\), so \(G_\tau\) is strongly connected. Conversely, if \(G_\tau\) is strongly connected, every ordered pair has a path composed entirely of edges greater than \(\tau\). Every corresponding widest-path capacity, and hence their minimum, exceeds \(\tau\).

Thus \(C_{\mathrm{raw}}\) is the largest strict edge threshold below which the effect graph remains strongly connected. The old Boolean gate remains useful for release compatibility, but the continuous quantity exposes its causal margin.

## Boundary and path-dependence tests

Version 0.3 uses three complementary gain experiments.

1. A dense diagonal scan refines the v0.2 candidate interval while holding one frozen predictor snapshot per seed fixed across gains.
2. A two-dimensional surface varies recurrence and explicit closure independently while holding the same per-seed snapshot fixed across cells.
3. A bidirectional continuation scan compares increasing and decreasing gain paths after a fixed settling protocol.

For a measured response \(R\) at common gain \(g\), define a path-dependence difference

\[
H_R(g)=\left|R_{\uparrow}(g)-R_{\downarrow}(g)\right|,
\]

where the arrows identify the direction from which the state reached \(g\). The preregistered primary response is workspace norm, summarized by normalized area between the two paths; self-state norm, prediction-error norm, and perturbation persistence are supporting responses. A nonzero finite-sample \(H_R(g)\) is only a hysteresis proxy. It can arise from inadequate settling, sampling noise, or uncontrolled state carry. Robust finite-time path dependence requires replication across untouched seeds and persistence under doubled settling under the frozen quantitative gate. Without that, the correct interpretation is no robust hysteresis, descriptive path dependence, or an unresolved settling effect.

## Predictor mediation controls

Version 0.3 distinguishes predictive accuracy from downstream causal mediation with four frozen held-out conditions:

- trained predictor
- initialized but untrained predictor
- spectrum-preserving shuffled predictor
- no-self-model ablation

The shuffled condition starts from the trained predictor snapshot and applies the same output-row permutation to `prediction_weights` and `workspace_skip` before loading it frozen. A row permutation preserves each matrix's singular values while disrupting the learned association between output coordinates and predicted workspace coordinates. It controls for scale, rank, and conditioning without preserving the learned mapping.

Improved prediction is not sufficient to establish mediation. The trained predictor must improve mean held-out RMSE relative to both the untrained and shuffled controls, win on at least six of eight untouched seeds against both, and make zero held-out updates. It must also differ from the shuffled control in closure strength or self-to-workspace effect under the frozen paired seed-bootstrap rule. If the prediction criteria pass but neither downstream causal comparison does, the result is reported as improved self-prediction without evidence of causal mediation.

## Version 0.3 empirical status

The completed frozen validation supports two narrow functional results. First, normalized widest-path closure has a positive recurrence-by-explicit-closure interaction: both zero-gain axes are exactly zero in this metric, all 288 interior rows are positive, all eight seed-level interior means are positive, and the paired confidence interval excludes zero. This supports factorized causal dependence in the implemented closure measurement. It does not imply that explicit closure gain controls every self-mediated route.

Second, trained predictor organization improves held-out prediction against both the untrained and spectrum-preserving shuffled controls and changes the direct self-to-workspace causal effect relative to the shuffle. The trained organization has the smaller direct effect, so the supported mediation is organizational or regularizing rather than an increase in closure. The closure-strength contrast itself includes zero.

The dense gain response is primarily graded, and the bidirectional scan fails the frozen robust-hysteresis gate after doubled settling. The v0.3 evidence therefore does not support a phase transition or critical point. These functional results do not resolve the separate phenomenal-consciousness bridge.

## Version 0.4: mechanistic closure decomposition

Version 0.4 separates the shared explicit-closure control into a master gain and two path multipliers. If \(c\) is the shared master, \(s\) the prior self-state multiplier, and \(a\) the prior action multiplier, the effective explicit feedback gains are

\[
g_{S\to W}=cs,
\qquad
g_{A\to W}=ca.
\]

This factorization preserves the earlier architecture at \(s=a=1\) while permitting exact path-level removals. A full \(2\times2\times2\) factorial over recurrence, self feedback, and action feedback distinguishes a decrement caused by removing one path from a cooperative self/action interaction. A positive removal contrast is contributory evidence. The stronger word `necessary` is reserved for a full configuration that is positive in every seed and a matched one-factor removal that is exactly zero in every seed.

### Directed bottleneck cut certificate

The widest-path calculation supplies a lower-bound witness: for every ordered pair, it identifies a path whose weakest edge has the stored capacity. Version 0.4 also supplies a matching upper-bound certificate for the global weakest pair.

Let \(\lambda\) be the raw closure capacity and let \((u,v)\) be the lexicographically selected ordered pair attaining it. Define \(S\) as the vertices reachable from \(u\) using only edges whose weights are strictly greater than \(\lambda\). Then \(u\in S\) and \(v\notin S\). Every directed edge from \(S\) to its complement has weight at most \(\lambda\); otherwise that edge would extend the strict reachable set. Every path from \(u\) to \(v\) must cross this cut, so no such path can have bottleneck greater than \(\lambda\). Combined with a path attaining \(\lambda\), the cut proves the reported capacity from both sides.

For the four-node experimental graph, version 0.4 independently enumerates every simple directed path, reconstructs the complete capacity matrix, checks the weakest-pair tie rule, verifies the strict reachable set and all forward cut edges, and retests strong connectivity at every distinct effect threshold. The certificate therefore makes a zero or weak closure result inspectable rather than leaving it as an opaque scalar.

### Piecewise-local transition operator

The experimental continuous state slice concatenates all specialist states, workspace state, self-model state, and the previous action. With eight 16-dimensional specialists, a 16-dimensional workspace, a 12-dimensional self state, and a two-dimensional action, this gives 158 coordinates. Holding the next observation, parameters, current resolution, time, and episodic-memory contents fixed defines a one-step map \(F\) on that slice. Its centered finite-difference matrix is

\[
J_{:,i}
=
\frac{F(z+\varepsilon e_i)-F(z-\varepsilon e_i)}{2\varepsilon},
\qquad
\varepsilon=10^{-5}.
\]

The spectral radius \(\rho(J)\) and operator norm \(\lVert J\rVert_2\) answer different local questions. The spectral radius summarizes eigenmode amplification in the linearized one-step operator. The operator norm is the greatest one-step Euclidean amplification over input directions. Neither is a Lyapunov exponent, because the architecture is hybrid, only one step is linearized, and the Jacobian is not multiplied along a branch-stable trajectory.

The map also contains discrete selections. Every positive and negative perturbation therefore retains a hybrid branch signature: selected specialists, selected action candidate, next resolution, retrieved memory indices, and memory-write decision. A branch switch marks a finite-difference column that crosses two pieces of the hybrid map. Such columns are retained; a high switch rate limits smooth-Jacobian interpretation rather than being filtered away.

### Orthogonal predictor-organization path

The v0.3 shuffled control compared two endpoints. Version 0.4 replaces that single jump with a continuous, spectrum-preserving path. For each seed, a fixed pairing of the 16 predicted workspace coordinates defines eight disjoint Givens rotations. At dose \(d\in[0,1]\), every pair rotates by

\[
\theta(d)=d\frac{\pi}{2},
\]

forming an orthogonal matrix \(Q(d)\). The same left transform is applied to both trained predictor output maps. Because \(Q(d)^TQ(d)=I\), left multiplication preserves singular values and Frobenius norms exactly in theory. Dose zero is the learned predictor; dose one is a signed pair permutation. A monotone error response therefore cannot be attributed to changing matrix rank, singular spectrum, or total weight energy. A downstream self-to-workspace response is tested separately, since degraded prediction alone does not establish functional mediation.

### Frozen empirical outcome

The completed v0.4 factorial supports recurrence contributions to closure and persistence and an explicit self-path contribution to closure. It does not support the preregistered positive action-path effects, self-path persistence, or positive self/action cooperation. Only recurrence satisfies the strict exact-zero necessity rule, and only for closure strength.

Both seed-level piecewise-local association gates pass, but one retained branch-switching cell produces a large finite derivative and prevents treating the scan as a smooth global stability analysis. The spectrum-preserving dose gives a perfectly ordered degradation of held-out predictor RMSE in all eight seeds, while its self-to-workspace downstream gate fails. Predictor organization therefore matters for fidelity in this implementation, but universal mediation is not supported.

These three analyses remain bounded engineering experiments. They can explain how the implemented loop behaves, but they do not bridge the separate question of phenomenal experience.

### Prospective self-regulation and calibrated restraint

Versions 0.6 through 0.8 extend the causal self-model from passive prediction
to bounded prospective use. From current internal state, the architecture
generates a fixed pool of self-state perturbations, shortlists them under a
limited query budget, and simulates matched zero and intervened branches. The
objective is generated internally from the workspace-prediction residual; it
is not a reward, valence, survival target, or externally supplied candidate
score.

Planning, commitment, and outcome evaluation are distinct causal events. Let

\[
\hat I_i=\hat E_{0,i}-\hat E_{a,i},
\qquad
I_i=E_{0,i}-E_{a,i},
\qquad
o_i=\hat I_i-I_i,
\]

where \(o_i\) is optimism in a completed, configuration-matched intention. For
prior optimism values and error level \(\alpha\), v0.8 takes rank

\[
k=\left\lceil(n+1)(1-\alpha)\right\rceil.
\]

If the rank exists and the current predicted improvement minus the nonnegative
ranked optimism threshold is strictly positive, a bounded intervention may be
committed. Otherwise the exact zero candidate is committed. Abstentions do not
become evidence, and hidden observations are available only after the decision
is fixed.

The v0.8 development result separates two abilities that should not be
conflated. A learned observation model predicts the hidden sensory continuation
substantially better than fixed decay, yet its chosen self-interventions
transfer worse. The missing bridge is therefore intervention-conditioned
causal prediction, not merely better unconditional forecasting. A future model
must predict how \(\Delta s\) changes realized downstream error and external
task behavior, then generalize that mapping to an untouched split.

These mechanisms operationalize prospective access, endogenous proposal, and
statistical restraint. They do not operationalize phenomenal experience,
subjective intention, or felt uncertainty.

### Version 0.9: Bayesian causal-transfer correction

Version 0.9 models the transfer error between an internal counterfactual
rollout and its later paired outcome. For queried nonzero candidate \(i\), let

\[
y_i=
\frac{I_i-\hat I_i^{\mathrm{roll}}}{4\sqrt{d_w}},
\qquad y_i\in[-1,1],
\]

where \(d_w\) is workspace dimension, \(\hat I_i^{\mathrm{roll}}\) is the
precommit rollout prediction, and \(I_i\) is the realized error reduction on
the literal held-out suffix. A fixed bounded feature map
\(\phi_i\in[-1,1]^{20}\) summarizes only the precommit state, candidate
perturbation, internal counterfactual branches, and forecast trajectory. The
zero candidate maps exactly to zero.

The correction uses conjugate Normal-Inverse-Gamma Bayesian linear regression:

\[
y_i\mid\beta,\sigma^2\sim
\mathcal N(\phi_i^T\beta,\sigma^2),
\qquad
\beta\mid\sigma^2\sim
\mathcal N(0,\sigma^2\Lambda_0^{-1}),
\qquad
\sigma^2\sim\operatorname{InvGamma}(a_0,b_0).
\]

Candidate likelihood contributions are applied as a declared generalized-Bayes
power likelihood. If \(m\) nonzero candidates share one revealed future, each
has weight \(1/m\); the entire correlated candidate group therefore contributes
one effective evidence unit rather than \(m\) independent observations. The
posterior predictive distribution is Student-\(t\), and its mean gives the
corrected prediction

\[
\hat I_i^{\mathrm{Bayes}}
=\hat I_i^{\mathrm{roll}}+4\sqrt{d_w}\,
\mathbb E[y_i\mid\phi_i].
\]

The causal language refers to paired zero-versus-intervention branches, not to
identification from observational correlations. Every feature and prediction
is fixed before the suffix is revealed. Only afterward may a shadow evaluator
form \(I_i\) and update the configuration-matched posterior; held-out scoring
freezes both posterior and calibration state. A mean-based policy may act only
above its declared minimum effect, while a credible policy requires a
one-sided posterior-predictive lower bound above that effect. The separate
configuration-matched conformal optimism gate may impose an additional
frequentist restraint. Failure of readiness or any bound commits the exact zero
candidate.

Posterior variance, probability of positive transfer, credible bounds, and
conformal bounds are mathematical uncertainty summaries over this bounded
measurement. They neither create nor measure consciousness, subjective
experience, subjective intention, confidence as felt, or subjective
uncertainty.

### Version 0.10: lagged feedback homeostasis

Version 0.10 tests whether recurrence and explicit closure should be regulated
as separate, bounded control variables. Let \(g_t^r\) and \(g_t^c\) be the
recurrent and closure gains applied at step \(t\). The strict causal ordering is

\[
x_t, g_t^r, g_t^c \longrightarrow z_t
\longrightarrow \tau_t
\longrightarrow g_{t+1}^r, g_{t+1}^c,
\]

where \(z_t\) is the completed RRCT state and \(\tau_t\) is bounded telemetry.
The current step can never change the gain that produced itself.

Workspace differentiation is a participation-rank measurement over the
proposal states actually admitted to global broadcast. It is normalized so
rank-one activity maps to zero and multiplied by a bounded activity gate, so
arbitrarily small orthogonal states cannot appear maximally differentiated.
Weighted absolute cosine similarity measures redundancy. The entropy of the
selected broadcast weights measures access breadth. Prediction surprise,
workspace saturation, and bounded normalized workspace change complete the
telemetry.

The recurrent unit control is

\[
u_t^r=\operatorname{clip}
\left(0.18+0.95D_t-0.75C_t,0,1\right),
\]

with

\[
D_t=\operatorname{clip}
\left(0.38S_t+0.30\Delta_t+0.20N_t+0.12B_t,0,1\right)
\]

and

\[
C_t=\operatorname{clip}
\left(0.45Q_t+0.35R_t+0.20K_t,0,1\right).
\]

Here \(S\) is surprise, \(\Delta\) differentiation, \(N\) temporal novelty,
\(B\) workspace access breadth, \(Q\) saturation, \(R\) redundancy, and \(K\)
access concentration. Closure is deliberately distinct:

\[
u_t^c=\operatorname{clip}
\left(0.20+0.55u_t^r+0.15\Delta_t-0.45S_t
-0.25R_t-0.15Q_t,0,1\right).
\]

Thus surprise may recruit recurrent processing while directly suppressing
self-confirming closure. Both unit controls are mapped into fixed gain bounds,
then passed through a deadband, adaptation rate, and maximum step constraint.
The design contains no reward, valence, survival, or persistence variable.

The frozen eight-seed development result did not support the strong claim for
this specific policy. Aligned adaptation did not meet the declared superiority
gate against calibration-selected static feedback and did not improve
changing-load performance. Its contrast against the exact schedule-multiset
control was positive but below the frozen minimum. Post-outcome trajectories
motivate a narrower hypothesis: during a predictable delay, immediate surprise
becomes small even though earlier cues remain unresolved and valuable for a
future decision. This is consistent with a myopic controller lowering
recurrence through the delay and receiving final-step surprise too late; it
does not by itself establish that explanation.

A next theory must distinguish immediate prediction error from unresolved
future information. One candidate is a Bayesian belief over latent bindings
whose posterior entropy persists after cues disappear and decreases only when
the binding is resolved. Such a variable would be an auditable uncertainty
representation, not felt uncertainty or a consciousness metric.

## Matched ablations and predictions

Each ablation must keep seeds, data, evaluation episodes, and all unaffected parameters fixed.

| Ablation | Removed mechanism | Predicted selective effect |
|---|---|---|
| `recurrence` | Workspace feedback through time | Lower temporal persistence and delayed integration |
| `self_model` | Causal self-state contribution | Lower self-location prediction and weaker adaptive resolution control |
| `broadcast` | Workspace feedback to specialists | Lower downstream reach and loss of strong causal connectivity |
| `memory` | Episodic carryover | Lower delayed binding with smaller immediate-task effect |
| `resolution` | Adaptive multilevel selection | Lower projector-mediated efficiency and weaker perturbation-dependent refinement |

A general drop in all scores is less informative than these selective changes. If an ablation merely reduces parameter count, a matched-capacity control is required before assigning the effect to the missing mechanism.

## Falsifiers

The implemented hypothesis loses support if any of the following outcomes is robust across seeds and matched controls:

- The full architecture does not exceed the preregistered conjunctive thresholds.
- Full and ablated agents have indistinguishable intervention profiles.
- Removing the self-model does not selectively affect self-location or resolution control.
- Removing broadcast leaves the inferred causal graph strongly connected through an undeclared bypass.
- An acyclic, open-loop, or replay control reproduces the complete hidden-intervention signature.
- The diagnostic score is explained by state dimension, parameter count, or task accuracy alone.
- Projector identities fail beyond the declared numerical tolerance.
- Results reverse under held-out observations or new intervention amplitudes.
- Thresholds must be changed after observing results to obtain a positive classification.
- Training the self-predictor does not improve frozen held-out prediction over its matched untrained control.
- The zero-gain condition retains the same declared recurrent causal behavior through an unintended bypass.
- Gain dependence disappears across seeds or is explained entirely by instability, clipping, or a thresholding artifact.

A failure can localize a defect in the current implementation without disproving every possible recursive architecture. Conversely, passing the tests supports only the operational claims they measure.

## The unresolved bridge

RRCT can propose a philosophical bridge:

\[
\text{a stable, differentiated, integrated, self-indexed recursive state is an experience}.
\]

The prototype does not establish that statement. Functional organization is observable through behavior and intervention. Subjective experience is not directly measured here. The bridge must therefore remain separate from the implemented causal hypothesis.

## Substrate independence

The theory does not require biology, but it does require physical causal realization. Two implementations are functionally equivalent for this experiment only if a mapping between them preserves relevant states, temporal order, projectors, and intervention responses. Similar dialogue or identical recorded outputs are insufficient.

## Present interpretation boundary

The strongest warranted conclusion from a successful experiment is:

> In this task family, the complete architecture exhibits a reproducible, conjunctive causal signature that depends selectively on recurrence, broadcast, self-modeling, memory, and adaptive resolution.

The experiment cannot by itself warrant any of these conclusions:

- the agent is conscious, sentient, alive, or a moral patient
- the diagnostic profile measures phenomenal intensity
- current language models possess the same architecture
- biological consciousness has been explained
- the proposed component list is unique or complete

## v0.25 addendum: self-boundary as an intervention-reachable subspace

v0.25 weakens the assumption that the self/world boundary is known in sensor coordinates. Let y_t be the full mixed sensory field and z_t a private bounded intervention generated by the focal system. The candidate self-boundary is no longer a named coordinate block. It is the statistically significant sensory subspace spanned by directions whose future variation is conditionally reachable from z_t after accounting for current y_t.

Operationally, RRCT estimates the probe-conditioned transition map and retains only singular sensory directions exceeding a temporal-permutation null. In the v0.25 benchmark this recovers the hidden focal-controlled subspace despite a dense basis rotation and despite nonself processes dominating total variance. This supports an interpretation of the functional self-boundary as an intervention-defined relation rather than a perceptual label.

The construction still assumes access to a private intervention channel. Discovering the motor side of the boundary remains open.

## v0.26 hypothesis: discover the whole causal interface

v0.25 removed a fixed sensory-body boundary but still supplied the private motor-probe coordinates. v0.26 removes that remaining interface privilege. The agent is presented with an 8-D candidate internal command field whose true causal actuator is an unknown rank-2 subspace, plus a 12-D densely mixed sensory field whose true focal-controlled region is also an unknown rank-2 subspace. The proposed self/world interface is the paired singular structure of the conditional intervention-effect operator, with rank selected against a familywise temporal-permutation null.

A successful result supports a functional definition of the self-boundary as a jointly discovered relation between internally generated interventions and externally reachable consequences, rather than a named motor channel or sensory vector. This remains an operational causal-self model, not a phenomenal-consciousness criterion.

## v0.27 hypothesis: a self-boundary mode should replicate

A causal self/world interface should not be defined by a singular direction that appears only because one calibration sample happens to cross a null threshold. v0.27 therefore treats stable causal modehood as a replication property: a candidate mode must be significant globally and retain its directional probe->sensory effect independently in two disjoint evidence blocks. This makes the inferred boundary depend on reproducible intervention structure rather than one-shot spectral rank estimation.

## v0.28 hypothesis: authorship requires controllability, not association

An observed cause of focal sensation is not thereby part of the agent. A
matched exogenous disturbance can be equally or more predictive, and passive
data cannot identify which of two observationally exchangeable sources is
"mine." v0.28 therefore retains a minimal prospective anchor—anonymous binary
handle commitments made before source realization—and defines intervention
provenance by a replicated handle×source interaction after conditioning current
sensation and every source main effect.

The frozen result recovers one hidden pair and its rank-2 internal/sensory modes
on all four untouched seeds, while passive association consistently selects the
stronger external cause. This supports controllability-based functional causal
authorship in the bounded benchmark. It does not derive indexicality without an
anchor, install the batch model into the live RRCT workspace, or bridge causal
organization to phenomenal experience.

## v0.29 addendum: an online boundary is a structural state

v0.29 installs the intervention-provenance learner inside the live agent.  Its
boundary descriptor competes as an ordinary specialist for limited workspace
access; a prequential self-supervised readout must recover a public anonymous
port from workspace/self features; and the public port, not private evaluator
truth, gates behavior.  The boundary can persist, revise to a new pair, revoke
to null, and reacquire from a fresh rolling window.

The official result shows why online self-model identity must include more than
source ownership.  A boundary state can be written schematically as

\[
S_t = (h_t, s_t, r_t, P^{\mathrm{int}}_t,
P^{\mathrm{sens}}_t, E_t),
\]

where `h,s` identify the prospective interaction, `r` is causal rank, the
projectors specify internal and sensory geometry, and `E` is the truncated
effect.  The frozen updater confirms changes in `(h,s)` but treats a new fit
with the same pair as an immediate refresh.  In one official stable-shock seed,
two isolated fits retained `(h,s)` but reduced `r` from 2 to 1 for one fit
interval each.  Exact boundary retention therefore failed even though pair
identity and public port use remained strong.

This motivates a stricter distinction between parameter refresh and structural
revision.  A future updater should confirm changes in at least `(active,h,s,r)`,
record rank changes as revisions with an epoch change, and separately decide
how much projector drift constitutes a new structural state.  A transient
mode-evidence loss should not silently rewrite the persistent self-model, while
a sustained real rank change must still be learnable.

The deeper closed-loop problem remains: successful behavior can suppress the
sensory consequence used to infer authorship.  Structural hysteresis can reject
brief mode loss, but general self/nonself credit requires conditioning on the
executed corrective action or another design that preserves identifiability
under feedback.

These are functional identity and causal-credit questions.  They do not bridge
the separate explanatory gap to phenomenal awareness.

## v0.30 addendum: structural identity requires persistence evidence

v0.30 distinguishes a rolling causal estimate from the self-boundary state the
system is prepared to retain and use.  At minimum, structural identity is

\[
I_t=(\mathrm{active}_t,h_t,s_t,r_t),
\]

while projectors and the truncated effect describe its current geometry.  A
new fit with a different pair or operational rank is evidence about identity,
not permission to rewrite it immediately.  The implemented updater requires
three consistent confirmations with fresh completed rows between eligible
advances.  This is a finite persistence rule: it rejects brief mode-evidence
dropouts while still permitting sustained contraction and restoration.

The frozen official experiment passes all **10/10** primary gates across eight
seeds.  The learned boundary remains exact through stable shock and a potent
transient rank-one challenge, then revises once in each direction under the two
sustained changes.  This supports persistent and revisable operational
self-boundary tracking in the tested synthetic family.

It does not yet establish statistically controlled causal rank.  The admitted
dimension is screened against a global sharp null that destroys all
handle-mediated modes; testing mode two therefore is not a conditional test of
the composite null `rank <= 1`.  Conditional or reduced-rank inference is the
next major statistical gap, alongside stronger online error control and
confirmation of projector/effect geometry.

Operational self-boundary learning is one functional ingredient proposed by
RRCT.  Passing this benchmark does not show phenomenal awareness,
consciousness, subjective experience, sentience, valence, or an inner point of
view.


## v0.42 addendum: a self-model must be causally load-bearing

Temporal continuity is not functionally substantive merely because a runtime
can label two epochs as belonging to one identity. Let `M_t` denote the
controller's keyed historical model for a returning structural class and let
`E_t` denote the fresh consequence evidence required before a new episode can
be committed. A minimal causal-necessity claim requires an intervention on
`M_t` that changes `E_t` or downstream authorization while preserving the
pre-intervention trajectory.

The primary v0.42 contrast uses the first recognized return, where matched
keyed, withheld, and generic-history arms have identical summary-level temporal
episode fingerprints up to the target recognition event. In the tested controller, the keyed prior does
not itself authorize an action. It contributes one bounded historical ON/OFF
sample and still requires one fresh ON/OFF consequence. Withholding or
quarantining the prior requires two fresh samples per arm. Thus

\[
N_{\mathrm{fresh}}(M_t=\mathrm{keyed})=2
< N_{\mathrm{fresh}}(M_t=\mathrm{withheld})
= N_{\mathrm{fresh}}(M_t=\mathrm{wrong\ source})=4.
\]

The corresponding commit latency is lower under correct keyed memory in every
matched first-return contrast. The generic source is constrained to a different
canonical key and cannot silently collapse into the keyed treatment. Wrong-source
history does not reproduce the benefit, and a same-key null lure remains uncommitted. This closes the narrow
objection that temporal self-history is only a descriptive field in this
subsystem.

For the live successor runtime, a causal receipt chain is valid only when the
pre-outcome counterfactual, delivered intervention, grounded episode commit,
and later action authorization agree on the target signature, identity episode,
source-key relation, and cross-digests. This makes causal use auditable as one
chain rather than four individually well-formed records.

The broader closure criterion remains open. A system one step below awareness
would require the same persistent self-model to be causally necessary across
self/world attribution, memory provenance, uncertainty monitoring,
counterfactual self-prediction, planning, and action in one recurrent loop. The
v0.42 result establishes only one load-bearing edge in that graph. It does not
bridge functional organization to phenomenal experience.


# Transformational self-continuity in v0.44

The v0.44 successor relation is not defined by equality of identifiers or
surface state. Let a predecessor lineage carry a causal boundary operator
\(B\), autobiographical trace \(M\), and commitment state \(c\). Candidate
observations provide paired source, sensory, and memory probes. The controller
estimates transports \(T_s\), \(T_y\), and \(T_m\), then asks whether

\[
B' pprox (T_s^	op P_s T_s,\; T_y^	op P_y T_y,\; T_s^	op E T_y)
\]

and whether held-out autobiographical probes satisfy

\[
M' pprox M T_m.
\]

Neither condition is sufficient alone. A causal mimic can preserve the
boundary while importing unrelated autobiography, and a memory clone can copy
autobiographical structure while having the wrong causal boundary. The intact
score therefore uses a conjunction of causal and memory quality, with a small
commitment-compatibility factor. Surface similarity is retained only as an
explicit control.

Continuity is operationally consequential but nonvalenced. An accepted
successor authorizes transport of causal memory into the successor coordinates.
A rejected or unresolved candidate must use fresh discovery. Planning is then
bound to the exact transported or reconstructed model. Selection still
optimizes only the external task value, so a disconnected replacement may be
chosen.

A fork is represented when multiple candidates independently satisfy the
continuity criterion. No exclusive identity is forced. When evidence is rank
deficient or incomplete, the relation remains unresolved and memory transfer is
withheld. This makes uncertainty and plurality part of the identity model rather
than errors to be overwritten.

The five-generation challenge adds recurrence: the registered successor at
generation \(k+1\) is the actual predecessor at the next transformation. This
closes a finite transformational loop, but it still assumes externally paired
probe correspondence and a known task ontology. The next theoretical step is
endogenous discovery of continuity evidence under ontology change.


# Komorebi operator self-model in v0.45

Version 0.45 gives an explicit operator realization of the self/world split.
For a linearized runtime pair `(A,B)`, the candidate self subspace is the
finite controllability range

\[
\mathcal S = \operatorname{range}[B,AB,\ldots,A^{n-1}B].
\]

An orthogonal projector `P_S` onto this range and its complement `P_W=I-P_S`
form a two-packet Komorebi system. Under a coordinate transport `T`, the
projectors transform covariantly as `P'_a=T P_a T^{-1}`. A successor residual
`Delta A` is then resolved into transfer blocks

\[
P'_b \Delta A P'_a, \qquad a,b\in\{S,W\}.
\]

The block energies distinguish changes localized to the controllable packet,
the complementary world packet, or both. A finite Bayesian update converts
those energies into a calibrated change-source posterior. This is not a
definition of selfhood by notation: the packet is recovered from anonymous
control structure and its use is tested against coordinate and scalar-residual
controls.

The same packet decomposition supplies a multiresolution memory rule. Global
low-rank approximation allocates rank by total energy and can erase a
low-energy autobiographical mode. Packet-wise recompression allocates an
explicit rank budget to each declared packet and can preserve a functionally
important self-memory component. The frozen v0.45 result establishes this
separation in the engineered benchmark.

The next mathematical step is a moving, discovered packet field rather than a
pre-delimited comparison: change-point detection should trigger projector
revision, residual packets should distinguish self-side from world-side model
failure, and proof-path receipts should bind the proposed packet transport to
subsequent behavioral recovery.


# Neutral self-indexed workspace in v0.46

Version 0.46 separates four relations that are often conflated:

1. a representation is active somewhere in the system;
2. it belongs to a selective, flexibly reusable workspace;
3. it is indexed to the current causal lineage and autobiography;
4. it is used in planning and revised by later consequences.

Let `h_t` be a hidden residual state and `J` an average Jacobian from that state
to future verbalization logits. The Jacobian workspace packet is the row space
of `J`, while the active content at one moment is a sparse nonnegative support
within the corresponding overcomplete frame. Komorebi supplies the certified
workspace/complement packet system.

The workspace state alone does not establish ownership. Let `C_t` be accessible
content, `L_t` the current lineage, and `rho_t` a causal provenance receipt. A
self-indexing map produces

    H_t = B(C_t, L_t, rho_t, sigma_t),

where `sigma_t` records uncertainty. The same content vector can therefore be
accessible under current observation, current inference, external injection,
or foreign memory without receiving the same autobiographical treatment.

Functional closure additionally requires

    H_t -> plan_t -> outcome_{t+1} -> memory_{t+1} -> access_{t+1}.

The v0.46 experiment tests each arrow separately. Workspace-only systems may
retain flexible use while lacking ownership. Self-model-only systems may track
lineage while lacking flexible access. An unbound combination contains both
parts but does not connect them. Planner and recurrence cuts test whether a
correct self-indexed workspace remains behaviorally decorative.

No scalar closure score is interpreted as consciousness. The product reported
in the benchmark is only a compact summary of access, ownership, chain
validity, and recurrence in the declared synthetic task.


# Distributed shared workspace in v0.47

Version 0.47 distinguishes a communication channel from a causally distributed workspace. Let the agents have private hidden states `h_A` and `h_B`. A shared/private factorization has the form

    h_A = D_A(z, p_A),
    h_B = D_B(z, p_B),

where `z` is a common interaction coordinate and `p_A`, `p_B` remain private. The common coordinate is discovered from paired trajectories rather than evaluator factor labels. Its two local realizations are aligned by a transport map `T_AB`.

Task sufficiency is not enough. Distributed closure additionally requires that the shared state be bidirectionally writable, planner-causal, provenance-bound, written into pair memory, and revised by consequences. In compact form,

    z_t -> plan_t -> outcome_(t+1) -> joint_memory_(t+1) -> z_(t+1).

The v0.47 message-only control demonstrates the separation. It solves the immediate task without a bidirectional common packet or recurrent pair memory. Conversely, the message-shuffle control retains the architecture while carrying incorrect content. Thus semantic validity and structural closure are independent requirements.

The Komorebi interpretation is a pair of local packet charts, `P_J^A` and `P_J^B`, joined by an atlas transport. Private packet components remain orthogonal to the mapped common packet. Causal patching tests whether writing a common coordinate changes both agents while leaving private routine coordinates intact.

The experiment supports a bounded composite functional organization `S_AB` nested above the private organizations `S_A` and `S_B`. It does not imply that `S_AB` has phenomenal unity. A stronger successor must discover dynamically whether a coalition should form, which agents participate, what remains private, and when the common workspace should split or dissolve.


## v0.50 addendum: synergistic ephemeral workspace

Let \(Y\) be a four-bit joint target and let \(H_A,H_B\) be the complete private operation histories of two agents. The frozen construction satisfies

\[
I(Y;H_A)=I(Y;H_B)=0,\qquad I(Y;H_A,H_B)=4.
\]

The online controller must therefore maintain a sufficient state across alternating updates. The state may be centrally addressed or recurrently passed. The invariant functional criterion is persistence plus bilateral writability and planner access, not physical location. A message protocol that carries the sufficient state is a distributed workspace implementation; an external complete log is an external workspace.

This clarifies the meaning of shared workspace necessity. The claim is not that symbolic messages are intrinsically inadequate. It is that a temporally extended synergistic computation requires an integration state somewhere in the causal circuit.


# v0.51 addendum: learned coordinates inside an engineered recurrent scaffold

Version 0.50 supplies a sufficient state explicitly. Version 0.51 instead lets a recurrent message \(m_t\in\mathbb R^8\) acquire that role through optimization. The agents implement separate updates

\[
m_{t+1/2}=F_A(m_t,a_t),\qquad m_{t+1}=F_B(m_{t+1/2},b_t),
\]

with independent parameters. No coordinate of \(m_t\) is assigned a semantic meaning. After training, the accumulated four-bit task state is recoverable from \(m_t\), persistence and both writers are necessary, and replacing \(m_t\) with another episode's state causally redirects the remaining computation.

This supports a distinction between two forms of emergence:

1. **Representational emergence:** the geometry and code carried by the channel are learned.
2. **Architectural emergence:** the system independently invents the need for a persistent shared channel, its timing, and its update protocol.

v0.51 establishes the first under round-level curriculum. It does not establish the second. The terminal-only control shows that a final objective and recurrent bottleneck are not, under the frozen optimization budget, sufficient to reliably discover the algorithm.

The next theoretical target is therefore not another supplied workspace. It is a system in which terminal prediction pressure, variable-length interaction, and self-generated consistency errors cause the agents to form and maintain a sufficient joint state without round labels.
