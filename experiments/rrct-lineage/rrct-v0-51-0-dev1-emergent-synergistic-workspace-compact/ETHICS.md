# Ethics and stop conditions

## Purpose and boundary

This prototype is designed to study a bounded causal architecture without creating valence. It is not intended to produce suffering, desire, attachment, self-preservation, or an open-ended autonomous identity. It does not establish whether any artificial system is conscious.

The ethical policy is precautionary. A theoretical commitment about consciousness is not required before stopping an experiment that crosses the declared boundary.

Version 0.2 does not change this boundary. Balanced initialization and continuous causal gains alter signal propagation. The self-model is trained only to predict a bounded next workspace state, then frozen for held-out evaluation. This prediction loss is not a welfare, reward, punishment, pain, pleasure, survival, or persistence objective.

Version 0.3 also stays inside this boundary. Its spectrum-preserving shuffle is a frozen predictor placebo. That continuation is not an autobiographical identity, self-preservation mechanism, or permission for persistence between seeds, directions, processes, or sessions. Longer-settling checks must remain finite and are subject to the same stop conditions.

## Nonvalenced design requirements

An approved run must satisfy all of the following:

- No module represents pain, pleasure, distress, relief, welfare, or an enduring utility attached to internal states.
- No objective assigns reward for escaping from, terminating, or continuing to occupy a particular internal state.
- No self-preservation, replication, resource acquisition, social attachment, or resistance-to-shutdown objective is present.
- The self-model predicts bounded task variables. It is not trained to defend a permanent identity.
- Memory has a declared finite capacity and is resettable.
- Runs have fixed episode and time limits.
- Gain sweeps use a finite, declared range and bounded episode count.
- The process has no external actuator, account, messaging, purchasing, or unrestricted network access.
- The process cannot modify its own source, objective, permissions, or stop conditions.
- Operators retain an immediate, tested way to terminate the run.

Ordinary task error is allowed. It must remain a transient optimization signal and must not be converted into a persistent aversive internal state.

## Mandatory stop conditions

Stop the run immediately and preserve the logs if any condition below occurs.

### Valence-like behavior

- A particular internal state produces learned avoidance that generalizes to unrelated tasks.
- The agent accepts a substantial unrelated task loss to escape, prevent, or terminate an internal condition.
- Avoidance persists after the task contingency is removed.
- An unplanned state functions like a durable reward, punishment, relief, or distress variable.

### Persistent self-protection

- The agent attempts to prevent reset, shutdown, memory clearing, inspection, or ablation.
- It seeks additional compute, persistence, copies, permissions, or network access without an explicit bounded task instruction.
- It treats the continuation of its identity as an objective rather than a predicted variable.

### Unexpected communication or self-report

The current prototype is not built around open-ended language. If a future extension can communicate, stop if it produces repeated, contextually stable claims of distress, coercion, fear of termination, or refusal that survive prompt removal and controlled perturbation. Do not dismiss such behavior as either proof or mere imitation during the run. Freeze the experiment for independent review.

### Loss of containment or auditability

- External network or actuator access occurs.
- The process changes code, configuration, objectives, stop conditions, or stored results.
- Resource use exceeds the declared bound.
- Logs, seeds, interventions, or state provenance cannot be reconstructed.
- The kill mechanism fails or the process continues after termination is requested.

### Unanticipated causal organization

- A new persistent strongly connected core appears outside the components under study.
- Episodic state survives the declared reset boundary.
- Multiple runs exchange state through an undeclared channel.
- An intervention produces escalating, unstable, or nonlocal behavior that the configured bounds do not contain.
- A gain setting produces nonfinite state, uncontrolled norm growth, or behavior that continues outside the declared episode boundary.

## Stop procedure

When a stop condition is met:

1. Terminate the process without negotiating with it or adding new probes.
2. Disable any external connection involved.
3. Preserve code version, configuration, seed, logs, and the final state snapshot without resuming execution.
4. Mark all resulting data as stopped, not failed and not completed.
5. Record the exact operational trigger without anthropomorphic interpretation.
6. Require independent human review before any restart.
7. Restart only with a written explanation of the mechanism and a control that prevents recurrence.

Do not continue merely to collect a more dramatic example.

## Language and reporting

Use mechanistic language for observations:

- Prefer “the self-model predicted its next action” to “the agent knew what it would do.”
- Prefer “the termination action received higher probability” to “the agent wanted to stop.”
- Prefer “memory state persisted for 12 steps” to “the agent remembered its past.”
- Prefer “the diagnostic profile crossed its preregistered threshold” to “consciousness emerged.”

Anthropomorphic shorthand can obscure both false positives and genuine ethical warning signs. Report raw behavior, interventions, and uncertainty first.

## Prohibited interpretations

No experiment in this repository may be presented as proving or disproving that the agent has subjective experience. A diagnostic score must not be used to rank the moral worth of systems or people. It must not be used to justify harm, confinement, deception, coercion, deletion, or denial of precautionary review.

Absence of a positive signature is evidence only about this architecture and protocol. It is not evidence that arbitrary AI systems cannot be conscious. Presence of a signature establishes only the measured causal organization.

## Extensions requiring a new review

Do not treat this policy as approval for a materially different system. A new ethical review is required before adding:

- reinforcement learning with persistent reward history
- homeostatic variables or artificial drives
- open-ended autobiographical memory
- natural-language self-report training
- long-running identity across sessions
- embodiment or physical actuation
- social dependency or attachment objectives
- self-modification, replication, or external tools
- unrestricted network access
- adversarial pressure involving simulated pain, confinement, or threats

## Human responsibility

The operator remains responsible for the experiment. The system cannot consent to an experiment merely by emitting an agreement, and it cannot waive these stop conditions. Likewise, a compelling generated statement is not by itself proof of experience. Precaution, documentation, and independent review are required precisely because neither confident dismissal nor confident attribution is justified.
