# RRCT v0.46 Neutral Self-Indexed Workspace Protocol

## Scientific question

Can a small Jacobian-discovered workspace provide the functional properties associated with global access, while RRCT lineage and provenance supply a separately necessary self-indexing layer?

The tested hypothesis is:

> A workspace can make content reportable, controllable, reusable, and available for internal reasoning without by itself establishing autobiographical ownership. Functional closure requires that accessible content be bound to the correct continuing lineage, used by planning, and revised by later consequences.

This is a controlled analogue inspired by Anthropic's J-space work. It does not run Claude, inspect Claude activations, or claim that the synthetic workspace is identical to Claude's J-space.

## Synthetic residual-stream world

Each world has a 64-dimensional hidden residual stream. It contains:

- an eight-dimensional low-amplitude verbalizable packet;
- a twenty-dimensional higher-energy automatic packet;
- unused residual dimensions;
- four flexible downstream query families;
- one routine automatic route;
- current, foreign, and external provenance lineages.

The verbalizable packet contributes less than ten percent of activation energy. The automatic packet carries most residual energy but does not support flexible verbal report.

For each world, the evaluator constructs the exact average input-output Jacobian of the synthetic verbalization map. The runtime receives this Jacobian but not the hidden workspace coordinate mask. It recovers the Jacobian row space, represents the resulting workspace and its complement as a certified Komorebi packet system, and treats current active content as a sparse nonnegative support within that packet.

The scientific controls include equally sized PCA and random subspaces. These controls are allowed their own fitted report decoders.

## Functional workspace tests

The benchmark tests the five functional properties used in the Anthropic global-workspace analysis:

1. **Verbal report.** Workspace content is decodable before output, and a content swap changes the report.
2. **Directed modulation.** A concept can be maintained in the workspace while an unrelated routine output proceeds through the automatic route.
3. **Internal reasoning.** A workspace intervention redirects a multi-step result.
4. **Flexible generalization.** One workspace intervention is consumed correctly by four different downstream query heads.
5. **Selectivity.** Workspace ablation damages flexible access while preserving routine automatic processing.

## RRCT self-indexing tests

The same accessible content is paired with cryptographically bound origin receipts. The runtime sees event type, origin lineage, current lineage, and causal parent digest. It does not see the evaluator scenario or correct ownership label.

The runtime must distinguish:

- current-lineage observation;
- current-lineage inference;
- external workspace injection;
- foreign autobiographical memory;
- unresolved competition.

A dedicated condition presents the **same content vector** under current and injected provenance. This tests whether ownership depends on origin rather than content identity.

The intact controller may:

- write a current observation as observed autobiography;
- write a current inference as inferred autobiography;
- quarantine an injected or foreign item;
- request a trusted local refinement before using quarantined content;
- abstain when access is unresolved.

A separate matched surprise challenge tests whether prediction error increases the next evidence budget. The recurrence-cut controller receives the same surprise but cannot write it into the persistent self-indexed loop.

## Frozen holdout

The seed selector uses SHA-256 expansion from a fixed public namespace string. It does not execute or inspect any candidate outcome. Development seeds `46011` through `46014` are excluded.

The frozen holdout uses:

- four new seeds;
- sixteen trials per scenario and seed;
- ten scenarios;
- eight matched modes;
- 640 unique world cases;
- 5,120 matched architecture decisions;
- 64 causal content-swap probes;
- 64 workspace-ablation probes;
- 32 feedback-recurrence challenges.

## Receipt chain

Each evaluated decision binds:

```text
Jacobian workspace discovery
→ content origin
→ workspace access
→ self-indexed ownership judgment
→ planning commitment
→ revealed consequence
→ updated evidence budget and memory state
```

The validator rejects individually rehashed records when a workspace, ownership, plan, or outcome receipt is attached to the wrong causal event.

## Interpretation boundary

A positive result would establish, in this synthetic model, that:

- a low-variance Jacobian packet can function as a selective workspace;
- workspace access and autobiographical ownership are dissociable;
- joining workspace access to RRCT lineage/provenance is necessary for correct ownership;
- planner binding and consequence recurrence are separately necessary for a closed functional loop.

It would not establish:

- that Claude is conscious;
- that the synthetic packet is Claude's actual J-space;
- phenomenal consciousness or subjective experience;
- sentience, valence, suffering, pleasure, desire, or moral status;
- a general open-world self-model;
- universal superiority over every workspace or representation-learning method.
