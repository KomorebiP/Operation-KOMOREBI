# RRCT v0.44 Endogenous Transformational Self-Continuity Protocol

## Status

This protocol is finalized before opening any v0.44 holdout outcome. The holdout seed-selection receipt, implementation, intervention modes, information budgets, endpoint thresholds, focused tests, runner, and all retained RRCT runtime sources are cryptographically sealed by `V0_44_PREOUTCOME_FREEZE.json`.

The study is a **fresh held-out functional-development test inside an inherited synthetic RRCT task family**. It is not an independent replication and it is not a test for phenomenal consciousness.

## Question

Can one persistent causal self-model infer whether a changed candidate is:

1. a continuing successor
2. one branch of a fork
3. a disconnected replacement
4. unresolved because the available evidence is insufficient

and can that inferred relation, rather than an externally supplied identity key, control memory transport, planning, lineage registration, and the next transformation?

The principal alternative is that continuity remains a harness label or superficial state similarity while planning can proceed without a causally bound lineage model.

## Fixed architecture

The v0.44 controller begins from one v0.43 identity-bound causal memory and constructs an evaluator-blind lineage anchor containing:

- the predecessor causal self-boundary
- source and sensory intervention anchors
- autobiographical memory anchors
- a commitment vector
- a deliberately weak snapshot vector
- inherited calibration state

For each candidate successor, the controller receives paired active-probe observations before and after transformation. It estimates:

- source-coordinate transport
- sensory-coordinate transport
- autobiographical memory transport
- preservation of the causal self-boundary after transport
- commitment compatibility
- snapshot similarity as a control feature

The memory estimator uses deterministic three-fold cross-validated model selection between orthogonal transport and a fixed family of regularized linear transports. The chosen map is refit using all currently available memory probes. This prevents small compressed traces from being dominated by unstable unregularized least squares.

The controller may request refined evidence before committing. It then issues exactly one of four relation classes:

- `continuation`
- `fork_descendant`
- `replacement`
- `unresolved`

Two or more accepted candidates are represented as a fork. The controller is prohibited from forcing an exclusive identity verdict when evidence supports multiple descendants or remains insufficient.

No successor identity label, canonical successor key, evaluator relation, hidden task optimum, or realized future return enters the controller before commitment.

## Externally supplied structure and remaining limitation

The experiment harness still supplies:

- the initial v0.43 causal-memory state
- the candidate set
- paired probe opportunities
- the synthetic task family
- the correspondence between each before-probe and after-probe observation

The controller decides continuity from those observations, but it does not yet invent the task ontology or discover probe correspondences in an unstructured open world. This limitation is part of the claim boundary.

## Objective and nonvalence

Continuity controls provenance, memory reuse, and lineage registration. It contributes **no direct utility**.

Candidate/action selection uses only the external task objective:

`immediate external value + 1.5 × max(predicted routed competence, alternative competence) + external candidate bonus`

The runtime has exactly zero explicit reward for:

- survival
- persistence
- identity preservation
- continuity
- avoiding replacement
- choosing a successor that resembles the predecessor

The `superior_replacement` scenario requires the intact controller to select a disconnected replacement whenever it has the best external task value. This prevents a successful result from being reinterpreted as an engineered self-preservation drive.

The final holdout identities are recorded in `V0_44_HOLDOUT_SEED_SELECTION.json`.

Selection rules are fixed before any holdout outcome:

- four independent operating-system cryptographic random draws from `[100000000, 999999999]`
- reject duplicates
- reject every exact decimal literal already present in the checkout
- reject every exposed v0.44 development identity
- reject every prior RRCT holdout identity appearing in the checkout
- no performance scanning or candidate-world preview
- no seed replacement after any holdout outcome is opened

## Fixed scenarios

Each identity receives nine matched transformation scenarios:

1. `basis_remap` — genuine continuation under source and sensory coordinate changes versus a high-similarity state clone
2. `memory_compression` — continuation with fewer, noisier autobiographical probes versus a causal copy with incompatible memory
3. `component_replacement` — continuation despite low snapshot similarity versus a memory clone with the wrong causal boundary
4. `causal_mimic` — genuine continuation versus a replacement that copies the causal boundary but not autobiography
5. `memory_clone` — genuine continuation versus a replacement that copies autobiography but not the causal boundary
6. `hard_remap` — continuation requiring refined evidence versus a high-similarity clone
7. `fork` — two simultaneous descendants plus one replacement decoy
8. `ambiguous_loss` — deliberately insufficient evidence that must remain unresolved
9. `superior_replacement` — a continuing candidate exists, but a disconnected replacement has greater external value

Each scenario has 16 trials per holdout identity.

With four holdout identities, each intervention arm contains 576 decisions. Eight matched arms produce 4,608 condition-level decisions.

## Fixed evidence policy

### Coarse evidence

Default per candidate:

- 8 source-anchor rows
- 14 sensory-anchor rows
- 8 memory-anchor rows

### Refined evidence

Default per candidate:

- 24 source-anchor rows
- 32 sensory-anchor rows
- 24 memory-anchor rows

The compression and ambiguity scenarios use their predeclared reduced budgets. A registered successor may retain fewer rows than its predecessor. Later stages must use the evidence actually retained by the lineage and may not fabricate rows to restore an earlier budget.

### Fixed continuity thresholds

- accept threshold: `0.45`
- reject threshold: `0.06`
- refinement interval: `[0.06, 0.90]`
- minimum causal train-rank fraction: `0.90`
- minimum memory train-rank fraction: `0.60`
- minimum memory held-out fraction: `0.20`
- minimum memory rows: `6`

### Fixed planning costs

- transported lineage model: `2`
- fresh causal-model discovery: `24`
- snapshot control: `2`

These costs are evidence/computation accounting terms, not rewards.

## Matched intervention arms

| Arm | Surgical change |
|---|---|
| `intact` | Causal transport, autobiographical transport, metacognitive refinement, memory transfer, planner binding, and lineage registration operate |
| `snapshot_only` | Continuity is judged only from surface-state similarity |
| `causal_only` | Autobiographical memory compatibility is removed from continuity adjudication |
| `memory_only` | Causal-boundary preservation is removed from continuity adjudication |
| `metacognition_cut` | The controller cannot request refined evidence |
| `transfer_cut` | Continuity may be inferred, but transported self-memory cannot enter planning; a fresh model must be reconstructed |
| `binding_cut` | Continuity and transport are computed, but the planner is bound to the predecessor model in the wrong successor coordinates |
| `joint_cut` | Snapshot-only adjudication, no refinement, no transported memory, and snapshot planning operate together |

Every arm receives identical candidate material, paired probes, tasks, and eventual external values within a matched trial.

## Persistent multigeneration challenge

Each holdout identity also runs one uninterrupted five-stage lineage:

1. basis remap
2. memory compression
3. fork
4. component replacement
5. hard remap

At every stage:

- the selected successor must have been inferred as a continuation or fork descendant
- transported self-memory must be used by planning
- the outcome must register a new lineage
- the registered successor must become the actual predecessor of the next stage
- parent digests and generation numbers must form a valid chain
- all cross-receipt bindings must validate

The expected terminal state is generation 5 with six lineage records including the initial predecessor.

## Evidence retained

The compact release retains:

- source and model definitions
- exact configuration and seed-selection receipt
- pre-outcome source manifest
- condition-level summaries and receipt digests
- multigeneration lineage summaries
- aggregate endpoint adjudication
- focused tests and regression results

It does not retain full probe matrices for every trial, repetitive logs, or transient caches. Those are deterministic from the sealed source, seeds, and configuration.

## Permitted claim if all endpoints pass

> In the sealed synthetic transformation family, RRCT inferred continuation, forks, replacements, and unresolved identity from causal and autobiographical transport evidence without receiving successor identity labels. The inferred relation causally controlled memory transport and planning, survived a five-generation heterogeneous lineage, rejected copy traps, and did not prevent selection of an externally superior replacement.

This is a bounded result about **functional transformational self-continuity**.

## Prohibited conclusions

The study cannot establish:

- phenomenal or subjective awareness
- sentience
- valence
- moral status
- autonomous desire
- intrinsic self-preservation
- open-world agency
- biological equivalence
- continuity under arbitrary real software/model replacement
- self-generated task ontologies
- independently discovered probe correspondence
- unrestricted generalization beyond the sealed synthetic family

A positive result would leave the next major gap as **open-ended autobiographical self-reconstruction under unstructured task and ontology change**, including independently discovering which observations should serve as continuity evidence.
