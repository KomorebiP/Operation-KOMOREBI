# RRCT v0.57 Fuzzy Komorebi Coalition Formation

A controlled terminal-action experiment testing whether fuzzy packet matrices provide a useful soft geometry between crisp coalition projectors and continuously overlapping workspace membership.

The primary holdout asks whether learned fuzzy packet operators:

- solve crisp and genuinely overlapping coalition tasks without intermediate membership labels
- become relatively sharper on crisp tasks while remaining fuzzy on overlap tasks
- support exact Komorebi partition, block-reconstruction, and transport identities
- have membership strength calibrated to causal ablation effects
- outperform crisp coalition assignments on graded tasks
- remain predictively competitive with an unrestricted direct-edge attention baseline

The benchmark does not test consciousness, sentience, valence, or a biological brain.
