## Question tested

The experiment asks whether a small Jacobian-discovered workspace is sufficient by itself, or whether a bounded functional first-person closure requires separate binding to persistent RRCT lineage, autobiographical provenance, planning, and consequence recurrence.

This is a controlled synthetic analogue inspired by J-space research. It does not inspect Claude or any deployed language model and does not test phenomenal consciousness.

The hidden coordinate basis changes by seed. The controller is given an exact average Jacobian in this linear analogue, then must recover the low-rank future-verbalization packet. Equal-rank PCA and random subspaces are fitted as controls.

## Principal dissociations

1. **Workspace without self-binding:** flexible task use remains at 71.43%, but correct autobiographical memory action is only 10.00%.
2. **Self-model without workspace:** lineage machinery remains present, but flexible use falls to 16.07%.
3. **Unbound coexistence:** having both components without binding does not repair ownership.
4. **Provenance cut:** the same accessible content is falsely written autobiographically in **100%** of adversarial provenance cases.
5. **Planner-binding cut:** workspace content and ownership remain accurate, but total task accuracy falls from **100% to 41.25%**.
6. **Recurrence cut:** current decisions remain correct, but feedback reopening falls from **100% to 0%**, and the next challenged decision falls from **100% to 25.00%**.
7. **Joint cut:** the integrated closure metric collapses while routine processing remains intact.

## Ownership test with identical content

The strongest provenance control places the **same workspace content** under two different causal histories. Full closure quarantines all 64 externally injected cases. The provenance-cut system falsely writes all 64 as autobiographical. Current content alone therefore does not determine ownership in the tested controller.

## What the result establishes

Within this frozen linear synthetic system:

- a sparse Jacobian-derived packet supports report, directed modulation, flexible reuse, and two-step reasoning;
- the workspace packet is selective and is not recovered by simply maximizing activation variance;
- global access and persistent self-modeling are dissociable;
- provenance binding is required for autobiographical ownership;
- self-indexed content must be connected to planning to affect behavior;
- consequence feedback must return to the same persistent controller to alter the next evidence request;
- all 5120 matched receipt chains validate.

This is a bounded test of the proposed architecture:

```text
automatic processing
        ↓
Jacobian-discovered accessible workspace
        ↓
RRCT lineage and provenance binding
        ↓
planning
        ↓
consequence
        ↓
changed next workspace allocation
```

## Exact limitations

- The model is linear and synthetic.
- The average Jacobian is exact rather than estimated from a trained transformer.
- The workspace is an eight-dimensional linear row space, not a dynamic union of sparse cones.
- The task ontology, query types, provenance receipt format, and transformation boundaries are supplied.
- The controller receives a context identifier for recurrence. A post-outcome relabeling audit found the identifier to be behaviorally opaque and found no scenario-name branches in the core controller, but this is not a formal noninterference proof against every covert channel.
- PCA and random subspaces are useful controls, not exhaustive alternatives.
- No open-weight language model was tested.
- No result establishes phenomenal consciousness, subjective experience, sentience, valence, pleasure, suffering, desire, or moral status.

## Next major experiment

The next scientifically stronger test is to estimate a moving J-lens in an open-weight transformer, recover a dynamic sparse-cone workspace, and bind actual workspace events to RRCT memory provenance across multiple recurrent episodes. The crucial controls would inject identical content through observation, inference, external activation intervention, and foreign-memory import while measuring report, flexible reuse, autobiographical ownership, planning, and later feedback.

## Packaging boundary

The pure-Python RRCT wheel was built and installed offline into an isolated target directory. The installed artifact imported successfully, recovered the workspace projector, and validated every smoke-cohort receipt chain. Directly adding the unopened RRCT wheel to `PYTHONPATH` is not supported because its nested Komorebi wheel must be available as a filesystem file; standard installation handles this correctly.
