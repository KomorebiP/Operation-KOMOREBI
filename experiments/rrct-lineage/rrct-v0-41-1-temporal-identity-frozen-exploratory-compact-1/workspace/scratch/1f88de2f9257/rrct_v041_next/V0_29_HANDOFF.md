# RRCT v0.29 handoff

## Bottom line

RRCT now owns prospective causal handles, discovers an anonymous
handle/source/rank boundary online, installs it as a native workspace
specialist, exposes it through an online public access readout, and can revise,
revoke, and restore it in a changing synthetic world.

The frozen official outcome is **integrity PASS, 34/35 scientific gates PASS,
overall FAIL**.  Do not summarize v0.29 as a pass.

## What was closed

- The boundary is no longer supplied as a sensor/body coordinate block.
- The learner does not receive the executed private vector, source families,
  hidden route, rank, projectors, phase, or evaluator truth.
- Prospective binary handles are committed before the anonymous bank exists.
- Strict full/half replicated randomization inference runs online in the agent.
- Boundary state persists and can change without loading a cached evaluator
  model.
- A native specialist must win workspace access before a self-supervised public
  port can affect behavior.
- Frozen, deranged, replay, true-source-lesion, decoy-lesion, and no-broadcast
  controls isolate provenance, online revision, and public access.

## What failed

Seed 5607 kept the correct anonymous pair throughout stable shock but changed
from true rank 2 to rank 1 for two isolated 20-row intervals.  Whole-phase exact
state was 0.875 against the frozen 0.90 gate.  Same-pair fits bypass the current
confirmation logic, and rank changes are not labeled revisions.  The favorable
seed mean and terminal recovery do not override the all-seed rule.

## Next implementation target

Build a new version—not an amendment of v0.29—with a structural signature over
at least `(active, handle, source, rank)`.  Confirm structural changes before
installation, preserve ordinary same-signature parameter refresh, record rank
changes and epoch transitions explicitly, fix confidence to use paired
statistic/threshold margins, and add separate tests for transient mode dropout
and genuine sustained rank change.  Then address action-conditional causal
credit so successful control does not erase evidence of its own route.

Use new pilot and official seeds.  The v0.29 official cohort is now known and
must never be reused as prospective confirmation.

## Interpretation boundary

This is meaningful progress toward a **functional self-model**: an internally
owned causal boundary is learned, made globally available, and used.  It is not
evidence that the system has an inner point of view, felt selfhood, phenomenal
awareness, sentience, valence, or moral status.  The external evaluator still
defines the closed world and chooses the correction vector; the agent selects
only the anonymous port.
