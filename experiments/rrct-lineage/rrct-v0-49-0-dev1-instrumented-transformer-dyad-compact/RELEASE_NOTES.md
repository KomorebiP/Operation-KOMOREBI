# RRCT 0.49.0.dev1 — Instrumented Transformer Dyad

## Added

- two separately initialized tiny transformer agents trained from scratch through recurrent continuous messages
- residual-stream instrumentation at three recurrent stages
- exact average gradients from shared report heads into intermediate residual states
- cross-agent representation alignment, linear decoding, selective ablation, and causal activation patching
- one-sided A-to-B and B-to-A transmission tests followed by local-evidence correction
- same-rank PCA and random-subspace controls
- message-only cooperation control
- four-seed source-sealed holdout with 23 predeclared endpoints

## Frozen result

All 23 endpoints passed on four untouched seeds. The early h1 average-Jacobian state had the predicted rank four but failed the stronger semantic, alignment, and causal-necessity criteria. A late h3 shared-access state aligned across independently initialized agents (mean report-space R² 0.9813; broader rank-eight R² 0.9897), supported all shared tasks, transmitted unilateral patches to the partner, and showed selective shared-task loss under ablation while private routines remained intact.

The broader late space explained roughly 79 percent of residual variance. Same-rank PCA performed comparably to the Jacobian-informed construction. The patch transmitted across one recurrent round but was corrected by persistent local evidence on return. A message-only decoder also solved the immediate joint task perfectly.

## Boundary

This is a bounded trained-transformer shared-access pilot, not a full distributed J-space result. It uses tiny task-specific transformers trained on all 144 combinations, not pretrained language models. It does not establish an early or persistent pair workspace, Jacobian specificity, spontaneous natural-language semantics, shared phenomenal consciousness, sentience, valence, or moral status.

## Version 0.9.0-dev1

Version 0.9.0-dev1 is a **development-only, non-preregistered, non-confirmatory** Bayesian causal-transfer implementation. It adds a bounded, no-intercept Normal-Inverse-Gamma regression over 20 named internal features. The posterior predicts a correction to rollout-estimated improvement for bounded self-state interventions. Its normalized target is the paired realized internal-`error_norm` reduction minus the rollout-predicted reduction, divided by \(4\sqrt{\text{workspace dimension}}\). Candidates evaluated against one shared hidden suffix are fractionally weighted to one effective episode.

This is conditional prediction of paired intervention outcomes under one frozen RRCT configuration and one internal metric. The word *causal* refers to those matched baseline/candidate interventions; the regression does not independently identify general causal structure, estimate unrestricted environmental effects, or establish external task improvement.

### Separated development protocol

- uses disjoint, hash-audited base-predictor, Bayesian-transfer, conformal-calibration, and evaluation episode splits
- freezes the self predictor, observation forecaster, Bayesian posterior, and calibration bank before held-out evaluation
- compares exact-zero, rollout, Bayesian-mean, Bayesian-credible, conformal, and deterministically permuted-outcome controls on matched query sets
- records marginal Bayesian uncertainty separately from the configuration-matched one-sided conformal optimism gate
- derives a descriptive risk-coverage table from calibration-prediction quantiles, the zero threshold, and a no-action sentinel without using evaluation outcomes to choose thresholds
- retains zero held-out posterior and calibration updates as explicit integrity requirements

### Portable artifact and audit controls

- writes self-predictor, observation-forecaster, real-posterior, and permuted-posterior snapshots as compressed NumPy artifacts
- loads portable snapshots with `allow_pickle=False`; `load_flat_snapshot_artifact()` and `load_transfer_snapshot_artifact()` reconstruct arrays and explicit JSON metadata
- transactionally validates transfer schema, dimensions, bounds, coordinate names, array hashes, sufficient-statistic consistency, receipt order, configuration/provenance keys, permuted mappings, posterior digests, and the complete agent-snapshot digest
- retains calibration-bank JSON, evidence/prediction/calibration/policy/risk-coverage CSVs, split hashes, source-file SHA-256 values, a machine-readable summary, and a complete output manifest
- refuses nonempty output directories and audits row retention, split disjointness, nonmutation, commit-before-reveal ordering, API/offline agreement, and held-out update counts
